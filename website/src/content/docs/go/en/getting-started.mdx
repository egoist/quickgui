QuickGUI apps are ordinary Go programs. Write components and fine-grained reactive state in Go, then build with `CGO_ENABLED=0`. The prebuilt native library is loaded in the same process through purego. Bun runs the CLI for development and packaging.

## Requirements

- macOS 14 or newer
- Go 1.23 or newer
- Bun 1.3 or newer
- Xcode Command Line Tools (`xcode-select --install`)

The packaged UI application currently targets macOS. Normal application builds use the prebuilt native host.

## Create a project

The CLI is not published yet. Start from a [QuickGUI checkout](https://github.com/egoist/quickgui) and run the Go counter:

```bash
bun install
bun packages/cli/src/cli.ts dev --project examples/counter
```

To create a separate app, scaffold without installing registry packages and choose **Go** when prompted:

```bash
bun packages/cli/src/cli.ts init ../my-app --no-install
cd ../my-app
go mod edit -replace github.com/egoist/quickgui/go=../quickgui/go
go mod tidy
```

In the generated `quickgui.config.ts`, change the `defineConfig` import to `../quickgui/packages/cli/src/index.ts` to use the local CLI. Then run `bun packages/cli/src/cli.ts dev --project ../my-app` from the QuickGUI checkout. Pass `--language go` to `init` to skip the language prompt.

## Your first window

The generated `main.go` imports `native` for windows and `ui` for components. Pass the component function directly to `WindowOptions.Component`. Call `native.Run` once to start the application event loop.

```go
package main

import (
	"github.com/egoist/quickgui/go/native"
	"github.com/egoist/quickgui/go/ui"
	"log"
)

func Counter() *ui.Element {
	count, setCount := ui.CreateSignal(0)
	return ui.View(
		ui.Text("Fine-grained native UI").FontSize(28).FontWeight(700),
		ui.Text("Count: ", count()),
		ui.Button("Increment").
			OnClick(func() { setCount(count() + 1) }).
			Padding(12).
			RoundedLg().
			Bg("#2563eb").
			Hover(func(s ui.StyleBuilder) ui.StyleBuilder { return s.BackgroundColor("#3b82f6") }),
	).FlexCol().
		SizeFull().
		ItemsCenter().
		JustifyCenter().
		Gap(20).
		Bg("#090d16").
		TextColor("#e2e8f0")
}

func main() {
	if err := native.Run(func() {
		open := func() {
			native.NewWindow(native.WindowOptions{
				Title:     "My App",
				Width:     720,
				Height:    480,
				Component: Counter,
			})
		}
		native.App.OnReopen(func(event native.ReopenEvent) {
			if !event.HasVisibleWindows {
				open()
			}
		})
		open()
	}); err != nil {
		log.Fatal(err)
	}
}
```

## Run and build

The watcher rebuilds your Go source and restarts the development app. The formatter gives long component calls consistent line breaks while preserving ordinary Go syntax. Production bundles are written under `dist/darwin-*`.

```bash
bun packages/cli/src/cli.ts dev --project ../my-app
bun packages/cli/src/cli.ts fmt --project ../my-app
bun packages/cli/src/cli.ts build --project ../my-app
```
