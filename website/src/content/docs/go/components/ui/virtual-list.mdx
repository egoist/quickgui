Lays out and paints the visible part of a long or variable-height collection.

## Import

Import `ui` from `github.com/egoist/quickgui/go/ui`.

```go
import (
	"github.com/egoist/quickgui/go/ui"
)
```

## Usage

```go
func VirtualListExample(rows []string, rowHeights []float64) *ui.Element {
	return ui.VirtualList().Child(func() *native.Node {
		var children []*native.Node
		for _, row := range rows {
			children = append(children, ui.Text(row).Height(36).Node)
		}
		return ui.Fragment(children)
	}).Height(320).EstimatedItemHeight(36).Overscan(6).
		OverscanPixels(240).ItemHeights(rowHeights).FollowMode("normal")

}
```

## Key props

| Prop | Purpose |
| --- | --- |
| `EstimatedItemHeight` | Initial logical row-height estimate used by virtualization. |
| `Overscan` | Extra rows mounted before and after the visible range. |
| `OverscanPixels` | Extra logical distance mounted before and after the visible range. |
| `ItemHeights` | Exact row heights supplied without waiting for layout measurement. |
| `ListAlignment` | Pins short list content to the top or bottom. |
| `FollowMode` | Chooses ordinary scrolling or tail-following behavior. |
| `children` | Content mounted inside the component. |
