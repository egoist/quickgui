Embeds the retained Ghostty terminal surface and reports process lifecycle events.

## Import

```sh
go get github.com/egoist/quickgui/extensions/terminal
```

```go
import (
	"github.com/egoist/quickgui/go/native"
	"github.com/egoist/quickgui/extensions/terminal"
	"github.com/egoist/quickgui/go/ui"
)
```

## Usage

```go
func TerminalExample(directory string) *native.Node {
	return terminal.View(terminal.Props{
		Program:          "/bin/zsh",
		Args:             []string{"-l"},
		WorkingDirectory: directory,
		Props:            ui.Props{Style: ui.Style().Width("100%").Height(320)},
	})
}
```

## Key props

| Prop | Purpose |
| --- | --- |
| `Program` | Executable launched by the terminal. |
| `Args` | Arguments passed to the terminal process. |
| `WorkingDirectory` | Initial working directory for the terminal process. |
| `Environment` | Environment entries added to the terminal process. |
| `OnStatus` | Reports terminal process lifecycle changes. |
| `Palette` | Sixteen ANSI colors (`terminal.Palette`) or an accessor. Updates preserve the PTY. |
| `CursorColor` | Cursor color or color accessor. |
| `PaddingColor` | Use `"extend"` to paint padding with terminal edge backgrounds. |
| `FontThicken` | Enables native font thickening. |
| `Scrollback` | Maximum retained scrollback lines. |
