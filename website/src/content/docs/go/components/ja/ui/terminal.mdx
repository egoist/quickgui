ターミナルのバックエンドは独立したネイティブ拡張です。CLI は `terminal` のインポートを検出し、対応する `@quickgui/extension-terminal` を取得して同梱します。インポートしないアプリには含まれません。

保持型の Ghostty ターミナルサーフェスを埋め込み、プロセスのライフサイクルイベントを通知します。

## インポート

```sh
go get github.com/egoist/quickgui/extensions/terminal
```

```go
import (
	"github.com/egoist/quickgui/go/native"
	"github.com/egoist/quickgui/extensions/terminal"
	"github.com/egoist/quickgui/go/ui"
)
```

## 使い方

```go
func TerminalExample(directory string) *native.Node {
	return terminal.View(terminal.Props{
		Program:          "/bin/zsh",
		Args:             []string{"-l"},
		WorkingDirectory: directory,
		Props:            ui.Props{Style: ui.Style().Width("100%").Height(320)},
	})
}
```

## 主なプロパティ

| プロパティ | 説明 |
| --- | --- |
| `Program` | ターミナルが起動する実行ファイルです。 |
| `Args` | ターミナルプロセスに渡す引数です。 |
| `WorkingDirectory` | ターミナルプロセスの初期作業ディレクトリです。 |
| `Environment` | ターミナルプロセスに追加する環境変数です。 |
| `OnStatus` | ターミナルプロセスのライフサイクル変更を通知します。 |
| `Palette` | 16 色の ANSI パレット（`terminal.Palette`）またはアクセサー。更新しても PTY は維持されます。 |
| `CursorColor` | カーソル色または色のアクセサー。 |
| `PaddingColor` | `"extend"` で端の背景色を余白まで延長します。 |
| `FontThicken` | ネイティブのフォント増厚を有効にします。 |
| `Scrollback` | 保持するスクロールバックの最大行数。 |
