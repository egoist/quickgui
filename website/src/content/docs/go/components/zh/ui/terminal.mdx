终端后端是独立的原生扩展。CLI 会根据 `terminal` 导入获取并打包匹配版本的 `@quickgui/extension-terminal`；未导入的应用不会包含终端后端。

嵌入保留式 Ghostty 终端表面，并报告进程生命周期事件。

## 导入

```sh
go get github.com/egoist/quickgui/extensions/terminal
```

```go
import (
	"github.com/egoist/quickgui/go/native"
	"github.com/egoist/quickgui/extensions/terminal"
	"github.com/egoist/quickgui/go/ui"
)
```

## 用法

```go
func TerminalExample(directory string) *native.Node {
	return terminal.View(terminal.Props{
		Program:          "/bin/zsh",
		Args:             []string{"-l"},
		WorkingDirectory: directory,
		Props:            ui.Props{Style: ui.Style().Width("100%").Height(320)},
	})
}
```

## 主要属性

| 属性 | 说明 |
| --- | --- |
| `Program` | 终端启动的可执行文件。 |
| `Args` | 传递给终端进程的参数。 |
| `WorkingDirectory` | 终端进程的初始工作目录。 |
| `Environment` | 添加到终端进程的环境变量。 |
| `OnStatus` | 报告终端进程的生命周期变化。 |
| `Palette` | 16 色 ANSI 调色板（`terminal.Palette`）或访问器，更新时保留 PTY。 |
| `CursorColor` | 光标颜色或颜色访问器。 |
| `PaddingColor` | 使用 `"extend"` 将终端边缘背景延伸到内边距。 |
| `FontThicken` | 启用原生字体加粗处理。 |
| `Scrollback` | 保留的最大回滚行数。 |
