虚拟化的分栏或统一文件差异视图，行同步且面板可独立横向滚动。

默认不包含任何语言语法。Rust 可注册静态链接的语法；Go 和 TypeScript 可通过 `LoadLanguagePack` / `loadLanguagePack` 加载单个跨平台包，其中包含所选 Tree-sitter Wasm 语法与查询。

组件默认不带视觉样式：文本和行号继承颜色，不添加背景、边框、圆角、内边距或语法／差异配色。外观由应用显式提供样式与颜色。

## 导入

```sh
go get github.com/egoist/quickgui/extensions/editor
```

```go
import (
	"github.com/egoist/quickgui/extensions/editor"
	"github.com/egoist/quickgui/go/ui"
)
```

## 用法

```go
func DiffViewExample() *ui.Element {
	return editor.DiffView(editor.DiffViewProps{
		OldPath: "before.go",
		NewPath: "after.go",
		OldText: "func answer() int { return 41 }\n",
		NewText: "func answer() int { return 42 }\n",
		Options: editor.DiffOptions{
			Layout:      editor.DiffSplit,
			Indicators:  editor.DiffBars,
			LineNumbers: true,
			Language:    "go",
		},
		Props: ui.Props{Style: ui.Style().Width("100%").Height(420)},
	})
}
```

## 语法高亮

DiffView 使用与 Editor 相同的内置 Tree-sitter 语法。文档、语言或语法调色板变化时，Rust 核心会分别解析每个可见文件的新旧行序列，并把捕获片段分配给逻辑行。样式文本仅在行挂载时创建并缓存，再按互不重叠的字节边界合并行内新增/删除强调。滚动不会调用解析器。

## 主要属性

| 属性                  | 说明                                        |
| --------------------- | ------------------------------------------- |
| `OldText` / `NewText` | 完整的受控源码对；值可以是字符串或访问器。  |
| `OldPath` / `NewPath` | 文件标签及语言推断路径。                    |
| `Patch`               | 已捕获的 Git 或普通统一补丁；优先于源码对。 |
| `Options.Layout`      | `DiffSplit` 或 `DiffUnified`。              |
| `Options.Indicators`  | `DiffBars`、`DiffClassic` 或 `DiffNone`。   |
| `Options.Wrap`        | 对长行换行，而不是启用横向滚动。            |
| `Options.Backgrounds` | 启用新增行与删除行背景。                    |
| `Theme`               | 覆盖差异、行号栏、区块及行内变化颜色。      |
| `SyntaxTheme`         | 覆盖 Tree-sitter 捕获颜色。                 |

分栏面板各自保留横向偏移，并共享一个同步的纵向偏移。只挂载可见行及受限的预渲染行。
