可选择、无插入光标的代码视图，支持 Tree-sitter 着色和逻辑行虚拟化。

组件默认不带视觉样式：文本和行号继承颜色，不添加背景、边框、圆角、内边距或语法／差异配色。外观由应用显式提供样式与颜色。

## 导入

```sh
go get github.com/egoist/quickgui/extensions/editor
```

```go
import (
	"github.com/egoist/quickgui/extensions/editor"
	"github.com/egoist/quickgui/go/ui"
)
```

## 用法

```go
func CodeExample() *ui.Element {
	return editor.CodeBlock(editor.CodeBlockProps{
		Value:       "package main\n\nfunc main() {}\n",
		Language:    "go",
		LineNumbers: true,
		Wrap:        false,
		Props:       ui.Props{Style: ui.Style().Width("100%").Height(280)},
	})
}
```

## 语法高亮

`Language` 选择内置的 Tree-sitter 语法和高亮查询。捕获结果通过 `SyntaxTheme` 映射为只影响前景色的区间，因此高亮不会改变布局。源码或语言变化时由 Rust 核心解析；滚动只挂载逻辑行并创建预先计算的区间。解析最多处理 2 MiB，超过 32 KiB 的单行保持普通颜色，捕获数量也有上限。

## 主要属性

| 属性               | 说明                                                    |
| ------------------ | ------------------------------------------------------- |
| `Value`            | UTF-8 源码字符串或响应式访问器。                        |
| `Language`         | 内置语法名称，例如 `"go"`、`"rust"` 或 `"typescript"`。 |
| `LineNumbers`      | 显示固定在左侧且不可选择的逻辑行号栏。                  |
| `Wrap`             | 对长行换行，而不是启用横向滚动。                        |
| `GutterBackground` | 覆盖行号栏背景色。                                      |
| `GutterColor`      | 覆盖行号前景色。                                        |
| `SyntaxTheme`      | 覆盖八种共享 Tree-sitter 捕获颜色。                     |
| `Props.Style`      | 设置保留式代码块元素的尺寸和样式。                      |

<Note>
  CodeBlock 可选择，但没有输入监听器、插入光标、IME 状态、撤销栈或焦点环。需要用户修改源码时请使用
  Editor。
</Note>
