组件是返回元素的普通 Go 函数。从 `View`、`Text` 和 `Button` 等基础组件开始，再组合侧栏中具备无障碍支持的控件。

## 定义组件

组件返回 `*ui.Element`。传入普通类型的参数和子节点。在调用处读取信号，例如 `CounterLabel(count())`，会让该参数保持同步。

```go
func CounterLabel(count int) *ui.Element {
	return ui.Text("Count: ", count).FontSize(20)
}

func ComponentExample() *ui.Element {
	count, setCount := ui.CreateSignal(0)
	return ui.View().Children(
		CounterLabel(count()),
		ui.Button("Increment").OnClick(func() { setCount(count() + 1) }),
	)
}
```

结构体参数的工作方式相同。更新 `quantity` 会改变绑定的文本，而 `LineItem` 保持挂载。

```go
type Product struct {
	ID    string
	Name  string
	Price int
}

func LineItem(product Product, quantity int) *ui.Element {
	return ui.Text(product.Name, " × ", quantity, " = $", product.Price*quantity)
}

func Cart() *ui.Element {
	quantity, setQuantity := ui.CreateSignal(1)
	return ui.View().Children(
		LineItem(Product{ID: "mug", Name: "Mug", Price: 12}, quantity()),
		ui.Button("Add one").OnClick(func() { setQuantity(quantity() + 1) }),
	)
}
```

用 `ui.View()` 和 `.Child(...)` 或 `.Children(...)` 构建容器。子节点回调是可选的：需要等到父节点就绪后再构建时再使用，例如在复合控件内部。

```go
func CardComponent(title string, children ...any) *ui.Element {
	return ui.View().
		Padding(20).
		Gap(12).
		FlexCol().
		Child(ui.Text(title).FontWeight(600)).
		Children(children...)
}

func CardComposition() *ui.Element {
	return CardComponent(
		"Account",
		ui.Text("Manage your account settings."),
		ui.Button("Save").OnClick(func() { log.Print("Saved") }),
	)
}
```

## 基础组件

从 `ui.View`、`ui.Text`、`ui.Button` 和 `ui.Input` 开始。在返回的元素上链式设置样式、属性和处理函数。

```go
func ButtonExample(save func()) *ui.Element {
	return ui.Button("Save changes").
		Height(40).
		PaddingLeft(16).
		PaddingRight(16).
		BackgroundColor("#2563eb").
		TextColor("white").
		BorderRadius(8).
		Hover(func(s ui.StyleBuilder) ui.StyleBuilder { return s.BackgroundColor("#3b82f6") }).
		OnClick(save)
}
```

## 复合组件

诸如标签页之类的组件族会暴露部件：`ui.Tabs.Root`、`ui.Tabs.List`、`ui.Tabs.Tab` 和 `ui.Tabs.Panel`。在根节点的子节点回调中创建部件，以便共享焦点、键盘行为和选择状态。

```go
func TabsExample() *native.Node {
	return ui.Tabs.Root(
		ui.TabsRootProps{DefaultValue: "overview", Activation: "automatic"},
		func() *native.Node {
			return ui.Fragment([]*native.Node{
				ui.Tabs.List(ui.PartProps{}, func() *native.Node {
					return ui.Fragment([]*native.Node{
						ui.Tabs.Tab(ui.TabsTabProps{Value: "overview"}, "Overview"),
						ui.Tabs.Tab(ui.TabsTabProps{Value: "settings"}, "Settings"),
					})
				}),
				ui.Tabs.Panel(ui.TabsPanelProps{Value: "overview"}, "Overview content"),
				ui.Tabs.Panel(ui.TabsPanelProps{Value: "settings"}, "Settings content"),
			})
		},
	)
}
```

## 受控状态

传入当前值的访问器，并在变更回调中保存下一个值。省略值并设置默认值时，控件会自行管理状态。可选标量使用指针；多选用切片。

```go
func CheckboxExample() *native.Node {
	checked, setChecked := ui.CreateSignal(false)
	return ui.Checkbox.Root(
		ui.CheckboxProps{
			Checked:         func() ui.CheckedState { return checked() },
			OnCheckedChange: func(next bool, _ *native.Event) { setChecked(next) },
		},
		func() *native.Node {
			return ui.Fragment([]*native.Node{
				ui.Checkbox.Indicator(ui.PartProps{}, "✓"),
				ui.Text("Remember me").Node,
			})
		},
	)
}
```

## 设置各部件的样式

在每个部件上设置 `PartProps.Style`。用 `ui.Style()` 和链式方法构建样式，并用 `.Merge(...)` 组合它们。

```go
ui.PartProps{
	Style: ui.Style().
		Display("flex").
		Height(32).
		PaddingLeft(12).
		PaddingRight(12).
		BackgroundColor("#2563eb").
		TextColor("white").
		BorderRadius(8),
}
```

选择状态和主题信号会就地更新部件。共享构建器见[样式与布局](/docs/go/styling)。
