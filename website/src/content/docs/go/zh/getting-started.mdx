这些指南使用 Go 前端。可在侧栏中选择使用 Solid 2 JSX 的 TypeScript 前端。

QuickGUI 应用是普通的 Go 程序。用 Go 编写组件和细粒度响应式状态，并以 `CGO_ENABLED=0` 构建。purego 在同一进程中加载预编译原生库；Bun 仅运行开发与打包 CLI。

## 系统要求

- macOS 14 或更新版本
- Go 1.23 或更新版本
- Bun 1.3 或更新版本
- Xcode Command Line Tools（`xcode-select --install`）

当前打包的 UI 应用面向 macOS。普通应用构建直接使用预编译原生宿主。

## 创建项目

CLI 尚未发布。请从 [QuickGUI 源码仓库](https://github.com/egoist/quickgui)运行 Go 计数器：

```bash
bun install
bun packages/cli/src/cli.ts dev --project examples/counter
```

若要创建独立应用，生成项目时跳过安装注册表依赖：

```bash
bun packages/cli/src/cli.ts init ../my-app --no-install
cd ../my-app
go mod edit -replace github.com/egoist/quickgui/go=../quickgui/go
go mod tidy
```

在语言选择提示中选择 **Go**。在生成的 `quickgui.config.ts` 中，将 `defineConfig` 导入路径改为 `../quickgui/packages/cli/src/index.ts` 以使用本地 CLI。然后在 QuickGUI 源码目录运行 `bun packages/cli/src/cli.ts dev --project ../my-app`。给 `init` 传入 `--language go` 可跳过语言选择。

## 第一个窗口

生成的 `main.go` 从 `native` 导入窗口 API，从 `ui` 导入组件。将组件函数直接传给 `WindowOptions.Component`。调用一次 `native.Run` 启动应用事件循环。

```go
package main

import (
	"github.com/egoist/quickgui/go/native"
	"github.com/egoist/quickgui/go/ui"
	"log"
)

func Counter() *ui.Element {
	count, setCount := ui.CreateSignal(0)
	return ui.View(
		ui.Text("Fine-grained native UI").FontSize(28).FontWeight(700),
		ui.Text("Count: ", count()),
		ui.Button("Increment").
			OnClick(func() { setCount(count() + 1) }).
			Padding(12).
			RoundedLg().
			Bg("#2563eb").
			Hover(func(s ui.StyleBuilder) ui.StyleBuilder { return s.BackgroundColor("#3b82f6") }),
	).FlexCol().
		SizeFull().
		ItemsCenter().
		JustifyCenter().
		Gap(20).
		Bg("#090d16").
		TextColor("#e2e8f0")
}

func main() {
	if err := native.Run(func() {
		open := func() {
			native.NewWindow(native.WindowOptions{
				Title:     "My App",
				Width:     720,
				Height:    480,
				Component: Counter,
			})
		}
		native.App.OnReopen(func(event native.ReopenEvent) {
			if !event.HasVisibleWindows {
				open()
			}
		})
		open()
	}); err != nil {
		log.Fatal(err)
	}
}
```

## 运行与构建

监视器会重新构建 Go 源码并重启开发应用。格式化命令为较长的组件调用添加一致的换行，输出仍是标准 Go 语法。生产构建输出到 `dist/darwin-*`。

```bash
bun packages/cli/src/cli.ts dev --project ../my-app
bun packages/cli/src/cli.ts fmt --project ../my-app
bun packages/cli/src/cli.ts build --project ../my-app
```
