QuickGUI 应用是普通的 Go 程序。用 Go 编写窗口和组件，再由 CLI 运行、热重载，并打包为原生 macOS 应用。

## 系统要求

- macOS 14 或更新版本
- Go 1.23 或更新版本
- Bun 1.4 或更新版本
- Xcode Command Line Tools（`xcode-select --install`）

当前打包的应用面向 macOS。

## 创建项目

```bash
bunx @quickgui/cli init my-app --language go
cd my-app
bun run dev
```

CLI 会创建 Go 模块、安装依赖并打开应用。省略 `--language go` 可在交互式提示中选择语言。

## 第一个窗口

生成的 `main.go` 会启动应用、打开窗口并渲染组件。将组件函数传给 `WindowOptions.Component`。在 `main` 中只调用一次 `native.Run`。

```go
package main

import (
	"log"

	"github.com/egoist/quickgui/go/native"
	"github.com/egoist/quickgui/go/ui"
)

func Counter() *ui.Element {
	count, setCount := ui.CreateSignal(0)
	return ui.View().
		FlexCol().
		SizeFull().
		ItemsCenter().
		JustifyCenter().
		Gap(20).
		Bg("#090d16").
		TextColor("#e2e8f0").
		Child(ui.Text("Fine-grained native UI").FontSize(28).FontWeight(700)).
		Child(ui.Text("Count: ", count())).
		Child(ui.Button().
			OnClick(func() { setCount(count() + 1) }).
			Padding(12).
			RoundedLg().
			Bg("#2563eb").
			Hover(func(s ui.StyleBuilder) ui.StyleBuilder { return s.BackgroundColor("#3b82f6") }).
			Child("Increment"))
}

func main() {
	if err := native.Run(func() {
		open := func() {
			native.NewWindow(native.WindowOptions{
				Title:     "My App",
				Width:     720,
				Height:    480,
				Component: Counter,
			})
		}
		native.App.OnReopen(func(event native.ReopenEvent) {
			if !event.HasVisibleWindows {
				open()
			}
		})
		open()
	}); err != nil {
		log.Fatal(err)
	}
}
```

在标签中读取 `count()` 会让该文本保持同步。点击按钮会更新信号，窗口的其余部分保持不变。

## 运行与构建

在项目目录中执行：

```bash
bun run dev
bun run fmt
bun run build
```

`dev` 会在你编辑时重新构建并重启。`fmt` 格式化 Go 源码。`build` 将打包后的应用写入 `dist/`。
