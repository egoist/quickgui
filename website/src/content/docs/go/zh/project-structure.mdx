生成的项目是一个 Go 模块，外加一个用于开发命令的小型 Bun 包。

## 生成的文件

```text
my-app/
├── main.go
├── go.mod
├── go.sum
├── quickgui.config.ts
├── package.json
└── README.md
```

首次成功执行 `go mod tidy` 后请提交 `go.sum`。较大的应用可拆分为普通 Go 包。

## 应用入口

`main.go` 调用 `native.Run`，并在该回调中打开窗口。组件是返回 `*ui.Element` 的函数。返回你构建的元素，或将其作为子节点传入。

```go
func ViewExample() *ui.Element {
	return ui.View().
		Padding(20).
		Gap(12).
		Child(ui.Text("Hello from Go")).
		Child(ui.Button("Continue").OnClick(func() {}))
}
```

## 配置

`entry` 是要构建的 Go 包。配置文件仅供 CLI 使用。

```ts
import { defineConfig } from "@quickgui/cli";

export default defineConfig({
  language: "go",
  name: "My App",
  identifier: "com.example.my-app",
  entry: ".",
});
```

`quickgui.toml` 接受相同的设置：

```toml
name = "My App"
identifier = "com.example.my-app"
entry = "."
```

CLI 先读取 `quickgui.toml`，再读取 `quickgui.config.ts`。传入 `--config configs/dev.toml` 可指定文件。请为版本号加引号，例如 `version = "0.1.0"`。相对路径以项目目录为基准，`dev` 会重新加载配置修改。

## 软件包

| 软件包 | 用途 |
| --- | --- |
| `github.com/egoist/quickgui/go/native` | 窗口、菜单、对话框及其他平台 API |
| `github.com/egoist/quickgui/go/ui` | 组件、信号和样式 |
| `github.com/egoist/quickgui/go/reactive` | 较大应用中的所有者和上下文 |
| `@quickgui/cli` | `dev`、`fmt` 和 `build` |

要共享组件或添加原生服务，请参阅[编写扩展](/docs/go/extensions)。

## 本地开发

```bash
bun run dev
bun run fmt
bun run build
```

`go mod tidy` 安装 Go 依赖。开发应用不需要 C 编译器。
