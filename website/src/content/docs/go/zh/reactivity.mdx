信号保存 UI 读取的值。信号变化时，只有读取它的文本和属性会更新。

## 响应式状态

用 `ui.CreateSignal` 创建信号。在文本和样式方法中读取它，例如 `ui.Text("Count: ", count())` 和 `.Width(width())`。在初始化时读取，例如 `initial := count()`，只是快照，之后不会更新。

自定义组件接受普通 Go 值。把 `count()` 传入 `LineItem(product, count())` 会让该参数保持实时更新。

也可以把字符串或数字信号作为子节点传入：`ui.Text("Count: ", count)`。前缀保持不变，只有数字会更新。

```go
func TextExample() *ui.Element {
	count, setCount := ui.CreateSignal(0)
	return ui.View().Children(
		ui.Text("Count: ", count()).FontSize(20),
		ui.Button("Increment").OnClick(func() { setCount(count() + 1) }),
	)
}
```

事件处理函数已经会合并写入。从其他 UI 代码批量写入时使用 `ui.Batch`。

## 派生状态

`ui.CreateMemo` 根据其他信号计算值。读取该 memo 的方式与读取信号相同。

```go
func DerivedExample() *ui.Element {
	count, setCount := ui.CreateSignal(0)
	doubled := ui.CreateMemo(func() int { return count() * 2 })
	return ui.View().Children(
		ui.Text("Doubled: ", doubled()),
		ui.Button("Increment").OnClick(func() { setCount(count() + 1) }),
	)
}
```

## 副作用与清理

使用 `ui.CreateEffect` 处理视图之外的工作，例如订阅或窗口标题。副作用会先运行一次，之后在它读过的值变化时再次运行。用 `ui.OnCleanup` 注册清理函数；它会在下一次副作用之前以及组件消失时运行。

直接绑定会变化的文本和属性。不要在副作用中重建视图。

```go
func EffectExample() *ui.Element {
	topic, setTopic := ui.CreateSignal("Inbox")
	ui.CreateEffect(func() {
		current := topic()
		log.Print("Subscribe: ", current)
		ui.OnCleanup(func() { log.Print("Unsubscribe: ", current) })
	})
	return ui.View().Children(
		ui.Text("Watching: ", topic()),
		ui.Button("Switch topic").OnClick(func() {
			if topic() == "Inbox" {
				setTopic("Archive")
			} else {
				setTopic("Inbox")
			}
		}),
	)
}
```

捕获该次运行的值，让清理逻辑引用上一个主题。

## 批量更新

按钮点击和其他事件处理函数会自动批处理写入。在其他位置把相关写入包在 `ui.Batch` 中，让观察者看到一次结果。`ui.Untrack` 读取值但不订阅。

在 UI goroutine 上读写信号。用 `ui.Async` 或 `native.Dispatch` 送回后台结果。

```go
func BatchedExample() *ui.Element {
	first, setFirst := ui.CreateSignal("Ada")
	last, setLast := ui.CreateSignal("Lovelace")
	ui.CreateEffect(func() { log.Print(first() + " " + last()) })
	applyProfile := func() {
		ui.Batch(func() {
			setFirst("Grace")
			setLast("Hopper")
		})
	}
	return ui.View().Children(
		ui.Text(first(), " ", last()),
		ui.Button("Apply profile").OnClick(applyProfile),
	)
}
```

这次批处理之后，观察者会看到 “Grace Hopper”，而不是中间名字。批处理是同步的：先完成后台工作，再写入信号。
