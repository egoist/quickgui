从 `main` 调用一次 `native.Run`。其启动回调打开窗口并注册应用级行为。完成回调和 UI 更新在 UI goroutine 上运行。

## 窗口生命周期

`native.NewWindow(native.WindowOptions{Component: App})` 打开一个拥有独立组件树的窗口。关闭窗口会释放该树。如果后续工作需要窗口，请在构建组件或处理事件时捕获 `native.CurrentWindow()`。

在 macOS 上处理 Dock 重新打开：如果没有可见窗口，就打开一个。

## 命令与服务

对话框、剪贴板、Shell、外观、菜单及其他平台功能请使用带类型的 `native` API。返回结果的调用接受完成回调；在回调中处理错误，不要阻塞 UI。

组件中的后台工作使用 `ui.Async`。要从其他 goroutine 送回结果，使用 `native.Dispatch`。只在 UI goroutine 上读写信号。

独立的原生服务使用 `native.InvokeExtension` 和 `native.OpenExtension`。参见[编写扩展](/docs/go/extensions)。

## 事件与文件监听

`native.WatchFiles(paths, changed, ready)` 监听文件变化并返回停止函数。用 `ui.OnCleanup` 注册组件拥有的监听器。优先使用这些事件，而不是轮询。
