导入 `github.com/egoist/quickgui/extensions/updater` 即可包含自动更新。未导入的应用不会附带更新器。

## 配置

生成签名密钥对：

```sh
quickgui keygen --sparkle --out-dir /secure/my-app-update-keys
```

不要把私钥 `.key` 提交到版本控制。把 `.pub` 的内容复制到配置中：

```toml
[updates]
baseUrl = "https://downloads.example.com/my-app"
publicKey = "BASE64_PUBLIC_KEY_FROM_THE_PUB_FILE"
automaticChecks = true
feedUrl = "https://downloads.example.com/my-app/appcast-{target}.xml"
notesFile = "RELEASE_NOTES.md"
```

`{target}` 会展开为 `darwin-arm64` 这类值。发行说明是可选的纯文本，最多 16 KiB。

CLI 会嵌入版本、标识符、feed URL 和公钥。密钥绝不会被嵌入。App Store 和沙盒构建应用 Go 构建标签排除更新器导入。

## 应用用法

在 `native.Run` 就绪之后、组件之外启动。整个应用共用一个更新器。

```go
import (
	"log"

	"github.com/egoist/quickgui/go/native"
	"github.com/egoist/quickgui/extensions/updater"
)

var updates *updater.Updater

func startUpdater() {
	updates = updater.Start(updater.Options{}, func(event updater.Event) {
		if event.Error != "" {
			log.Print(event.Error)
		}
		if event.QuitRequired {
			native.App.Quit(false, nil)
		}
	}, func(err error) {
		if err != nil {
			log.Print(err)
		}
	})
}
```

从「检查更新」菜单项调用 `updates.Check(done)`，从可用更新横幅调用 `updates.Install(done)`，从设置调用 `updates.SetAutomaticChecks(enabled, done)`。回调在 UI 协程上运行。`State()` 返回最近一次事件。

`Options` 可以覆盖 feed URL 和公钥。开发构建默认禁用。只在测试 feed 和可丢弃的应用包上使用 `AllowDevelopment: true`。

## 生命周期

`Event.Status` 为 `idle`、`checking`、`available`、`downloading`、`installing` 或 `disabled`。事件包含版本、说明、进度、自动检查偏好，以及可选错误。

在 macOS 上，Sparkle 负责下载、校验、安装和重新启动。手动检查可以显示 Sparkle 的标准界面；定时检查可以把结果提供给应用内横幅。

Windows 和 Linux 在启用自动检查时，启动时检查一次。`QuitRequired` 表示助手正在等待应用退出。保存工作后调用 `native.App.Quit(false, nil)`。如果退出被取消，助手会超时并保留当前应用。

## 平台支持

| 平台 | 更新包 | 安装方式 |
| --- | --- | --- |
| macOS | 包含已签名 `.app` 的 ZIP | Sparkle，仅随更新器一起提供 |
| Windows | NSIS `.exe` 安装程序 | 助手等待退出，静默运行已校验的安装程序，然后重新启动 |
| Linux | Type-2 `.AppImage` | 助手等待退出并替换用户拥有的 AppImage |

Linux `.deb` 包、系统二进制文件以及 root 拥有的安装会报告 `disabled`。这些情况请使用平台包管理器。

Feed 是带 Ed25519 签名的 HTTPS Sparkle RSS appcast。没有未签名的回退。

## 发布更新

把私钥放在 `QUICKGUI_UPDATER_PRIVATE_KEY`（或 `SPARKLE_PRIVATE_KEY`）中。也可以用 `updates.ed25519SecretKey` 指向本地密钥文件。

```sh
quickgui build --update-manifest
```

CLI 会签名产物并写入 `appcast-<target>.xml`。先上传带版本的产物，再替换 feed。每种架构有自己的 feed。`updates.manifest = true` 会在每次生产构建时生成 feed。

macOS 归档应包含经过 Developer ID 签名并公证的应用。Windows 需要 `makensis`。Linux 需要 `appimagetool`。

## 原生产物

在本仓库中，用 `bun packages/native/build.ts --extension updater` 构建一次更新器。打包应用在存在 Go 导入时会自动包含更新器。

见[更新器示例](https://github.com/egoist/quickgui/tree/main/examples/updater)。Sparkle 文档涵盖 appcast 细节：[Sparkle](https://sparkle-project.org/documentation/)。
