窗口内 UI 使用 QuickGUI 浮层，文件选择和警告使用系统对话框。

## Popover

Popover 由触发器、定位器和弹出层组成。请求的方向是偏好值；碰撞会自动解决。在根内用 `ui.UsePopoverPlacement` 读取结果。

```go
func PopoverExample() *native.Node {
	return ui.Popover.Root(
		ui.PopoverRootProps{},
		func() *native.Node {
			return ui.Fragment([]*native.Node{
				ui.Popover.Trigger(ui.PopoverTriggerProps{}, "Account"),
				ui.Popover.Positioner(
					ui.PopoverPositionerProps{},
					func() *native.Node {
						return ui.Popover.Popup(
							ui.PopoverPopupProps{PartProps: ui.PartProps{Style: ui.Style().
								Width(240).
								Padding(16)}},
							func() *native.Node {
								return ui.Fragment([]*native.Node{
									ui.Popover.Title(ui.PartProps{}, "Account"),
									ui.Popover.Close(ui.PartProps{}, "Done"),
								})
							},
						)
					},
				),
			})
		},
	)
}
```

## Dialog

把模态内容放在 `Dialog.Portal` 下。`Dialog.Title` 和 `Dialog.Description` 为对话框提供无障碍名称。`AlertDialog` 用于确认。受控根会收到下一个打开状态以及变化原因。

```go
func DialogExample() *native.Node {
	return ui.Dialog.Root(
		ui.DialogRootProps{},
		func() *native.Node {
			return ui.Fragment([]*native.Node{
				ui.Dialog.Trigger(ui.PartProps{}, "Open dialog"),
				ui.Dialog.Portal(
					ui.PartProps{},
					func() *native.Node {
						return ui.Fragment([]*native.Node{
							ui.Dialog.Backdrop(ui.PartProps{}),
							ui.Dialog.Viewport(
								ui.PartProps{},
								func() *native.Node {
									return ui.Dialog.Popup(
										ui.DialogPopupProps{},
										func() *native.Node {
											return ui.Fragment([]*native.Node{
												ui.Dialog.Title(ui.PartProps{}, "Confirm action"),
												ui.Dialog.Description(
													ui.PartProps{},
													"Review the details before continuing.",
												),
												ui.Dialog.Close(ui.PartProps{}, "Cancel"),
											})
										},
									)
								},
							),
						})
					},
				),
			})
		},
	)
}
```

## 系统浮窗

`ui.SystemPopover` 在操作系统面板中显示其内容。设置逻辑宽高，然后声明普通 QuickGUI 子节点。

```go
func SystemPopoverExample() *native.Node {
	return ui.SystemPopover.Root(
		ui.PopoverRootProps{},
		func() *native.Node {
			return ui.Fragment([]*native.Node{
				ui.SystemPopover.Trigger(ui.PopoverTriggerProps{}, "Account"),
				ui.SystemPopover.Content(
					ui.PopoverContentProps{
						Width:     240,
						Height:    120,
						Placement: "bottom-start",
					},
					"Account settings",
				),
			})
		},
	)
}
```

## 原生对话框

系统文件对话框异步完成。在渲染时捕获父窗口，并将其传给请求。取消的面板返回 `Canceled: true`。

```go
func OpenFolderButton() *ui.Element {
	window := native.CurrentWindow()
	return ui.Button("Open folder").OnClick(func() {
		native.ShowOpenDialog(
			native.OpenDialogOptions{
				Window:     window,
				Title:      "Open folder",
				Properties: []string{"openDirectory"},
			},
			func(result native.OpenDialogResult, err error) {
				if err == nil && !result.Canceled {
					fmt.Println(result.FilePaths)
				}
			},
		)
	})
}
```
