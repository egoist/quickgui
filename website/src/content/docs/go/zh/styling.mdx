用 `.P4()`、`.MxAuto()`、`.GridCols(3)`、`.RoundedLg()` 等链式方法设置元素样式。用 `.Style(shared)` 应用共享构建器。

```go
return ui.View().
	FlexCol().
	PaddingLeft(20).
	RoundedLg().
	TextAlign("center").
	Child(ui.Text("hello")).
	Child(ui.Input().Value("xxx"))
```

## 样式方法

声明按顺序应用。同一属性以后面的值为准，包括显式的零值。数值长度是逻辑像素。字符串也可以是百分比。

```go
func Card() *ui.Element {
	return ui.View().
		Padding(20).
		BorderRadius(12).
		Bg("#111827").
		Child(ui.Text("Hello").TextColor("#e2e8f0"))
}
```

## 合并样式

`.Style(base).Style(overrides)` 按顺序合并。用 `.Merge(...)` 组合可复用的构建器。重复的悬停和其他交互状态也以同样方式合并。

```go
func MergedCard() *ui.Element {
	base := ui.Style().Padding(20).BorderRadius(8).Bg("#111827")
	overrides := ui.Style().BorderRadius(12)
	return ui.View().Child("Merged styles").Style(base).Style(overrides)
}
```

## 复用样式

`ui.Style()` 返回 `ui.StyleBuilder`。每个方法都返回新的构建器，因此共享样式不会被修改。派生变体时请保存返回值。通过 `.Style(...)` 或部件的 `PartProps.Style` 字段应用它。

```go
func SharedCard() *native.Node {
	card := ui.Style().Padding(20).BorderRadius(12)
	emphasized := card.PaddingLeft(28).Bg("#1e293b")
	return ui.Fragment([]*native.Node{
		ui.View().Child("Hello").Style(card).Bg("#111827").Node,
		ui.View().Child("Another card").Style(emphasized).Node,
	})
}
```

`.When(condition, func(s ui.StyleBuilder) ui.StyleBuilder { ... })` 根据布尔值派生构建器。对于会变化的值，使用元素的 `.When(getter, style)`，或在访问器中构建样式。传入 `.Width(width)` 会保持实时更新；在初始化时调用 `width()` 会捕获当前值。

## Flexbox

使用 `.Flex()`、`.FlexRow()` 或 `.FlexCol()`。给可滚动的弹性子节点设置 `.MinHeight(0)` 或 `.MinWidth(0)`，以便它们能够收缩。

```go
func Row() *ui.Element {
	return ui.View().
		Flex().
		Gap(12).
		ItemsCenter().
		Child(ui.Text("Flexible content").Flex1().MinWidth(0)).
		Child(ui.Button("Action").FlexShrink(0))
}
```

## 网格布局

设置 `Display("grid")` 以及 `GridTemplateColumns("220px 1fr")` 这样的轨道列表。

```go
func Grid() *ui.Element {
	return ui.View().
		Display("grid").
		GridTemplateColumns("220px 1fr").
		Gap(16).
		Child(ui.Text("Sidebar")).
		Child(ui.Text("Content"))
}
```

## 文本与颜色

排版沿树向下继承。颜色接受十六进制、`rgb()` / `rgba()`，或打包的 RGBA 值。只覆盖子节点中不同的属性。内边距和边框不会继承。

```go
func TypographyExample() *ui.Element {
	return ui.View().
		TextColor("#334155").
		FontSize(14).
		Padding(20).
		Child(ui.Text("Inbox").FontSize(24).FontWeight(600)).
		Child(ui.Text("All caught up."))
}
```

## 交互状态

用 `.Hover(...)`、`.Active(...)`、`.FocusStyle(...)`、`.DisabledStyle(...)` 和 `.SelectedStyle(...)` 处理指针、键盘和选择状态。在基础样式上添加 `.Transition(...)` 可为颜色和不透明度添加动画；参见[过渡与动画](/docs/go/animations)。

```go
func SelectableButton() *ui.Element {
	selected, setSelected := ui.CreateSignal(false)
	button := ui.Style().Padding(12).Bg("#e5e7eb").
		Hover(func(s ui.StyleBuilder) ui.StyleBuilder { return s.Opacity(0.85) })
	return ui.Button("Toggle selection").Style(button).
		When(selected(), ui.Style().Bg("#2563eb").TextColor("white")).
		OnClick(func() { setSelected(!selected()) })
}
```

## 分组与具名分组悬停

`.Group(true)` 标记未命名分组；`.Group("card")` 为其命名。`.GroupHover(...)` 跟随最近的祖先分组。`.GroupHoverNamed("card", ...)` 跟随最近的同名祖先。重叠属性上，节点自身的悬停样式优先。

```go
func GroupExample() *ui.Element {
	return ui.View().
		Group("card").
		Padding(20).
		Child(
			ui.Text("Changes when the card is hovered").
				TextColor("#64748b").
				GroupHoverNamed("card", func(s ui.StyleBuilder) ui.StyleBuilder {
					return s.TextColor("#2563eb")
				}),
		)
}
```

`.GroupActive(...)` 和 `.GroupActiveNamed(...)` 跟随按下的分组。`.FocusWithin(...)` 跟随节点或其后代中的焦点。这些状态接受绘制属性，但不能设置光标。
