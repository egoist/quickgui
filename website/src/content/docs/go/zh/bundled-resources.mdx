用 `resources` 打包未编译进可执行文件的文件：图像、模板、JSON 和其他数据。CLI 按基本名称把每个路径复制进应用包。运行中的应用从资源目录读取它们，不依赖启动时的工作目录。

自定义字体是单独的选项。见[字体](#fonts)。

## 配置

```ts
import { defineConfig } from "@quickgui/cli";

export default defineConfig({
  name: "My App",
  identifier: "com.example.my-app",
  entry: ".",
  resources: ["assets", "copy/template.txt"],
  fonts: ["assets/MyFont.ttf"],
});
```

每一项都是文件或目录。相对路径相对项目目录解析。目标名称必须唯一，且不能覆盖 `fonts`、`AppIcon.icns`、`quickgui.json` 或宿主共享库等保留名。

`quickgui dev` 和 `quickgui build` 都会暂存这些文件。路径不存在时构建失败。

## 安装位置

| 平台 | 资源目录 |
| --- | --- |
| macOS `.app` | `Contents/Resources` |
| Linux AppDir、AppImage 和 `.deb` | 可执行文件旁边（`usr/bin`） |
| Windows 安装程序 | `$INSTDIR` 里可执行文件旁边 |

配置的路径 `assets` 会安装为该目录下的 `assets/`。文件 `copy/template.txt` 会安装为 `template.txt`。运行时把这些名称拼到 `ResourceDir` 上；不要从项目树或当前工作目录读取。

## 读取文件

在 `native.Run` 就绪后向宿主查询路径，再拼接打包后的名称：

```go
import (
	"path/filepath"

	"github.com/egoist/quickgui/go/native"
	"github.com/egoist/quickgui/go/ui"
)

func App() *ui.Element {
	return ui.Image().Value(hero).Width(160).Height(120)
}

var hero string

func main() {
	native.Run(func() {
		native.App.GetPaths(func(paths *native.AppPaths, err error) {
			if err != nil || paths == nil {
				return
			}
			hero = filepath.Join(paths.ResourceDir, "assets", "hero.png")
			native.NewWindow(native.WindowOptions{
				Title:     "My App",
				Component: App,
			})
		})
	})
}
```

`ui.Image` 接受该文件系统路径。其他文件用同样的拼接：用 `os.ReadFile` 或你自己的加载器打开。相对图像路径不会相对资源目录解析。

## 字体

`fonts` 列出 OpenType 文件。CLI 把它们复制到资源目录中的 `fonts/`，并在打开第一个窗口之前注册。

```ts
export default defineConfig({
  name: "My App",
  identifier: "com.example.my-app",
  entry: ".",
  fonts: ["assets/MyFont.ttf"],
});
```

在样式里使用字体家族名。字体不能代替 `resources`：图像或 JSON 文件仍应放在 `resources` 中。
