用 `ui.Style().Transition(...)` 为样式变化添加动画。组件不会为每一帧重新运行。

## 悬停过渡

把过渡放在基础样式上，这样指针移入和移出时都会运行。同一声明也适用于 `Active`、`Focus`、`Expanded` 和 `DragOver`。

```go
func HoverAction() *ui.Element {
	return ui.Button("Continue").
		Padding(12).
		BorderRadius(8).
		BackgroundColor("#334155").
		TextColor("white").
		Opacity(0.85).
		Transition("background-color 160ms ease-out, opacity 160ms ease-out").
		Hover(func(s ui.StyleBuilder) ui.StyleBuilder { return s.BackgroundColor("#2563eb").Opacity(1) })
}
```

## 状态驱动的动画

用信号或 `ui.When` 改变目标。下面的卡片在颜色和不透明度动画时保持相同的子节点。

```go
func AnimatedSelection() *ui.Element {
	selected, setSelected := ui.CreateSignal(false)
	return ui.View().
		Display("flex").
		FlexDirection("column").
		Gap(12).
		Child(ui.Button("Toggle emphasis").OnClick(func() { setSelected(!selected()) })).
		Child(
			ui.View().
				Padding(20).
				BorderRadius(12).
				BackgroundColor("#334155").
				TextColor("white").
				Opacity(0.6).
				Transition("background-color 180ms ease-out, opacity 180ms ease-out").
				When(selected, ui.Style().BackgroundColor("#2563eb"), ui.Style().Opacity(1)).
				Child("Your selection"),
		)
}
```

在过渡进行中更新目标会从当前可见值继续，反向时也是如此。

## 时长与帧率

多个属性共用一组时间设置时，使用 `ui.TransitionDeclaration`。

```go
func CappedTransition() *ui.Element {
	return ui.Button("Hover me").
		Padding(12).
		BackgroundColor("#334155").
		TextColor("white").
		Opacity(0.8).
		Transition(ui.TransitionDeclaration{
			Properties: []string{"background-color", "opacity"},
			Duration:   180 * time.Millisecond,
			Easing:     "ease-out",
			MaxFps:     30,
		}).
		Hover(func(s ui.StyleBuilder) ui.StyleBuilder { return s.BackgroundColor("#2563eb").Opacity(1) })
}
```

| 字段 | 用法 |
| --- | --- |
| `TransitionProperty(...)` | 由支持的名称组成的逗号分隔字符串或 `[]string`。 |
| `TransitionDuration(...)` | 毫秒数、`time.Duration`，或 `"180ms"` / `"0.18s"`。时长限制在 0–10 秒。 |
| `TransitionEasing(...)` | `"linear"`、`"ease"`、`"ease-in"`、`"ease-out"` 或 `"ease-in-out"`。`"ease"` 与 `"ease-in-out"` 相同。 |
| `TransitionTimingFunction(...)` | 与 `TransitionEasing` 相同。 |
| `TransitionMaxFps(...)` | 可选的帧率上限。省略则跟随显示器。 |

一个节点的所有选中属性共用一组时长、缓动和帧率上限。不支持延迟、`cubic-bezier()` 以及按属性设置不同时间。

`Transition(180 * time.Millisecond)` 会为背景、边框和文字颜色添加动画。使用 `"all"` 覆盖所有支持的绘制属性，或使用 `"none"` 清除简写。

## 支持的属性

| 过渡名称 | 样式方法 |
| --- | --- |
| `background-color` 或 `background` | `BackgroundColor(...)` 或纯色 `Background(...)` |
| `border-color` | `BorderColor(...)` |
| `border-width` | `BorderWidth(...)` 及各边宽度 |
| `border-radius` | `BorderRadius(...)` 及各角半径 |
| `color` | 继承的 `TextColor(...)` |
| `opacity` | `Opacity(...)` |
| `box-shadow` | `BoxShadow(...)` |
| `transform` | `Transform(...)`（translate、scale、rotate） |

宽度、高度、内边距和渐变不会插值。不支持的名称会被拒绝。

对于滑动的开关滑块，将 `Transform("translateX(20px)")` 过渡到 `"translateX(0px)"`。这样会移动绘制的控件，而不会改变相邻布局。

## 挂载与减少动态效果

过渡为已有节点上的变化添加动画。首次绘制会立即应用。改变目标时保持节点挂载。`ui.Show` 在条件为 false 时移除子节点，不会等待淡出。不透明度为 `0` 仍会占据布局，并可以接收输入。

对话框使用 `EnterDuration` 和 `ExitDuration` 控制打开和关闭的时机；参见 [Dialog](/docs/go/components/dialog)。

过渡遵循系统的「减少动态效果」设置。设置 `native.WindowOptions.ReduceMotion` 可为单个窗口覆盖它。

## 动态图像

把 GIF 或 WebP 路径传给 `ui.Image`。播放跟随文件，不需要定时器。

```go
func AnimatedImage(path string) *ui.Element {
	return ui.Image().Value(path).
		Width(96).Height(96).ObjectFit("contain")
}
```

路径必须能解析为文件，也可以传入 data URL。用 CLI 的 `resources` 选项打包资源。参见 [Image](/docs/go/components/image) 和[项目配置](/docs/go/project-structure#configuration)。
