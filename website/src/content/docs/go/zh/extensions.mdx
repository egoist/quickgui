将 UI 作为 Go 包共享；需要 QuickGUI 未附带的额外库时，再添加原生服务。

## 选择扩展类型

| 要添加的内容 | 分发内容 |
| --- | --- |
| 组件、主题或辅助函数 | Go 模块 |
| 原生服务或 SDK | Go 包加上原生库 |
| 基于该服务的 UI | 两者都要：服务和你的组件 |

现有 API 已够用时，从 Go 包开始。需要自定义 SDK 之类的能力时，再添加原生扩展。[自动更新](/docs/go/updater) 就是后者的例子。

使用者导入你的 Go 包。CLI 会找到其清单并附带匹配的原生库。

## 创建扩展项目

```sh
bunx @quickgui/cli init-extension my-components --type go
bunx @quickgui/cli init-extension my-service --type zig
bunx @quickgui/cli init-extension my-service --type rust
```

`--type go`（默认）会搭建可复用组件。`zig` 和 `rust` 会搭建带 Go 封装和演示应用的原生服务。

```sh
cd my-service
bun run dev
```

用 `--module github.com/acme/my-service` 设置 Go 模块路径，用 `--npm-package @acme/extension-my-service` 设置原生包。`--name` 覆盖由目录推导的服务名称。

`bun run build` 为当前机器编译原生库，输出到 `artifacts/lib/<target>/`。`bun run dev` 先构建一次，之后重载 Go 编辑。修改原生代码后请重启。纯 Go 扩展会跳过原生构建。

## 共享组件

依赖 QuickGUI Go 模块并导出组件函数：

```go
package notice

import "github.com/egoist/quickgui/go/ui"

func Notice(message func() string, styles ...ui.StyleBuilder) *ui.Element {
	return ui.Text(message()).
		Padding(12).
		BackgroundColor("#eff6ff").
		TextColor("#1e40af").
		BorderRadius(8).
		Style(ui.Style().Merge(styles...))
}
```

调用 `notice.Notice(message, ui.Style().Padding(16))`，或将结果作为子节点传入。用 Go 版本标签发布模块。使用者通过 `go get` 添加。

将可选的原生集成放在独立包中，这样只需要 UI 的应用不会把它们拉进来。由已挂载组件拥有的资源请使用 `ui.OnCleanup`。

## 组织原生扩展

将 Go 包与小型原生库配对。[`native-extension` 示例](https://github.com/egoist/quickgui/tree/main/examples/native-extension) 展示了这种布局：

```text
go.mod
echo/
  echo.go
  quickgui.extension.json
native/
  echo.c
artifacts/
  package.json
  lib/darwin-arm64/libquickgui_acme_echo.dylib
```

C、C++、Zig 和 Rust 都可以实现该服务，只要导出下文所述的 C 入口点。服务通过 JSON 与 Go 封装通信；它不会添加新的 UI 基础组件。

请让扩展的发布版本在清单、npm 包和 `RequireExtension` 调用中保持一致。

## 声明依赖

将 `quickgui.extension.json` 放在被导入的 Go 包旁边：

```json
{
  "schema": 1,
  "name": "acme-echo",
  "abi": 1,
  "package": "@acme/extension-echo",
  "version": "1.0.0",
  "library": "quickgui_acme_echo"
}
```

名称以小写字母开头，可以包含数字和连字符。`host` 为保留名称。`library` 字段为 `quickgui_` 加上将连字符换成下划线后的名称。

在包中注册依赖并封装调用：

```go
package echo

import (
	"encoding/json"

	"github.com/egoist/quickgui/go/host"
	"github.com/egoist/quickgui/go/native"
)

func init() {
	host.RequireExtension("acme-echo", "1.0.0")
}

func Send(message string, done func(string, error)) {
	native.InvokeExtension("acme-echo", "echo", message, func(raw string, err error) {
		var reply string
		if err == nil {
			err = json.Unmarshal([]byte(raw), &reply)
		}
		done(reply, err)
	})
}
```

不要在 `init` 中打开窗口或启动工作线程。在 `native.Run` 就绪后再调用操作。回复在 UI goroutine 上运行。

对于长期运行的服务，`native.OpenExtension(name, options, changed, ready)` 返回一个会话。需要 JSON 结果时使用 `session.Request`，只需成功或错误时使用 `session.Command`。所有者消失时关闭会话。

导入该包即足以让 CLI 打包它。清单和 `RequireExtension` 两者都需要。

## 实现原生接口

从原生库导出 `quickgui_extension_v1`。它返回一个描述符，包含名称、版本以及两个函数：`invoke` 和 `shutdown`。要保留请求字节时先复制它们，将耗时工作放到工作线程上，并用 JSON 回复。

常见请求：

| 请求 | 使用时机 |
| --- | --- |
| `echo` 等方法 | 一次性的 `InvokeExtension` |
| `start` | `OpenExtension` 打开了会话 |
| `send` 等命令 | 在该会话上执行工作 |
| `stop` | 会话正在关闭 |
| `shutdown` | 应用正在退出 |

每个请求只回复一次。关闭会话必须停止之后的事件。完整的一次性服务见 [C echo 示例](https://github.com/egoist/quickgui/blob/main/examples/native-extension/backend/echo.c)。

## 自动注册

应用启动时，每个已打包的扩展按名称和版本加载。导入你的包即完成选择。同名但版本冲突会导致启动失败。

## 构建与打包产物

为每个支持的操作系统和架构构建原生库，并放到 `artifacts/lib/<target>/` 下。目标目录为 `darwin-arm64`、`darwin-x64`、`linux-arm64`、`linux-x64`、`windows-arm64` 和 `windows-x64`。

将产物作为 npm 包发布：

```json
{
  "name": "@acme/extension-echo",
  "version": "1.0.0",
  "files": ["lib", "README.md"]
}
```

如果需要辅助可执行文件或其他文件，在清单的 `resources` 对象中为 `darwin`、`linux` 或 `windows` 列出它们的名称，并把这些文件放在库旁边。

## 测试与分发

用 `go get` 添加你的 Go 模块，导入该包，然后在使用者应用中运行 `bun run dev` 或 `bun run build`。本地原生二进制可将 `QUICKGUI_EXTENSION_DIR` 设为产物目录。

发布前：

- 未导入该包的应用不得包含它。
- 缺失的库或版本不匹配必须明确失败。
- 关闭会话或退出应用必须停止回调和工作线程。
- 打包 npm 归档，在全新应用中安装，并在每个要发布的目标上运行该应用。

最终用户收到的是打包后的应用。运行它不需要 Bun、Go 或原生工具链。
