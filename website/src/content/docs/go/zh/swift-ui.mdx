`ui.SwiftUI` 组件族在 QuickGUI 窗口中嵌入真正的 macOS 控件。普通 QuickGUI 组件不依赖它。

## Host

在 `ui.SwiftUI.Host` 内创建控件。Host 是原生视图边界，并可以根据内容自行确定尺寸。

```go
func SwiftUiHostExample() *native.Node {
	return ui.SwiftUI.Host(
		ui.SwiftUIHostProps{MatchContents: true},
		func() *native.Node {
			return ui.SwiftUI.Button(ui.SwiftUIButtonProps{Label: "Continue"})
		},
	)
}
```

## 原生控件

可用控件包括 Button、Slider、Toggle、ProgressView、Stepper、TextField、SecureField、Picker、SegmentedControl、DatePicker、ColorPicker 和 Gauge。它们看起来像当前 macOS 系统控件。

## 受控值

绑定访问器，并从变更回调保存值。SwiftUI 控件和 QuickGUI 节点可以共享同一个信号。DatePicker 使用以毫秒为单位的 Unix 时间戳。

```go
func SwiftUiToggleExample() *native.Node {
	on, setOn := ui.CreateSignal(true)
	return ui.SwiftUI.Host(
		ui.SwiftUIHostProps{MatchContents: true},
		func() *native.Node {
			return ui.SwiftUI.Toggle(ui.SwiftUIToggleProps{
				IsOn:         on,
				Label:        "Notifications",
				OnIsOnChange: func(next bool, _ *native.Event) { setOn(next) },
			})
		},
	)
}
```

## 尺寸

`MatchContents: true` 根据控件确定两个轴的尺寸。使用 `ui.SwiftUIMatchContents{Vertical: true}` 获取固有高度，并自行设置宽度。

```go
ui.SwiftUIHostProps{
	MatchContents: ui.SwiftUIMatchContents{Vertical: true},
	PartProps:     ui.PartProps{Style: ui.Style().Width(320)},
}
```

## 平台支持

SwiftUI 托管仅支持 macOS。外观可能随操作系统版本变化。样式、玻璃效果以及在 SwiftUI 中嵌入 QuickGUI 参见[修饰器与托管](/docs/go/swift-ui-hosting)。
