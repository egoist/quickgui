将字段值保存在信号中，并从回调写回已接受的变更。

## 文本输入

`ui.Input` 和 `ui.TextArea` 是原生文本编辑器。将 `Value` 绑定到当前字符串，并在 `OnInput` 中从 `event.Value` 更新它。`OnSubmit` 处理单行输入中的 Return。

```go
func InputExample() *ui.Element {
	value, setValue := ui.CreateSignal("")
	return ui.Input().
		Value(value()).
		Placeholder("Write here").
		OnInputEvent(func(event *native.Event) { setValue(event.Value) }).
		Width(320).Height(32)
}
```

## 字段

`Field.Root` 将标签、控件、描述和错误关联起来。从你的状态驱动 `Required`、`Invalid` 和 `ValidationMessage`。`ValidationMode` 和 `ValidationDebounceTime` 控制何时运行验证；规则由应用负责。

```go
func FieldExample() *native.Node {
	email, setEmail := ui.CreateSignal("")
	return ui.Field.Root(
		ui.FieldRootProps{
			Required: true,
			Filled:   func() bool { return email() != "" },
		},
		func() *native.Node {
			return ui.Fragment([]*native.Node{
				ui.Field.Label(ui.FieldLabelProps{}, "Email"),
				ui.Field.Control(ui.FieldControlProps{InputPartProps: ui.InputPartProps{
					Value:       email,
					Placeholder: "you@example.com",
					OnInput:     func(event *native.Event) { setEmail(event.Value) },
				}}),
				ui.Field.Description(ui.PartProps{}, "Used for receipts"),
				ui.Field.Error(ui.PartProps{}, "Enter a valid email address"),
			})
		},
	)
}
```

## 选项

复选框通过 `ui.CheckedState` 接受 `bool` 或 `ui.CheckedIndeterminate`。单选组保存一个值。复选框组和切换组可以保存多个值。只读与禁用是分开的。

```go
func CheckboxGroupExample() *native.Node {
	values, setValues := ui.CreateSignal([]string{"email"})
	return ui.CheckboxGroup.Root(
		ui.CheckboxGroupProps{
			AllValues:     []string{"email", "push"},
			Value:         values,
			OnValueChange: func(next []string, _ *native.Event) { setValues(next) },
		},
		func() *native.Node {
			return ui.Fragment([]*native.Node{
				ui.Checkbox.Root(ui.CheckboxProps{Parent: true}, "All notifications"),
				ui.Checkbox.Root(ui.CheckboxProps{Value: "email"}, "Email"),
				ui.Checkbox.Root(ui.CheckboxProps{Value: "push"}, "Push"),
			})
		},
	)
}
```

## 选择器

用 `PickerSourceProps.Items` 声明选项。Select 保存选中值。Combobox 增加文本过滤。Autocomplete 允许自由输入。多选选择器使用 `Values` 和 `OnValuesChange`。

```go
func SelectExample() *native.Node {
	value, setValue := ui.CreateSignal[*string](nil)
	return ui.Select.Root(
		ui.SelectRootProps{
			PickerSourceProps: ui.PickerSourceProps{Items: func() []ui.OptionDeclaration {
				return []ui.OptionDeclaration{{Value: "go", Label: "Go"}, {Value: "swift", Label: "Swift"}}
			}},
			Value:         value,
			OnValueChange: func(next *string, _ *native.Event) { setValue(next) },
		},
		func() *native.Node {
			return ui.Fragment([]*native.Node{
				ui.Select.Value(ui.PartProps{}),
				ui.Select.Icon(ui.PartProps{}, "▾"),
			})
		},
	)
}
```

## 事件

按钮接受 `ui.OnClick(func() { ... })`。需要 `*native.Event` 时使用 `ui.OnClickEvent`。复合组件回调传入类型化的值，并在相关时附带事件。信号写入应在 UI goroutine 上进行；后台工作使用 `ui.Async`。
