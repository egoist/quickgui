生成されるプロジェクトは Go モジュールと、開発コマンド用の小さな Bun パッケージです。

## 生成されるファイル

```text
my-app/
├── main.go
├── go.mod
├── go.sum
├── quickgui.config.ts
├── package.json
└── README.md
```

最初の `go mod tidy` が成功したら `go.sum` をコミットします。大きなアプリは通常の Go パッケージに分割してください。

## アプリケーションのエントリ

`main.go` は `native.Run` を呼び出し、そのコールバックからウィンドウを開きます。コンポーネントは `*ui.Element` を返す関数です。構築した要素を返すか、子として渡してください。

```go
func ViewExample() *ui.Element {
	return ui.View().
		Padding(20).
		Gap(12).
		Child(ui.Text("Hello from Go")).
		Child(ui.Button("Continue").OnClick(func() {}))
}
```

## 設定

`entry` はビルドする Go パッケージです。設定ファイルは CLI だけが使います。

```ts
import { defineConfig } from "@quickgui/cli";

export default defineConfig({
  language: "go",
  name: "My App",
  identifier: "com.example.my-app",
  entry: ".",
});
```

`quickgui.toml` でも同じ設定を書けます。

```toml
name = "My App"
identifier = "com.example.my-app"
entry = "."
```

CLI は `quickgui.config.ts` より先に `quickgui.toml` を読みます。ファイルを選ぶには `--config configs/dev.toml` を渡します。バージョンは引用符で囲みます（例: `version = "0.1.0"`）。相対パスはプロジェクトディレクトリから解決され、`dev` は設定の編集をリロードします。

## パッケージ

| パッケージ | 用途 |
| --- | --- |
| `github.com/egoist/quickgui/go/native` | ウィンドウ、メニュー、ダイアログなどのプラットフォーム API |
| `github.com/egoist/quickgui/go/ui` | コンポーネント、シグナル、スタイル |
| `github.com/egoist/quickgui/go/reactive` | 大きなアプリでのオーナーとコンテキスト |
| `@quickgui/cli` | `dev`、`fmt`、`build` |

コンポーネントの共有やネイティブサービスの追加は [拡張の作成](/docs/go/extensions) を参照してください。

## ローカル開発

```bash
bun run dev
bun run fmt
bun run build
```

`go mod tidy` が Go の依存関係をインストールします。アプリの作業に C コンパイラーは不要です。
