`ui.SwiftUI` ファミリーは、本物の macOS コントロールを QuickGUI ウィンドウに埋め込みます。通常の QuickGUI コンポーネントはこれなしでも動作します。

## Host

コントロールは `ui.SwiftUI.Host` の内側に作成します。ホストはネイティブビューの境界であり、内容から自身のサイズを決められます。

```go
func SwiftUiHostExample() *native.Node {
	return ui.SwiftUI.Host(
		ui.SwiftUIHostProps{MatchContents: true},
		func() *native.Node {
			return ui.SwiftUI.Button(ui.SwiftUIButtonProps{Label: "Continue"})
		},
	)
}
```

## ネイティブコントロール

Button、Slider、Toggle、ProgressView、Stepper、TextField、SecureField、Picker、SegmentedControl、DatePicker、ColorPicker、Gauge が利用できます。見た目は現在の macOS システムコントロールと同じです。

## 制御値

アクセサーを結び付け、変更コールバックから値を保存します。SwiftUI コントロールと QuickGUI ノードは同じシグナルを共有できます。DatePicker はミリ秒単位の Unix タイムスタンプを使います。

```go
func SwiftUiToggleExample() *native.Node {
	on, setOn := ui.CreateSignal(true)
	return ui.SwiftUI.Host(
		ui.SwiftUIHostProps{MatchContents: true},
		func() *native.Node {
			return ui.SwiftUI.Toggle(ui.SwiftUIToggleProps{
				IsOn:         on,
				Label:        "Notifications",
				OnIsOnChange: func(next bool, _ *native.Event) { setOn(next) },
			})
		},
	)
}
```

## サイズ

`MatchContents: true` は両軸をコントロールからサイズします。固有の高さだけにする場合は `ui.SwiftUIMatchContents{Vertical: true}` を使い、幅は自分で設定します。

```go
ui.SwiftUIHostProps{
	MatchContents: ui.SwiftUIMatchContents{Vertical: true},
	PartProps:     ui.PartProps{Style: ui.Style().Width(320)},
}
```

## 対応プラットフォーム

SwiftUI のホスティングは macOS 専用です。見た目は OS のバージョンによって変わることがあります。スタイル、ガラス、SwiftUI 内への QuickGUI の埋め込みは [モディファイアとホスティング](/docs/go/swift-ui-hosting) を参照してください。
