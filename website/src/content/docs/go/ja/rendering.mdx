コンポーネントはマウント時に実行され、表示すべきツリーを返します。その後のシグナル更新は、バインドされたテキストとプロパティを変えます。子の構造自体が変わりうるときは `ui.Show` と `ui.For` を使います。

## レンダリングモデル

すべてのコンポーネントは `*ui.Element` を返します。要素は子として渡すか、複数の兄弟には `ui.Fragment(...)` を返します。作成した要素は必ず使ってください。返す、代入する、または親へ渡します。

```go
func ViewExample() *ui.Element {
	return ui.View().
		Padding(20).
		Gap(12).
		Child(ui.Text("Hello from Go")).
		Child(ui.Button("Continue").OnClick(func() {}))
}
```

## 条件付きコンテンツ

通常の Go の `if` はコンポーネントの作成中にしか実行されません。あとから子を出したり消したりするときは `ui.Show` を使います。

```go
func DisclosureExample() *ui.Element {
	open, setOpen := ui.CreateSignal(false)
	return ui.View().Children(
		ui.Button("Toggle details").OnClick(func() { setOpen(!open()) }),
		ui.Show(
			open,
			func() *ui.Element { return ui.Text("Details") },
		),
	)
}
```

条件が同じ分岐にとどまっている間、その分岐の状態は保持されます。分岐を離れると、副作用と購読は解除されます。

## リストとノードの同一性

変化しうるリストには `ui.For` を使います。各行には位置ではなく、データベース ID のような安定した一意のキーを指定してください。`ui.KeyedFor` は行に現在の項目へのアクセサーも渡すため、名前の変更ではラベルだけが更新され、行は再作成されません。

リストデータを編集するときは、新しいスライスをセッターに渡してください。保存済みスライスをその場で変更しても UI には通知されません。

```go
type ListPerson struct {
	ID   int
	Name string
}

func KeyedListExample() *ui.Element {
	people, setPeople := ui.CreateSignal([]ListPerson{{1, "Ada"}, {2, "Grace"}})
	return ui.View().Children(
		ui.Button("Reorder and rename").OnClick(func() {
			setPeople([]ListPerson{{2, "Grace"}, {1, "Ada Lovelace"}})
		}),
		ui.KeyedFor(
			people,
			func(person ListPerson) any { return person.ID },
			func(person func() ListPerson, index func() int) *ui.Element {
				return ui.Text(index(), ": ", person().Name)
			},
			func() *ui.Element { return ui.Text("No people") },
		),
	)
}
```

並び替えでは既存の行が移動します。大きなコレクションでは、表示中の行だけをマウントする仮想化テーブルまたはリストを使ってください。

## ウィンドウのライフサイクル

各ウィンドウは独自のコンポーネントルートを持ちます。ウィンドウを閉じると、要素、エフェクト、`ui.OnCleanup` のコールバックが解放されます。

バックグラウンド処理はコンポーネントのマウント中に開始します。`ui.Async` は `load` を UI ゴルーチンの外で実行し、結果を書き戻します。ウィンドウを閉じるか分岐を外すとコンテキストがキャンセルされ、遅れて届いた結果は無視されます。

```go
func LoadingPanel(load func(context.Context) (string, error)) *ui.Element {
	result, setResult := ui.CreateSignal("Loading…")
	ui.Async(
		load,
		func(value string, err error) {
			if err != nil {
				setResult(err.Error())
				return
			}
			setResult(value)
		},
	)
	return ui.Text(result())
}
```

## 現在のウィンドウ

コンポーネントのマウント中に `native.CurrentWindow()` をキャプチャし、そのハンドルをコールバックで使います。

```go
func CloseButton() *ui.Element {
	window := native.CurrentWindow()
	return ui.Button("Close window").OnClick(func() { window.Close() })
}
```

bun run test
