`main` から `native.Run` を一度呼び出します。起動コールバックでウィンドウを開き、アプリ全体の動作を登録します。完了コールバックと UI の更新は UI ゴルーチンで実行されます。

## ウィンドウのライフタイム

`native.NewWindow(native.WindowOptions{Component: App})` は独自のコンポーネントツリーを持つウィンドウを開きます。ウィンドウを閉じるとそのツリーは解放されます。後続の処理でウィンドウが必要な場合は、コンポーネントの構築中またはイベント処理中に `native.CurrentWindow()` をキャプチャしてください。

macOS では Dock からの再表示を処理します。表示中のウィンドウがなければ 1 つ開いてください。

## コマンドとサービス

ダイアログ、クリップボード、シェル、外観、メニューなどのプラットフォーム機能には、型付きの `native` API を使います。結果を返す呼び出しは完了コールバックを取ります。エラーはその中で処理し、UI をブロックしないでください。

コンポーネント内のバックグラウンド処理には `ui.Async` を使います。ほかのゴルーチンから結果を届けるには `native.Dispatch` を使います。シグナルの読み書きは UI ゴルーチンだけで行ってください。

独立したネイティブサービスには `native.InvokeExtension` と `native.OpenExtension` を使います。[拡張の作成](/docs/go/extensions) を参照してください。

## イベントとファイル監視

`native.WatchFiles(paths, changed, ready)` はファイルの変更を監視し、停止用の関数を返します。コンポーネントが所有するウォッチャーは `ui.OnCleanup` に登録します。ポーリングよりこれらのイベントを優先してください。
