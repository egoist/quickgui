QuickGUI アプリは通常の Go プログラムです。ウィンドウとコンポーネントを Go で記述すると、CLI がネイティブの macOS アプリとして実行、リロード、パッケージ化します。

## 動作要件

- macOS 14 以降
- Go 1.23 以降
- Bun 1.4 以降
- Xcode Command Line Tools（`xcode-select --install`）

パッケージ化したアプリは現在 macOS が対象です。

## プロジェクトを作成

```bash
bunx @quickgui/cli init my-app --language go
cd my-app
bun run dev
```

CLI は Go モジュールを作成し、依存関係をインストールしてアプリを開きます。言語を対話的に選ぶ場合は `--language go` を省略してください。

## 最初のウィンドウ

生成された `main.go` はアプリを起動し、ウィンドウを開いてコンポーネントを描画します。コンポーネント関数を `WindowOptions.Component` に渡し、`main` から `native.Run` を一度呼び出してください。

```go
package main

import (
	"log"

	"github.com/egoist/quickgui/go/native"
	"github.com/egoist/quickgui/go/ui"
)

func Counter() *ui.Element {
	count, setCount := ui.CreateSignal(0)
	return ui.View().
		FlexCol().
		SizeFull().
		ItemsCenter().
		JustifyCenter().
		Gap(20).
		Bg("#090d16").
		TextColor("#e2e8f0").
		Child(ui.Text("Fine-grained native UI").FontSize(28).FontWeight(700)).
		Child(ui.Text("Count: ", count())).
		Child(ui.Button().
			OnClick(func() { setCount(count() + 1) }).
			Padding(12).
			RoundedLg().
			Bg("#2563eb").
			Hover(func(s ui.StyleBuilder) ui.StyleBuilder { return s.BackgroundColor("#3b82f6") }).
			Child("Increment"))
}

func main() {
	if err := native.Run(func() {
		open := func() {
			native.NewWindow(native.WindowOptions{
				Title:     "My App",
				Width:     720,
				Height:    480,
				Component: Counter,
			})
		}
		native.App.OnReopen(func(event native.ReopenEvent) {
			if !event.HasVisibleWindows {
				open()
			}
		})
		open()
	}); err != nil {
		log.Fatal(err)
	}
}
```

ラベルで `count()` を読むと、そのテキストが同期されます。ボタンをクリックするとシグナルが更新され、ウィンドウの残りの部分はそのままです。

## 実行とビルド

プロジェクトディレクトリで次のコマンドを実行します。

```bash
bun run dev
bun run fmt
bun run build
```

`dev` は編集に合わせて再ビルドして再起動します。`fmt` は Go ソースを整形します。`build` はパッケージ化したアプリを `dist/` に出力します。
