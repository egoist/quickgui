ルーターは現在のパスからコンポーネントを選び、戻る／進むの履歴を保持します。ルートは現在のウィンドウに描画されます。

## ルートの宣言

ルートは `ui.Route` で宣言します。パラメーターは `ui.UseParams`、ナビゲーションは `ui.UseRouter` または `ui.Link` で行います。

```go
func RouterExample() *native.Node {
	return ui.Router(ui.RouterProps{
		InitialPath: "/",
		Routes: []*ui.RouteDeclaration{
			ui.Route("/", func() *native.Node {
				return ui.Link(ui.LinkProps{Href: "/settings"}, "Settings")
			}),
			ui.Route("/settings", func() *ui.Element {
				return ui.Text("Settings")
			}),
		},
		Fallback: func() *ui.Element { return ui.Text("Page not found") },
	})
}
```

## 入れ子のレイアウト

関連するルートは `ui.Layout` で包みます。マッチした子を表示する位置で `ui.Outlet()` を呼び出します。`ui.Outlet()` の外側にある共通の枠は、兄弟ルート間を移動しても状態を保持します。

```go
func NestedRouterExample() *native.Node {
	return ui.Router(ui.RouterProps{
		Routes: []*ui.RouteDeclaration{
			ui.Layout(
				func() *ui.Element {
					return ui.View().
						Display("flex").
						FlexDirection("column").
						Gap(12).
						Child(ui.Link(ui.LinkProps{Href: "/"}, "Home")).
						Child(ui.Link(ui.LinkProps{Href: "/settings"}, "Settings")).
						Child(ui.Outlet())
				},
				ui.Route("/", func() *ui.Element { return ui.Text("Home") }),
				ui.Route("/settings", func() *ui.Element { return ui.Text("Settings") }),
			),
		},
	})
}
```

## ナビゲーション

ルート内では `ui.UseRouter()` が `Navigate`、`Replace`、`Back`、`Forward` を公開します。`ui.Link` は行き先を宣言します。`Navigate` は履歴エントリを追加し、`Replace` は現在のエントリを更新します。

```go
func BackButton() *ui.Element {
	router := ui.UseRouter()
	return ui.Button("Back").OnClick(router.Back)
}
```

## ルートパラメーター

パスパラメーターは `ui.UseParams`、クエリの値は `ui.UseSearchParams`、現在のロケーションは `ui.UseLocation` で読みます。表示値が更新されるべき場所で読み取ってください。パラメーターだけが変わっても、同じルートコンポーネントはマウントされたままです。

`:name` セグメントはパスパラメーターを 1 つ取り込みます。クエリ文字列はパスとは別です。

```go
func ParameterRouterExample() *native.Node {
	return ui.Router(ui.RouterProps{
		InitialPath: "/projects/quickgui?tab=history",
		Routes: []*ui.RouteDeclaration{
			ui.Route("/projects/:name", func() *ui.Element {
				params := ui.UseParams()
				search := ui.UseSearchParams()
				return ui.View().Children(
					ui.Text("Project: ", params()["name"]),
					ui.Text("Tab: ", search()["tab"]),
				)
			}),
		},
	})
}
```

このルートは `quickgui` と `history` から始まります。セットアップ中に `params()["name"]` を読むと、ラベルは最初の値のまま固定されます。
