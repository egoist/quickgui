スタイルの変化は `ui.Style().Transition(...)` でアニメーションします。コンポーネントはフレームごとに再実行されません。

## ホバーのトランジション

トランジションは基底スタイルに指定すると、ポインターの進入と離脱の両方で実行されます。同じ宣言は `Active`、`Focus`、`Expanded`、`DragOver` でも使えます。

```go
func HoverAction() *ui.Element {
	return ui.Button("Continue").
		Padding(12).
		BorderRadius(8).
		BackgroundColor("#334155").
		TextColor("white").
		Opacity(0.85).
		Transition("background-color 160ms ease-out, opacity 160ms ease-out").
		Hover(func(s ui.StyleBuilder) ui.StyleBuilder { return s.BackgroundColor("#2563eb").Opacity(1) })
}
```

## 状態によるアニメーション

シグナルまたは `ui.When` で対象を切り替えます。下のカードは子要素を保ったまま、色と不透明度がアニメーションします。

```go
func AnimatedSelection() *ui.Element {
	selected, setSelected := ui.CreateSignal(false)
	return ui.View().
		Display("flex").
		FlexDirection("column").
		Gap(12).
		Child(ui.Button("Toggle emphasis").OnClick(func() { setSelected(!selected()) })).
		Child(
			ui.View().
				Padding(20).
				BorderRadius(12).
				BackgroundColor("#334155").
				TextColor("white").
				Opacity(0.6).
				Transition("background-color 180ms ease-out, opacity 180ms ease-out").
				When(selected, ui.Style().BackgroundColor("#2563eb"), ui.Style().Opacity(1)).
				Child("Your selection"),
		)
}
```

トランジションの途中で対象を更新すると、現在の表示値から継続します。逆方向に戻す場合も同様です。

## 時間とフレームレート

複数のプロパティが同じタイミングを共有する場合は `ui.TransitionDeclaration` を使います。

```go
func CappedTransition() *ui.Element {
	return ui.Button("Hover me").
		Padding(12).
		BackgroundColor("#334155").
		TextColor("white").
		Opacity(0.8).
		Transition(ui.TransitionDeclaration{
			Properties: []string{"background-color", "opacity"},
			Duration:   180 * time.Millisecond,
			Easing:     "ease-out",
			MaxFps:     30,
		}).
		Hover(func(s ui.StyleBuilder) ui.StyleBuilder { return s.BackgroundColor("#2563eb").Opacity(1) })
}
```

| フィールド | 用途 |
| --- | --- |
| `TransitionProperty(...)` | 対応する名前のカンマ区切り文字列、または `[]string`。 |
| `TransitionDuration(...)` | ミリ秒の数値、`time.Duration`、または `"180ms"` / `"0.18s"`。期間は 0〜10 秒に制限されます。 |
| `TransitionEasing(...)` | `"linear"`、`"ease"`、`"ease-in"`、`"ease-out"`、`"ease-in-out"`。`"ease"` は `"ease-in-out"` と同じです。 |
| `TransitionTimingFunction(...)` | `TransitionEasing` と同じです。 |
| `TransitionMaxFps(...)` | 任意のフレームレート上限です。省略するとディスプレイに従います。 |

ノードは、選択したすべてのプロパティに対して duration、easing、フレームレート上限を 1 つだけ持ちます。遅延、`cubic-bezier()`、プロパティごとの異なるタイミングには対応していません。

`Transition(180 * time.Millisecond)` は背景色、ボーダー色、文字色をアニメーションします。対応するすべての描画プロパティには `"all"`、ショートハンドを解除するには `"none"` を使います。

## 対応するプロパティ

| トランジション名 | スタイルメソッド |
| --- | --- |
| `background-color` または `background` | `BackgroundColor(...)` または単色の `Background(...)` |
| `border-color` | `BorderColor(...)` |
| `border-width` | `BorderWidth(...)` と各辺の幅 |
| `border-radius` | `BorderRadius(...)` と各角の半径 |
| `color` | 継承される `TextColor(...)` |
| `opacity` | `Opacity(...)` |
| `box-shadow` | `BoxShadow(...)` |
| `transform` | `Transform(...)`（translate、scale、rotate） |

幅、高さ、パディング、グラデーションは補間されません。非対応の名前は拒否されます。

スイッチのつまみをスライドさせるには、`Transform("translateX(20px)")` から `"translateX(0px)"` へトランジションします。描画されたコントロールだけが動き、隣のレイアウトはずれません。

## マウントと視差効果の抑制

トランジションは既存ノード上の変化をアニメーションします。最初の描画はすぐに適用されます。対象が変わる間はノードをマウントしたままにしてください。`ui.Show` は `false` のときに子を取り除き、フェードは待ちません。不透明度 `0` でもレイアウト上の領域を占め、入力を受け取れます。

ダイアログの開閉タイミングには `EnterDuration` と `ExitDuration` を使います。[Dialog](/docs/go/components/dialog) を参照してください。

トランジションはシステムの視差効果を減らす設定に従います。1 つのウィンドウで上書きするには `native.WindowOptions.ReduceMotion` を設定します。

## アニメーション画像

GIF または WebP のパスを `ui.Image` に渡します。再生はファイルに従うため、タイマーは不要です。

```go
func AnimatedImage(path string) *ui.Element {
	return ui.Image().Value(path).
		Width(96).Height(96).ObjectFit("contain")
}
```

パスはファイルに解決される必要があります。data URL を渡すこともできます。アセットは CLI の `resources` オプションでパッケージします。[Image](/docs/go/components/image) と [プロジェクト設定](/docs/go/project-structure#configuration) を参照してください。
