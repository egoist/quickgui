シグナルは UI が読む値を保持します。シグナルが変わると、それを読んだテキストとプロパティだけが更新されます。

## リアクティブな状態

シグナルは `ui.CreateSignal` で作成します。`ui.Text("Count: ", count())` や `.Width(width())` のように、テキストやスタイルメソッドで読み取ります。セットアップ中の `initial := count()` のような読み取りはスナップショットであり、その後は更新されません。

カスタムコンポーネントは通常の Go の値を受け取ります。`LineItem(product, count())` のように `count()` を渡すと、その引数は同期され続けます。

文字列または数値のシグナルは子として直接渡せます。`ui.Text("Count: ", count)` では接頭辞はそのままで、数値だけが更新されます。

```go
func TextExample() *ui.Element {
	count, setCount := ui.CreateSignal(0)
	return ui.View().Children(
		ui.Text("Count: ", count()).FontSize(20),
		ui.Button("Increment").OnClick(func() { setCount(count() + 1) }),
	)
}
```

イベントハンドラー内の書き込みはすでにまとめられます。ほかの UI コードからまとめて書き込むときは `ui.Batch` を使います。

## 派生状態

`ui.CreateMemo` はほかのシグナルから値を計算します。メモはシグナルと同じ方法で読みます。

```go
func DerivedExample() *ui.Element {
	count, setCount := ui.CreateSignal(0)
	doubled := ui.CreateMemo(func() int { return count() * 2 })
	return ui.View().Children(
		ui.Text("Doubled: ", doubled()),
		ui.Button("Increment").OnClick(func() { setCount(count() + 1) }),
	)
}
```

## 副作用とクリーンアップ

購読やウィンドウタイトルなど、ビューの外の処理には `ui.CreateEffect` を使います。エフェクトは最初に実行され、読み取った値が変わると再実行されます。後始末は `ui.OnCleanup` に登録します。次のエフェクトの前と、コンポーネントがなくなるときに実行されます。

変化するテキストとプロパティは直接バインドします。エフェクト内でビューを再構築しないでください。

```go
func EffectExample() *ui.Element {
	topic, setTopic := ui.CreateSignal("Inbox")
	ui.CreateEffect(func() {
		current := topic()
		log.Print("Subscribe: ", current)
		ui.OnCleanup(func() { log.Print("Unsubscribe: ", current) })
	})
	return ui.View().Children(
		ui.Text("Watching: ", topic()),
		ui.Button("Switch topic").OnClick(func() {
			if topic() == "Inbox" {
				setTopic("Archive")
			} else {
				setTopic("Inbox")
			}
		}),
	)
}
```

その実行の値をキャプチャしておくと、クリーンアップはひとつ前のトピックを参照します。

## 更新のバッチ処理

ボタンのクリックなどのイベントハンドラーは、書き込みを自動でバッチ処理します。それ以外では関連する書き込みを `ui.Batch` で包み、購読側が 1 つの結果だけを見るようにします。`ui.Untrack` は購読せずに値を読みます。

シグナルの読み書きは UI ゴルーチンで行います。バックグラウンドの結果は `ui.Async` または `native.Dispatch` で届けます。

```go
func BatchedExample() *ui.Element {
	first, setFirst := ui.CreateSignal("Ada")
	last, setLast := ui.CreateSignal("Lovelace")
	ui.CreateEffect(func() { log.Print(first() + " " + last()) })
	applyProfile := func() {
		ui.Batch(func() {
			setFirst("Grace")
			setLast("Hopper")
		})
	}
	return ui.View().Children(
		ui.Text(first(), " ", last()),
		ui.Button("Apply profile").OnClick(applyProfile),
	)
}
```

このバッチのあと、購読側が見るのは途中の名前ではなく “Grace Hopper” です。バッチは同期的です。バックグラウンド処理を終えてからシグナルに書き込んでください。
