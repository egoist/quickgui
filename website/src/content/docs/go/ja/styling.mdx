`.P4()`、`.MxAuto()`、`.GridCols(3)`、`.RoundedLg()` などの fluent メソッドで要素にスタイルを付けます。共有ビルダーは `.Style(shared)` で適用します。

```go
return ui.View().
	FlexCol().
	PaddingLeft(20).
	RoundedLg().
	TextAlign("center").
	Child(ui.Text("hello")).
	Child(ui.Input().Value("xxx"))
```

## スタイルメソッド

宣言は順番に適用されます。同じプロパティでは後の値が優先され、明示的なゼロも上書きします。数値の長さは論理ピクセルです。文字列ではパーセントも使えます。

```go
func Card() *ui.Element {
	return ui.View().
		Padding(20).
		BorderRadius(12).
		Bg("#111827").
		Child(ui.Text("Hello").TextColor("#e2e8f0"))
}
```

## スタイルのマージ

`.Style(base).Style(overrides)` は順番にマージします。再利用可能なビルダーの合成には `.Merge(...)` を使います。繰り返しのホバーなど、インタラクション状態も同じようにマージされます。

```go
func MergedCard() *ui.Element {
	base := ui.Style().Padding(20).BorderRadius(8).Bg("#111827")
	overrides := ui.Style().BorderRadius(12)
	return ui.View().Child("Merged styles").Style(base).Style(overrides)
}
```

## スタイルの再利用

`ui.Style()` は `ui.StyleBuilder` を返します。各メソッドは新しいビルダーを返すため、共有スタイルは変更されません。バリエーションを派生するときは戻り値を代入してください。`.Style(...)` またはパーツの `PartProps.Style` フィールドに渡します。

```go
func SharedCard() *native.Node {
	card := ui.Style().Padding(20).BorderRadius(12)
	emphasized := card.PaddingLeft(28).Bg("#1e293b")
	return ui.Fragment([]*native.Node{
		ui.View().Child("Hello").Style(card).Bg("#111827").Node,
		ui.View().Child("Another card").Style(emphasized).Node,
	})
}
```

`.When(condition, func(s ui.StyleBuilder) ui.StyleBuilder { ... })` は真偽値からビルダーを派生します。変化しうる値には、要素の `.When(getter, style)` を使うか、アクセサー内でスタイルを組み立てます。`.Width(width)` のように渡すと同期され続け、セットアップ時の `width()` は現在の値をキャプチャするだけです。

## Flexbox

`.Flex()`、`.FlexRow()`、`.FlexCol()` を使います。スクロールする flex の子には `.MinHeight(0)` または `.MinWidth(0)` を指定して縮小できるようにします。

```go
func Row() *ui.Element {
	return ui.View().
		Flex().
		Gap(12).
		ItemsCenter().
		Child(ui.Text("Flexible content").Flex1().MinWidth(0)).
		Child(ui.Button("Action").FlexShrink(0))
}
```

## グリッド

`Display("grid")` と、`GridTemplateColumns("220px 1fr")` のようなトラックリストを設定します。

```go
func Grid() *ui.Element {
	return ui.View().
		Display("grid").
		GridTemplateColumns("220px 1fr").
		Gap(16).
		Child(ui.Text("Sidebar")).
		Child(ui.Text("Content"))
}
```

## テキストと色

タイポグラフィはツリーを下へ継承されます。色には 16 進数、`rgb()` / `rgba()`、またはパックした RGBA 値を使えます。子では異なるプロパティだけを上書きします。パディングとボーダーは継承されません。

```go
func TypographyExample() *ui.Element {
	return ui.View().
		TextColor("#334155").
		FontSize(14).
		Padding(20).
		Child(ui.Text("Inbox").FontSize(24).FontWeight(600)).
		Child(ui.Text("All caught up."))
}
```

## インタラクション状態

ポインター、キーボード、選択の状態には `.Hover(...)`、`.Active(...)`、`.FocusStyle(...)`、`.DisabledStyle(...)`、`.SelectedStyle(...)` を使います。色と不透明度をアニメーションするには基底スタイルに `.Transition(...)` を追加します。[トランジションとアニメーション](/docs/go/animations) を参照してください。

```go
func SelectableButton() *ui.Element {
	selected, setSelected := ui.CreateSignal(false)
	button := ui.Style().Padding(12).Bg("#e5e7eb").
		Hover(func(s ui.StyleBuilder) ui.StyleBuilder { return s.Opacity(0.85) })
	return ui.Button("Toggle selection").Style(button).
		When(selected(), ui.Style().Bg("#2563eb").TextColor("white")).
		OnClick(func() { setSelected(!selected()) })
}
```

## グループと名前付きグループのホバー

`.Group(true)` は名前なしグループ、`.Group("card")` は名前付きグループです。`.GroupHover(...)` は最も近い祖先グループに従い、`.GroupHoverNamed("card", ...)` はその名前を持つ最も近い祖先に従います。重複するプロパティでは、ノード自身のホバースタイルが優先されます。

```go
func GroupExample() *ui.Element {
	return ui.View().
		Group("card").
		Padding(20).
		Child(
			ui.Text("Changes when the card is hovered").
				TextColor("#64748b").
				GroupHoverNamed("card", func(s ui.StyleBuilder) ui.StyleBuilder {
					return s.TextColor("#2563eb")
				}),
		)
}
```

`.GroupActive(...)` と `.GroupActiveNamed(...)` は押されたグループに従います。`.FocusWithin(...)` はノード自身または子孫のフォーカスに従います。これらの状態は描画プロパティを受け取り、カーソルは設定できません。
