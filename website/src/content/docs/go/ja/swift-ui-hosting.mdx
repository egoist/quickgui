SwiftUI のモディファイアはネイティブコントロールにスタイルを付けます。リバースホスティングは QuickGUI のサブツリーを SwiftUI 内に置きます。

## モディファイア

`ui.SwiftUI` のモディファイアファクトリーを `Modifiers` に順番どおり渡します。利用できるファクトリーには ButtonStyle、ButtonBorderShape、ControlSize、LabelStyle、Tint、Disabled があります。

```go
return ui.SwiftUI.Button(ui.SwiftUIButtonProps{
	Label: "Create project",
	Modifiers: []ui.SwiftUIModifier{
		ui.SwiftUI.ButtonStyle("borderedProminent"),
		ui.SwiftUI.ControlSize("large"),
		ui.SwiftUI.Tint("#f97316"),
	},
})
```

## Liquid Glass

対応するシステムでは、`ui.SwiftUI.ButtonStyle("glass")` がシステムのガラスボタンを要求します。最終的な見た目は macOS が決めます。

## リバースホスティング

`ui.SwiftUI.QuickGUIHostView` は SwiftUI 内に QuickGUI の内容を表示します。サイズを設定し、コールバックで子を宣言します。

```go
func SwiftUiQuickguiHostViewExample() *native.Node {
	return ui.SwiftUI.Host(
		ui.SwiftUIHostProps{MatchContents: true},
		func() *native.Node {
			return ui.SwiftUI.QuickGUIHostView(
				ui.SwiftUIQuickGUIHostViewProps{Width: 320, Height: 180},
				func() *ui.Element {
					return ui.View().
						Width("100%").
						Height("100%").
						Padding(16).
						Child("QuickGUI inside SwiftUI")
				},
			)
		},
	)
}
```

## SwiftUI ポップオーバー

SwiftUI のポップオーバーは `Render` を通じてネイティブのトリガーを使います。内容には対話的な QuickGUI コンポーネントをホストできます。

```go
func SwiftUiPopoverExample() *native.Node {
	open, setOpen := ui.CreateSignal(false)
	return ui.SwiftUI.Host(
		ui.SwiftUIHostProps{MatchContents: true},
		func() *native.Node {
			return ui.SwiftUI.Popover.Root(
				ui.SwiftUIPopoverProps{
					IsPresented:         open,
					OnIsPresentedChange: setOpen,
				},
				func() *native.Node {
					return ui.Fragment([]*native.Node{
						ui.SwiftUI.Popover.Trigger(ui.SwiftUIPopoverTriggerProps{
							Render: func() *native.Node {
								return ui.SwiftUI.Button(ui.SwiftUIButtonProps{Label: "Account"})
							},
						}),
						ui.SwiftUI.Popover.Content(
							ui.SwiftUIPopoverContentProps{},
							func() *native.Node {
								return ui.SwiftUI.QuickGUIHostView(
									ui.SwiftUIQuickGUIHostViewProps{Width: 240, Height: 120},
									"Account settings",
								)
							},
						),
					})
				},
			)
		},
	)
}
```

## ライフサイクル

埋め込みサーフェスはオーナーウィンドウが表示されたあとに作成され、ホストが取り除かれると閉じます。リバースホストする子はコールバック内で宣言し、そのサーフェスに属するようにします。要素をウィンドウ間で移動しないでください。
