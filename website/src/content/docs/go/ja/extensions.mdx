拡張は、再利用可能なコンポーネントの Go パッケージか、アプリが呼べるサービスのための Go パッケージとネイティブライブラリの組み合わせです。まずは Go パッケージから始めてください。オプションのバックエンドが必要なときだけネイティブライブラリを追加します。terminal と [自動更新](/docs/go/updater) のパッケージがその例です。

## 拡張の種類を選ぶ

| 追加するもの | 配布するもの |
| --- | --- |
| コンポーネントまたはアプリケーションロジック | Go モジュール |
| ネイティブサービスまたはオプションのバックエンド | Go パッケージ、マニフェスト、ネイティブライブラリ |
| ネイティブデータを使う UI | ネイティブサービスと Go コンポーネント |

利用者はあなたの Go パッケージをインポートします。CLI はマニフェストを見つけ、対応するネイティブ成果物を同梱します。

## 拡張プロジェクトを作成する

```sh
quickgui init-extension my-components --type go
quickgui init-extension my-service --type zig
quickgui init-extension my-service --type rust
```

`go` が既定で、再利用可能なコンポーネントの雛形を作ります。`zig` と `rust` は、型付き Go ラッパー、マニフェスト、npm 成果物パッケージ付きのネイティブサービスの雛形を作ります。どのテンプレートにも `cmd/demo` と `quickgui.toml` が含まれます：

```sh
cd my-service
bun run dev
```

Go モジュールには `--module github.com/acme/my-service`、成果物パッケージには `--npm-package @acme/extension-my-service` を使います。Zig テンプレートには Zig 0.16.x が必要です。このチェックアウトでは、CLI が公開されるまで `bun packages/cli/src/cli.ts init-extension` を実行します。

## コンポーネントの共有

独自モジュールからコンポーネント関数をエクスポートします。このパッケージにネイティブマニフェストは不要です。

```go
package notice

import "github.com/egoist/quickgui/go/ui"

func Notice(message func() string, styles ...ui.StyleBuilder) *ui.Element {
	return ui.Text(
		message(),
	).
		Padding(12).
		BackgroundColor("#eff6ff").
		TextColor("#1e40af").
		BorderRadius(8).
		Style(ui.Style().
			Merge(styles...))
}
```

Go のバージョンタグで公開します。利用者は `go get` で追加します。`terminal` や `updater` をインポートすると、それらのネイティブパッケージがアプリに入ります。オプションの連携は別パッケージに分けてください。

## ネイティブ拡張の構成

[`native-extension` の例](https://github.com/egoist/quickgui/tree/main/examples/native-extension) は Go パッケージと小さな C ライブラリを対にします。[`quickgui_extension.h`](https://github.com/egoist/quickgui/blob/main/include/quickgui_extension.h) に対してビルドします。

```text
go.mod
echo/
  echo.go
  quickgui.extension.json
native/
  quickgui_extension.h
  echo.c
artifacts/
  package.json
  lib/darwin-arm64/libquickgui_acme_echo.dylib
build-extension.ts
```

C、C++、Rust、および C ABI をエクスポートする他の言語で拡張を実装できます。Rust の拡張は [`extension_api.rs`](https://github.com/egoist/quickgui/blob/main/src/extension_api.rs) を取り込み、QuickGUI 自体をリンクせずに `cdylib` をビルドできます。

## 依存関係の宣言

このマニフェストは**インポートする Go パッケージのソースの隣**に置きます：

```json
{
  "schema": 1,
  "name": "acme-echo",
  "abi": 1,
  "package": "@acme/extension-echo",
  "version": "1.0.0",
  "library": "quickgui_acme_echo"
}
```

名前は小文字で始まり、小文字・数字・ハイフンを最大 64 文字まで含めます。`host` は予約されています。library フィールドは `quickgui_` に、ハイフンをアンダースコアに置き換えた名前を足したものです。

Go パッケージはその要求を記録し、型付きの呼び出しを公開します：

```go
package echo

import (
	"encoding/json"

	"github.com/egoist/quickgui/go/host"
	"github.com/egoist/quickgui/go/native"
)

func init() {
	host.RequireExtension("acme-echo", "1.0.0")
}

func Send(message string, done func(string, error)) {
	native.InvokeExtension("acme-echo", "echo", message, func(raw string, err error) {
		var reply string
		if err == nil {
			err = json.Unmarshal([]byte(raw), &reply)
		}
		done(reply, err)
	})
}
```

操作は `native.Run` の準備ができたあとに呼び出してください。永続的なサービスでは `native.OpenExtension(name, options, changed, ready)` がセッションを返します。所有者が破棄されたら、UI ゴルーチン上で閉じてください。

CLI は `go list -deps` でマニフェストを見つけます。マニフェストと `RequireExtension` の両方が必要です。一方は同梱を、もう一方は読み込みを制御します。

## ネイティブインターフェースを実装する

C リンケージで `quickgui_extension_v1` をエクスポートします。名前、バージョン、ABI バージョン `1`、2 関数のテーブル（`invoke` と `shutdown`）を持つディスクリプタを返します。借用したリクエストのバイト列は保持する前にコピーし、すぐに戻り、あとから応答してください。

| リクエスト | 拡張が行うこと |
| --- | --- |
| `echo` のようなワンショットのメソッド | 1 回応答する |
| `start` | セッションを開き、そのイベントシンクを保持する |
| `send` のようなコマンド | そのセッションを見つけ、このコマンドに応答する |
| `stop` | そのセッションをキャンセルする |
| `shutdown` | すべてのセッションをキャンセルし、ブロックしない |

リクエストと応答のペイロードはそれぞれ 64 KiB までです。[C の echo 実装](https://github.com/egoist/quickgui/blob/main/examples/native-extension/backend/echo.c) は、完結したワンショットの例です。

## 自動登録

アプリは起動時に選ばれた各ライブラリを読み込み、名前、バージョン、ABI を確認します。同じ名前のバージョンが衝突すると失敗します。ライブラリイメージはプロセスの生存期間中ロードされたままです。shutdown 関数は残っているセッションをキャンセルしなければなりません。

## 成果物のビルドとパッケージ化

サポートする各ホスト向けにネイティブライブラリをビルドし、`artifacts/lib/<platform>-<arch>/` に配置します。そのフォルダーを、マニフェストと同じ `version` の npm パッケージとして公開します。

```json
{
  "name": "@acme/extension-echo",
  "version": "1.0.0",
  "files": ["lib", "README.md"],
  "exports": { "./package.json": "./package.json" }
}
```

ヘルパーファイルはライブラリの隣に置きます。ベース名はマニフェストの `resources` オブジェクトに、`darwin`、`linux`、`windows` をキーにして宣言します。

## テストと配布

利用者はモジュールを `go get` し、`quickgui dev` を実行します。CLI は対応する npm パッケージを取得します。開発中は `QUICKGUI_EXTENSION_DIR` をローカルの成果物ディレクトリに設定することもできます。

インポートのないアプリがその拡張を同梱しないこと、インポートを追加すると含まれること、セッションを閉じるとイベントが止まることを確認してください。エンドユーザーが受け取るのはパッケージ済みアプリです。実行に Bun やネイティブのツールチェーンは不要です。
