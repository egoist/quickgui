QuickGUI 的 Rust 应用是普通的 Cargo 包。你实现一个 `View`，CLI 负责运行、热重载并打包原生 macOS 应用。

## 系统要求

- macOS 14 或更新版本
- Rust 1.90 或更新版本
- Bun 1.4 或更新版本
- Xcode Command Line Tools（`xcode-select --install`）

首次 `dev` 构建会编译图形依赖，耗时更长。之后的编辑会复用增量 Cargo 产物。当前打包的应用面向 macOS。

## 创建项目

```sh
bunx @quickgui/cli init my-app --language rust
cd my-app
bun run dev
```

CLI 会创建 crate、安装依赖并打开应用。省略 `--language rust` 可在提示时选择语言。

## 第一个窗口

生成的 `src/main.rs` 会启动应用、打开窗口并实现 `View`。把状态保存在视图上，更改后调用 `cx.invalidate()`。

```rust
use quickgui::{
    App, AppInfo, Application, Color, EventContext, IntoElement, View, ViewContext, WindowOptions,
    div, text,
};

fn main() -> Result<(), quickgui::AppError> {
    Application::new()
        .app_info(AppInfo::new("My App", "0.1.0", "com.example.my-app").expect("valid identity"))
        .on_reopen(|has_visible_windows, cx| {
            if !has_visible_windows {
                open_window(cx);
            }
        })
        .run(open_window)
}

fn open_window(cx: &mut App) {
    cx.open_window(WindowOptions::new("My App").size(760.0, 520.0), Counter { count: 0 });
}

struct Counter {
    count: usize,
}

impl View for Counter {
    fn render(&mut self, cx: &mut ViewContext<'_, Self>) -> impl IntoElement {
        let increment = cx.listener("increment", |this, cx: &mut EventContext| {
            this.count += 1;
            cx.invalidate();
        });
        div()
            .size_full()
            .flex_col()
            .items_center()
            .justify_center()
            .gap_3()
            .child(text(format!("Count: {}", self.count)))
            .child(
                div()
                    .on_click(increment)
                    .px_4()
                    .py_2()
                    .rounded_lg()
                    .bg(Color::rgb8(37, 99, 235))
                    .child("Increment"),
            )
    }
}
```

## 运行与构建

在项目目录中执行：

```sh
bun run check
bun run test
bun run fmt
bun run dev
bun run build
```

`check`、`test` 和 `fmt` 会运行 Cargo。`build` 将打包后的应用写入 `dist/`。
