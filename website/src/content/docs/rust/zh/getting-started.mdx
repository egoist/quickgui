这些指南面向 Rust。可在侧栏切换 Go 或 TypeScript。

QuickGUI 的 Rust 应用链接 `quickgui` crate，并通过 `Application::run` 打开原生窗口。

## 系统要求

- Rust 1.90 或更新版本
- Bun 1.4 或更新版本
- macOS 上的 Xcode Command Line Tools（`xcode-select --install`）

首次开发构建耗时更长。之后的编辑会复用增量 Cargo 产物。当前支持的目标平台是 macOS。

## 创建项目

```sh
bunx @quickgui/cli init my-app --language rust
cd my-app
bun run dev
```

从本仓库：

```sh
git clone https://github.com/egoist/quickgui.git
cd quickgui
bun install
bun packages/cli/src/cli.ts init ../my-app --language rust
cd ../my-app
bun run dev
```

## 第一个窗口

生成的 `src/main.rs` 会启动 [`Application`](https://docs.rs/quickgui)、打开窗口，并实现 [`View`](https://docs.rs/quickgui)。把状态保存在 `View` 上，修改后调用 `cx.invalidate()`。

```rust
use quickgui::{
    App, AppInfo, Application, Color, EventContext, IntoElement, View, ViewContext, WindowOptions,
    div, text,
};

fn main() -> Result<(), quickgui::AppError> {
    Application::new()
        .app_info(AppInfo::new("My App", "0.1.0", "com.example.my-app").expect("valid identity"))
        .on_reopen(|has_visible_windows, cx| {
            if !has_visible_windows {
                open_window(cx);
            }
        })
        .run(open_window)
}

fn open_window(cx: &mut App) {
    cx.open_window(WindowOptions::new("My App").size(760.0, 520.0), Counter { count: 0 });
}

struct Counter {
    count: usize,
}

impl View for Counter {
    fn render(&mut self, cx: &mut ViewContext<'_, Self>) -> impl IntoElement {
        let increment = cx.listener("increment", |this, cx: &mut EventContext| {
            this.count += 1;
            cx.invalidate();
        });
        div()
            .size_full()
            .flex_col()
            .items_center()
            .justify_center()
            .gap_3()
            .child(text(format!("Count: {}", self.count)))
            .child(
                div()
                    .on_click(increment)
                    .px_4()
                    .py_2()
                    .rounded_lg()
                    .bg(Color::rgb8(37, 99, 235))
                    .child("Increment"),
            )
    }
}
```

当用户点击 Dock 图标且没有可见窗口时，`on_reopen` 会再次打开窗口。

## 运行与构建

```sh
bun run check
bun run test
bun run fmt
bun run dev
bun run build
```

这些命令会调用 Cargo。生产构建使用 `--release` 编译，并把打包后的应用写到 `dist/`。
