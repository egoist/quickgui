用 `transition` 为样式变化添加动画。视图不会为每一帧渲染。

## 悬停过渡

```rust
button()
    .bg(Color::rgb8(37, 99, 235))
    .transition(Transition::colors(Duration::from_millis(160)))
    .hover(|style| style.bg(Color::rgb8(29, 78, 216)))
    .child("Hover")
```

## 状态驱动的动画

根据视图状态改变样式字段并调用 `invalidate`。元素保持挂载时，受支持的属性会进行动画。

## 时长与帧率

`Transition::new` 接受 `Duration`。用 `with_easing` 设置缓动，用 `max_fps` 在动画运行期间限制帧率。

## 支持的属性

`TransitionProperties` 覆盖背景、边框颜色和宽度、圆角、文本颜色、盒阴影、透明度和变换。宽度、高度和内边距不会插值。

## 挂载与减少动态效果

若组件支持，请让浮层保持挂载直到关闭动画结束。遵循系统的“减少动态效果”偏好。不要用帧循环驱动动画。

## 动态图像

`img` 会播放动态 GIF 和 WebP 文件。不需要定时器。参见 [Image](/docs/rust/components/image)。
