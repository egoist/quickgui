将 UI 作为 Rust 模块共享，或为 Go 和 TypeScript 应用编写原生扩展。Rust 应用本身启用 crate 功能，不在配置中设置 `extensions`。

## 选择扩展类型

| 要添加的内容 | 发布内容 |
| --- | --- |
| 组件或辅助函数 | Rust 模块或 crate |
| 可选的 QuickGUI 能力 | `updater`、`terminal` 等 Cargo 功能 |
| 供 Go 或 TypeScript 使用的原生服务 | 库、清单和带类型的封装 |

## 创建扩展项目

```sh
bunx @quickgui/cli init-extension my-extension --type rust
```

当 Go 或 TypeScript 应用需要消费该服务时使用。`--npm-package` 设置产物包名称。

## 共享组件

导出返回 `Element` 的函数：

```rust
use quickgui::{Color, Element, text};

pub fn notice(message: impl Into<std::sync::Arc<str>>) -> Element {
    text(message)
        .p(12.0)
        .bg(Color::rgb8(239, 246, 255))
        .text_color(Color::rgb8(30, 64, 175))
        .rounded(8.0)
}
```

把 `notice("Saved")` 作为子节点返回。把应用级服务放在 `View::render` 之外。

## 组织原生扩展

原生扩展会附带 `quickgui.extension.json`、带版本号的共享库，以及你声明的其他文件。布局见 [Go 扩展指南](/docs/go/extensions)，也可参考 [`native-extension` 示例](https://github.com/egoist/quickgui/tree/main/examples/native-extension)。

## 声明依赖

Rust **应用**在 `Cargo.toml` 中启用功能：

```toml
[dependencies]
quickgui = { version = "0.1.3", features = ["terminal"] }
```

Go 和 TypeScript 的使用者在各自的配置中声明扩展包。

## 实现原生接口

原生库响应 JSON 请求和可选会话。保留传入字节前请先复制，把耗时工作放到 worker 上，并在会话关闭时停止工作。入口点和请求列表见[实现原生接口](/docs/go/extensions#implement-the-native-contract)。

## 自动注册

Cargo 会链接你依赖的 crate。列出 `extensions` 是给加载已打包库的 Go 和 TypeScript 应用用的。

## 构建与打包产物

应用编辑会重建 crate。修改原生扩展代码后，先重建库，再重建消费它的 Go 或 TypeScript 应用。

## 测试与分发

Rust 应用直接调用 crate API。若为其他语言发布原生库，请先在全新的 Go 或 TypeScript 应用中试用打包后的包，再发布。
