窗口内界面使用 QuickGUI 浮层；文件选择和警告使用系统对话框。

## Popover

组合 `Popover` 的触发器、定位器、弹出层和箭头部件。放置与关闭由系统处理。把 `open` 存在视图上。

## Dialog

`Dialog::new` 和 `Dialog::alert` 增加模态行为，以及标题、说明、背景、视口和关闭部件。用 `restore_focus_to` 恢复焦点；不要再加第二层焦点陷阱。

## 系统浮窗

`SystemPopover` 是锚定到已挂载节点的操作系统面板。它可以延伸到父窗口之外。随其所有者一起释放。

## 原生对话框

```rust
cx.prompt("Save changes?", ["Save", "Cancel"]);
cx.prompt_for_paths(PathPromptOptions::new().files(true).multiple(true));
```
