在 `quickgui` crate 上启用 `updater` 功能。Rust 应用直接调用 `UpdateClient`。

## 配置

生成签名密钥，然后将公钥复制到项目中：

```sh
bunx @quickgui/cli keygen --sparkle --out-dir "$HOME/.config/my-app/update-keys"
cp "$HOME/.config/my-app/update-keys/quickgui-update.pub" ./update-public-key.pub
```

不要将 `quickgui-update.key` 纳入版本控制。

```ts
import { readFileSync } from "node:fs";
import { defineConfig } from "@quickgui/cli";

export default defineConfig({
  language: "rust",
  name: "My App",
  identifier: "com.example.my-app",
  version: "1.0.0",
  entry: ".",
  updates: {
    baseUrl: "https://downloads.example.com/my-app",
    publicKey: readFileSync(
      new URL("./update-public-key.pub", import.meta.url),
      "utf8",
    ).trim(),
    automaticChecks: true,
  },
});
```

启用 crate 功能，而不是在 `extensions` 中列出：

```toml
[dependencies]
quickgui = { version = "0.1.3", features = ["updater"] }
```

`darwin-arm64` 构建会检查 `https://downloads.example.com/my-app/appcast-darwin-arm64.xml`，除非用 `updates.feedUrl` 覆盖。

## 应用用法

应用启动后、在 `View::render` 之外构造一个 `UpdateClient`，让所有窗口共享它：

```rust
use quickgui::{UpdateClient, default_update_target};

let client = UpdateClient::new("1.0.0", public_key)?
    .target(default_update_target())?;
if let Some(update) = client.check("https://downloads.example.com/my-app/{{target}}/latest.json")? {
    let staged = client.download_and_stage(&update)?;
    client.install_staged(&staged)?;
}
```

“检查更新”操作可以从监听器调用 `check`，并在横幅需要更新时调用 `cx.invalidate()`。

## 生命周期

在进程生命周期内保留该客户端。如果其他窗口仍需要更新状态，关闭窗口时不得丢弃它。用 `UpdateCancellation` 取消下载和暂存。

## 平台支持

设置 `updates.publicKey` 后，macOS 可以发出 Sparkle appcast。Windows 和 Linux 使用已签名的 JSON 清单。把开发构建指向可丢弃的更新源。

## 发布更新

```sh
bun run build --update-manifest
```

签名使用 `updates.minisignSecretKey` 或 `QUICKGUI_MINISIGN_SECRET_KEY` 中的 Minisign 密钥。私钥不会嵌入应用。

## 原生产物

只要启用了 crate 功能，生产构建就会包含更新器支持。最终用户运行打包后的应用即可，无需安装额外的更新器工具。
