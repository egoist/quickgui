在 `quickgui` crate 上启用 `updater` feature。Rust 应用直接调用 `UpdateClient`。

## 配置

生成签名密钥对，并把公钥复制到项目中：

```sh
bunx @quickgui/cli keygen --sparkle --out-dir "$HOME/.config/my-app/update-keys"
cp "$HOME/.config/my-app/update-keys/quickgui-update.pub" ./update-public-key.pub
```

不要把私钥 `quickgui-update.key` 提交到版本控制。

```ts
import { readFileSync } from "node:fs";
import { defineConfig } from "@quickgui/cli";

export default defineConfig({
  language: "rust",
  name: "My App",
  identifier: "com.example.my-app",
  version: "1.0.0",
  entry: ".",
  updates: {
    baseUrl: "https://downloads.example.com/my-app",
    publicKey: readFileSync(
      new URL("./update-public-key.pub", import.meta.url),
      "utf8",
    ).trim(),
    automaticChecks: true,
  },
});
```

启用 crate feature：

```toml
[dependencies]
quickgui = { version = "0.1.3", features = ["updater"] }
```

CLI 会嵌入公钥、版本、标识符和 feed URL。`darwin-arm64` 构建会检查 `https://downloads.example.com/my-app/appcast-darwin-arm64.xml`，除非你设置了 `updates.feedUrl`。

## 应用用法

应用启动后、在 `View::render` 之外构造一个 `UpdateClient`：

```rust
use quickgui::{UpdateClient, default_update_target};

let client = UpdateClient::new("1.0.0", public_key)?
    .target(default_update_target())?;
if let Some(update) = client.check("https://downloads.example.com/my-app/{{target}}/latest.json")? {
    let staged = client.download_and_stage(&update)?;
    client.install_staged(&staged)?;
}
```

「检查更新」操作可以从监听器调用 `check`，并在界面需要显示进度时调用 `cx.invalidate()`。

## 生命周期

在整个进程生命周期内保留该 client。如果其他窗口仍需要更新状态，关闭一个窗口时不得丢弃它。

## 平台支持

设置了 `updates.publicKey` 时，macOS 可以生成 Sparkle appcast。Windows 和 Linux 使用已签名的 JSON 清单。开发构建请指向可丢弃的 feed。

## 发布更新

```sh
bun run build --update-manifest
```

签名需要私钥位于 `updates.minisignSecretKey` 或 `QUICKGUI_MINISIGN_SECRET_KEY`。私钥绝不会被嵌入应用。

## 原生产物

打包后的 Rust 应用包含可执行文件和 `quickgui.json`。更新器从该元数据读取嵌入的公钥和当前版本。
