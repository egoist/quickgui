启用 `swift-ui` crate 功能。它们是 QuickGUI 窗口中真正的 macOS 控件。普通 QuickGUI 组件无需依赖它们。

## Host

构造 `MacSwiftUiHost`，同步描述树，并用 `native_view` 挂载。

```rust
let mut host = MacSwiftUiHost::new(|_id| {})?;
host.sync(&[SwiftUiButton::new(1).label("Continue").into()])?;
native_view(host.view())
```

## 原生控件

可用控件包括按钮、开关、滑块、步进器、进度视图、仪表、文本和安全输入、选择器、分段控件、日期和颜色选择器以及浮窗。每个组件页面列出其构建方法。

## 受控值

```rust
let mut host = MacSwiftUiHost::new_with_control_events(
    |_id| {},
    |_id, _presented| {},
    |id, value| { /* store value for id */ },
    |_id| {},
)?;
host.sync(&[SwiftUiToggle::new(1, enabled).label("Notifications").into()])?;
native_view(host.view())
```

## 尺寸

`MacSwiftUiHost::fitting_size` 报告控件的固有尺寸。只希望某一轴随内容变化时，请约束父级。

## 平台支持

SwiftUI 托管仅支持 macOS。Liquid Glass 等可选外观跟随操作系统。参见[修饰器与托管](/docs/rust/swift-ui-hosting)。
