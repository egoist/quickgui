链式方法设置布局、绘制、排版和交互样式。数值长度使用逻辑像素。

## 样式方法

```rust
div()
    .p(16.0)
    .gap(12.0)
    .bg(Color::rgb8(24, 24, 27))
    .text_color(Color::rgb8(250, 250, 250))
```

`flex_col`、`p_3`、`rounded_lg`、`text_lg` 等辅助方法与 QuickGUI 使用的间距和圆角比例一致。`p_3` 为 12 像素。自定义值请使用 `p(14.0)`、`rounded(10.0)` 以及 `w` / `h`。

## 合并样式

同一属性以后面的链式调用为准。`when` 仅在条件为真时应用分支：

```rust
div().p(12.0).when(self.selected, |style| style.bg(Color::rgb8(37, 99, 235)))
```

## 复用样式

编写接收并返回 `Element` 的函数：

```rust
fn panel(child: impl IntoElement) -> Element {
    div().p_3().rounded_xl().bg(Color::rgb8(32, 36, 44)).child(child)
}
```

## Flexbox

使用 `flex`、`flex_col`、`flex_grow`、对齐和 `gap`。在可伸缩的滚动子项上设置 `min_w(0.0)` 或 `min_h(0.0)`，以便它们可以缩小。

## 网格布局

使用 `grid` 以及轨道、放置和跨度方法。

```rust
div()
    .grid()
    .grid_template_columns([GridTrack::px(220.0), GridTrack::fr(1.0)])
    .gap(16.0)
    .child(text("Sidebar"))
    .child(text("Content"))
```

## 文本与颜色

字族、字重、字号、换行和选择都是原生文本。颜色接受 `Color::rgb8`、`Color::rgba8` 和打包值。

## 交互状态

```rust
button()
    .bg(Color::rgb8(37, 99, 235))
    .hover(|style| style.bg(Color::rgb8(29, 78, 216)))
    .child("Save")
```

## 分组与具名分组悬停

在祖先上设置具名 `group`，在后代上设置 `group_hover`，即可一起设置样式。
