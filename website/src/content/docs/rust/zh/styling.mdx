Fluent methods set layout, paint, typography, and interaction styles. Numeric lengths are logical pixels.

## 样式方法

```rust
div()
    .p(16.0)
    .gap(12.0)
    .bg(Color::rgb8(24, 24, 27))
    .text_color(Color::rgb8(250, 250, 250))
```

Fixed presets such as `flex_col`, `p_3`, `rounded_lg`, and `text_lg` match the helpers generated for Go and TypeScript. `p_3` is 12 pixels on the four-pixel spacing scale. For custom values, use `rounded(10.0)`, `p(14.0)`, and `w` / `h`.

## 合并样式

Later fluent calls override earlier ones for the same property. `when` applies a branch only if the condition is true:

```rust
div().p(12.0).when(self.selected, |style| style.bg(Color::rgb8(37, 99, 235)))
```

## 复用样式

Write functions that take and return `Element`:

```rust
fn panel(child: impl IntoElement) -> Element {
    div().p_3().rounded_xl().bg(Color::rgb8(32, 36, 44)).child(child)
}
```

## Flexbox

Use `flex`, `flex_col`, `flex_grow`, alignment, and `gap`. Set `min_w(0.0)` or `min_h(0.0)` on flexible scroll containers so content can shrink.

## 网格布局

Use `grid` plus track, placement, and span methods for two-dimensional layouts. Grid sizing is native; children keep ids when positions change.

## 文本与颜色

Font family, weight, size, wrapping, and selection use retained native text. Colors accept `Color::rgb8`, `Color::rgba8`, and packed linear values. Images and SVGs share the core’s bounded caches.

## 交互状态

```rust
button()
    .bg(Color::rgb8(37, 99, 235))
    .hover(|style| style.bg(Color::rgb8(29, 78, 216)))
    .child("Save")
```

## 分组与具名分组悬停

Use a named `group` on an ancestor and `group_hover` on descendants to style coordinated states. The core resolves group membership and invalidates the affected retained subtree.
