为持有状态的界面实现 `View`。基础组件是返回 `Element` 的函数。复合控件装饰你拥有的元素。

## 定义组件

```rust
struct Greeting {
    name: String,
}
impl View for Greeting {
    fn render(&mut self, _cx: &mut ViewContext<'_, Self>) -> impl IntoElement {
        text(format!("Hello, {}", self.name))
    }
}
```

没有自身状态的子视图也可以是返回 `Element` 的函数。

## 基础组件

`div`、`text`、`button`、`text_input`、`text_area`、`Markdown`、`img`、`svg`、`custom_shader` 和 `VirtualList` 是构建块。`submit_button` 会提交最近的 `form`。可选的 `Terminal` 通过 crate 功能提供。

## 复合组件

把部件放在根节点下，以便共享焦点和选择。

```rust
let checkbox = Checkbox::new(self.checked);
checkbox
    .root_part(div().flex_row().gap(8.0).on_click(toggle))
    .child(checkbox.indicator_part(div().size(16.0, 16.0)))
    .child(text("Remember this device"))
```

## 受控状态

把值存在视图上，并传入 `Checkbox::new` 或 `text_input` 等构造函数。从监听器更新这些字段，然后 `invalidate`。状态由视图拥有。

## 组件类别

侧栏列出选择、标签页、字段、菜单、选择器、对话框、表格、树等控件。每个控件都有独立页面，包含用法、结构和 props。

完整界面示例见[表单与输入](/docs/rust/forms-and-input)和[浮层与对话框](/docs/rust/overlays-and-dialogs)。

## 设置各部件的样式

对每个视觉部件应用链式样式方法。部件默认无样式，布局和颜色由应用决定。`SliderState`、`TabsState`、`SelectState` 等类型会公开当前状态，便于自定义呈现。

辅助方法与复用见[样式与布局](/docs/rust/styling)。
