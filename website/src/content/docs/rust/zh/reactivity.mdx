把状态保存在 `View` 上。`render` 读取该状态来构建树。变更后调用 `cx.invalidate()`，让窗口再次渲染。

## 响应式状态

把字段放在视图结构体上。用 `cx.listener` 注册监听器，以便事件可以更改这些字段。在 `render` 中复制的值是该帧的快照。

```rust
struct Counter {
    count: usize,
}
impl View for Counter {
    fn render(&mut self, cx: &mut ViewContext<'_, Self>) -> impl IntoElement {
        let increment = cx.listener("increment", |this, cx: &mut EventContext| {
            this.count += 1;
            cx.invalidate();
        });
        div()
            .child(text(format!("Count: {}", self.count)))
            .child(button().on_click(increment).child("Increment"))
    }
}
```

## 派生状态

在 `render` 中根据已存储的字段计算派生值。保持计算纯净；从监听器中写入。

```rust
let doubled = self.count * 2;
text(format!("{doubled}"))
```

同一帧中多个子节点需要昂贵结果时，把它存在视图上。

## 副作用与清理

从监听器或 `Application` 回调启动外部工作。视图被丢弃时一并丢弃该工作。关闭窗口会丢弃视图及其监听器。

```rust
impl Drop for WatcherView {
    fn drop(&mut self) {
        self.stop.take().map(|stop| stop());
    }
}
```

## 批量更新

`cx.invalidate()` 将窗口标记为脏。一次事件中的多次失效会合并为一次渲染。普通状态更新不要跑帧循环；没有变化时窗口会休眠。
