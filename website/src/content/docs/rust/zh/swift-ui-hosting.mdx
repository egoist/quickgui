按声明顺序应用 `SwiftUiModifier` 值。`style`、`control_size` 和 `disabled` 等便捷 builder 会追加这些修饰器。

## 修饰器

支持按钮样式、边框形状、控件尺寸、标签样式、着色和禁用状态。在 `sync` 之前应用到描述符上。

## Liquid Glass

```rust
SwiftUiButton::new(1)
    .label("Continue")
    .style(SwiftUiButtonStyle::Glass)
    .control_size(SwiftUiControlSize::Large)
```

macOS 会在可用的地方绘制玻璃效果。

## 反向托管

```rust
SwiftUiQuickGuiHost::pending(1)
```

用 `SwiftUiQuickGuiHost` 和 `MacSwiftUiHost::set_embedded_view` 嵌入 QuickGUI 子树。

## SwiftUI Popover

`SwiftUiPopover` 包含 `trigger` 和 `content` 元素列表。该内容中的 `SwiftUiQuickGuiHost` 可以托管普通 QuickGUI 子节点。

## 生命周期

丢弃 `MacSwiftUiHost` 会释放原生视图。已呈现的面板会随所属窗口一起关闭。
