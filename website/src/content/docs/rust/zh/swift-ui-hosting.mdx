按声明顺序应用 `SwiftUiModifier` 值。`style`、`control_size`、`disabled` 等构建方法会追加这些修饰器。

## 修饰器

支持按钮样式、边框形状、控件尺寸、标签样式、色调和禁用状态。在 `sync` 之前把它们应用到描述上。

## Liquid Glass

```rust
SwiftUiButton::new(1)
    .label("Continue")
    .style(SwiftUiButtonStyle::Glass)
    .control_size(SwiftUiControlSize::Large)
```

macOS 在可用时绘制玻璃效果。

## 反向托管

```rust
SwiftUiQuickGuiHost::pending(1)
```

用 `SwiftUiQuickGuiHost` 和 `MacSwiftUiHost::set_embedded_view` 把 QuickGUI 内容嵌回 SwiftUI。

## SwiftUI Popover

`SwiftUiPopover` 有明确的 `trigger` 和 `content` 列表。该内容中的 `SwiftUiQuickGuiHost` 可托管普通 QuickGUI 组件。

## 生命周期

丢弃 `MacSwiftUiHost` 会释放原生视图。嵌入表面随其 Host 一起释放，已呈现的面板随其所有者一起释放。
