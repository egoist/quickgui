路由器根据当前路径选择匹配项，并保留前进/后退历史。你的视图挂载匹配的树。

## 路由声明

```rust
let router = Router::new(
    [
        RouteDefinition::new("home", "/"),
        RouteDefinition::new("project", "/projects/:id"),
    ],
    "/",
)?;
```

`RouteDefinition::layout` 声明无路径祖先。相对子路径会拼接到父路径；绝对子路径从根开始。

## 嵌套布局

匹配路由链，并用布局元素包裹内部内容。无路径布局会出现在 `matched` 祖先中，而不增加 URL 段。

```rust
RouteDefinition::layout("shell").parent("root")
```

## 导航

```rust
self.router.push("/projects/42")?;
cx.invalidate();
```

路由器支持 `push`、`replace`、`back` 和 `forward`。导航始终在应用内部进行。

## 路由参数

```rust
if let Some(matched) = self.router.matched() {
    let id = matched
        .params()
        .iter()
        .find(|param| param.name() == "id")
        .map(|param| param.value())
        .unwrap_or("");
    text(format!("Project {id}"))
} else {
    text("Page not found")
}
```

查询键值对在 `RouteLocation` 上。
