把当前值传入 `text_input` / `text_area`，并从 `on_input` 写入编辑结果。

## 文本输入

```rust
text_input(self.name.as_str())
    .placeholder("Name")
    .on_input(edit)
text_area(self.notes.as_str())
    .on_input(edit_notes)
```

## 字段

`Field` 和 `Fieldset` 把标签、说明、控件和错误信息关联起来。校验状态在 `FieldState` 上。

## 选项

用指示器和标签组合 `Checkbox`、`CheckboxGroup`、`RadioGroup`、`Radio` 和 `Switch`。把选中值保存在 view 上，并从 listener 更新。

## 选择器

`SelectState`、`ComboboxState` 和 `AutocompleteState` 保存当前值和选项。保持选项值稳定。

## 事件

输入 listener 会收到下一段文本。在 `ViewContext` 上注册指针、按键和提交处理函数。
