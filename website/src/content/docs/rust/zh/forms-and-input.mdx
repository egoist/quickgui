文本控件是受控的：把当前值传入 `text_input` / `text_area`，并从 `on_input` 写入编辑。

## 文本输入

```rust
text_input(self.name.as_str())
    .placeholder("Name")
    .on_input(edit)
text_area(self.notes.as_str())
    .on_input(edit_notes)
```

## 字段

`Field` 和 `Fieldset` 将标签、说明、控件和错误关联起来。验证模式和防抖在 `FieldState` 上设置。

## 选项

用指示器和标签组合 `Checkbox`、`CheckboxGroup`、`RadioGroup`、`Radio` 和 `Switch`。把选中值存在视图上，并从监听器更新。

## 选择器

`SelectState`、`ComboboxState` 和 `AutocompleteState` 接收选项列表。保持选项值稳定。

## 事件

输入监听器接收下一段文本。指针、按键、手势、拖放和提交处理函数在 `ViewContext` 上注册。声明你需要的监听器，控件才能发出对应事件。
