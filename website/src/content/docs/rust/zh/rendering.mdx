`View::render` 在 `invalidate` 之后，或操作系统请求重绘时构建树。给应跨渲染保持身份的元素稳定的 `id`。

## 渲染模型

从 `render` 返回 `impl IntoElement`。窗口会休眠直到有变化。界面空闲时不要用定时器重建。

```rust
div()
    .p(16.0)
    .child(text("Hello"))
    .child(button().child("Continue"))
```

## 条件内容

```rust
if self.expanded {
    text("Expanded content")
} else {
    text("Collapsed")
}
```

省略某个分支会丢弃其节点。具有稳定 id 的兄弟元素保持身份。

## 列表与节点身份

```rust
div().children(self.items.iter().map(|item| {
    text(item.name.as_str()).id(item.id)
}))
```

为有状态的行提供稳定的 `id`，而不是位置。大型集合请使用 `VirtualList` 或 `TableState`，以便只挂载可见行。

## 窗口生命周期

每次 `open_window` 都有自己的视图。关闭一个窗口不会丢弃其兄弟窗口。在 macOS 上，当 Dock 重新打开并报告 `has_visible_windows` 为 false 时，打开一个新窗口。

## 当前窗口

```rust
fn render(&mut self, cx: &mut ViewContext<'_, Self>) -> impl IntoElement {
    let close = cx.listener("close", |_this, cx: &mut EventContext| {
        let _ = cx.close_window();
    });
    button().on_click(close).child("Close")
}
```

`ViewContext` 和 `EventContext` 在渲染和事件期间提供当前窗口。
