生成的项目是一个 Cargo 包，外加一个小型 Bun 包来提供开发命令。

## 生成的文件

```text
my-app/
├── src/main.rs
├── Cargo.toml
├── Cargo.lock
├── quickgui.config.ts
├── package.json
└── README.md
```

首次成功构建后请提交 `Cargo.lock`。较大的应用可拆分为普通 Rust 模块。

## 应用入口

`src/main.rs` 启动 `Application::new().run(...)`，并在该回调中打开窗口。每个窗口拥有一个 `View`。配置中的 `entry` 是 crate 目录（或 `Cargo.toml` 路径）。

```rust
fn main() -> Result<(), quickgui::AppError> {
    Application::new().run(|cx| {
        cx.open_window(WindowOptions::new("My App").size(760.0, 520.0), App);
    })
}
```

## 配置

```ts
import { defineConfig } from "@quickgui/cli";

export default defineConfig({
  language: "rust",
  name: "My App",
  identifier: "com.example.my-app",
  entry: ".",
  fonts: ["assets/MyFont.ttf"],
  resources: ["assets"],
});
```

`quickgui.toml` 接受相同的配置项。CLI 先读取 `quickgui.toml`，再读取 `quickgui.config.ts`。在 `Cargo.toml` 中启用 `updater`、`terminal` 等可选功能，而不是在 `extensions` 中列出。

## 软件包

依赖 `quickgui` crate。`@quickgui/cli` 是开发依赖。

```toml
[dependencies]
quickgui = { version = "0.1.3", features = ["updater"] }
```

## 本地开发

```sh
bun run dev
bun run check
bun run test
bun run build
```

如果同时开发多个 Rust 应用，请使用共享的 `CARGO_TARGET_DIR`，以便复用首次图形构建。
