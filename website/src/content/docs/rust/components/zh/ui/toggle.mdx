可按压的控件，会保留开启或关闭的按下状态。

## 导入

从 `quickgui` 导入 `Toggle`。

```rust
use quickgui::*;
```

## 用法

```rust
Toggle::new(pressed)
    .root_part(button().on_click(toggle).child("Pin this item"))
```

## 结构

- `Toggle::root_part`
- `Toggle::indicator_part`

## 主要属性

| 属性 | 说明 |
| --- | --- |
| `pressed` | 受控的按下状态。 |
| `default_pressed` | 组件自行管理状态时的初始按下状态。 |
| `on_pressed_change` | 报告核心接受的按下状态。 |
| `disabled` | 禁止交互，并暴露禁用状态。 |
