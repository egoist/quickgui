保留式原生代码编辑器，支持语法着色、行号、缩进和双轴滚动。

默认不包含任何语言语法。Rust 可注册静态链接的语法；Go 和 TypeScript 可通过 `LoadLanguagePack` / `loadLanguagePack` 加载单个跨平台包，其中包含所选 Tree-sitter Wasm 语法与查询。

组件默认不带视觉样式：文本和行号继承颜色，不添加背景、边框、圆角、内边距或语法／差异配色。外观由应用显式提供样式与颜色。

## 导入

启用 QuickGUI 可选的 `editor` crate feature，并导入保留式编辑器类型。

```rust
use quickgui::{Editor, IntoElement, SyntaxLanguage, View, ViewContext};
```

## 用法

```rust
struct EditorExample {
    editor: Editor,
}

impl View for EditorExample {
    fn render(&mut self, cx: &mut ViewContext<'_, Self>) -> impl IntoElement {
        let changed = cx.input_listener("source", |view, value, cx| {
            if view.editor.set_text(value).changed {
                cx.invalidate();
            }
        });
        self.editor.element("source").on_input(changed)
    }
}
```

## 语法高亮

`SyntaxLanguage` 选择已注册的 Tree-sitter 语法和高亮查询。查询捕获结果会归并为八种稳定的 `SyntaxTheme` 类别，并以只影响前景色的 `HighlightStyle` 区间应用，因此颜色不会改变文本尺寸。源码或语言变化时重新解析受限文档；调色板变化只重新映射已有捕获，滚动不会执行语法分析。解析最多处理 2 MiB，超过 32 KiB 的单行保持普通颜色，捕获数量也有上限。这是结构化语法高亮，不是语言服务器语义标记。

## 主要属性

| 属性                | 说明                                                   |
| ------------------- | ------------------------------------------------------ |
| `Editor::with_text` | 创建保留式受控源码模型。                               |
| `set_text`          | 提交输入回调的值，仅在需要时刷新语法区间。             |
| `set_language`      | 选择一个内置 Tree-sitter 语法。                        |
| `TextInputIndentation`    | 配置制表符、空格、自动缩进和只读行为。                 |
| `EditorStyle`       | 配置排版、换行、调色板、行号栏、活动行及可选焦点边框。 |
| `element`           | 使用稳定元素 ID 构建原生编辑器叶节点。                 |

<Note>
  在 `quickgui` 依赖中添加 `features = ["editor"]`。每个打开的文档保留一个 Editor
  模型，使输入、选择、撤销和滚动状态具有稳定标识。
</Note>

## 语言包

默认组件不编译任何语言语法。将所选 Tree-sitter 解析器构建为 `.wasm`，再与文本查询合并为一个跨平台包。配置中的 `grammars` 映射到 Wasm 文件路径，`languages` 列出名称、语法、别名、扩展名和查询文件路径。声明的语言依赖会自动包含，相同语法只保存一次。

```sh
quickgui pack-languages languages.json --languages lua,rust --out resources/languages.qglang
```

```rust
// Enable features = ["language-packs"] for the Wasm pack loader.
let languages = quickgui::load_syntax_language_pack("languages.qglang")?;
```

`LoadLanguagePack` / `loadLanguagePack` 在应用就绪后调用一次，使用打包资源目录中的路径。包是二进制 ustar 文件，包含 JSON 清单、文本查询和原始 Wasm 模块；不使用 base64，不需要解压或提取文件。相同内容重复加载不会触发重建，冲突时整个注册操作失败。Rust 也可仅启用 `editor`，通过 `register_syntax_language` 注册应用静态链接的语法。
