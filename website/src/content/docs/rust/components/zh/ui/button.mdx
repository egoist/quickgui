可访问的按压目标，可自行设置样式并组合文本或其他内容。

## 导入

从 `quickgui` 导入 `button`。

```rust
use quickgui::*;
```

## 用法

```rust
button()
    .h(40.0)
    .px(16.0)
    .bg(Color::rgb8(37, 99, 235))
    .text_color(Color::WHITE)
    .rounded(8.0)
    .hover(|style| style.bg(Color::rgb8(59, 130, 246)))
    .on_click(save)
    .child("Save changes")
```

## 主要属性

| 属性 | 说明 |
| --- | --- |
| `child` | 挂载在组件内部的内容。 |
| `on_click` | 在核心完成激活判定后运行。 |
| `disabled` | 禁止交互，并暴露禁用状态。 |
