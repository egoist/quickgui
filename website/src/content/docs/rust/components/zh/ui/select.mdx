单选或多选选择器，选项界面显示在原生浮窗中。

## 导入

从 `quickgui` 导入 `Select`。

```rust
use quickgui::*;
```

## 用法

```rust
let mut state = SelectState::new(items);
state.open(true);
div().child(text(state.selected_label().unwrap_or("Choose")))
```

## 主要属性

| 属性 | 说明 |
| --- | --- |
| `items` | 用于选项或键盘导航的有限声明模型。 |
| `value` | 受控值，具体类型取决于该组件的约定。 |
| `default_value` | 组件自行管理状态时的初始值。 |
| `multiple` | 允许选择或打开多个值。 |
| `on_value_change` | 报告核心接受的值。 |
