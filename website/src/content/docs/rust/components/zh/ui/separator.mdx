具备语义的水平或垂直分隔线，不附带视觉样式。

## 导入

从 `quickgui` 导入 `separator`。

```rust
use quickgui::*;
```

## 用法

```rust
separator(SeparatorOrientation::Horizontal).w(240.0)
```

## 结构

- `separator::root_part`

## 主要属性

| 属性 | 说明 |
| --- | --- |
| `orientation` | 水平或垂直布局，以及对应的键盘方向。 |
| `style` | QuickGUI 的布局、绘制、排版和交互状态样式。 |
