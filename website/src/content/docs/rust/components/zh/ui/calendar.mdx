支持键盘导航的月历网格，用于选择单个日期。

## 导入

从 `quickgui` 导入 `Calendar`。

```rust
use quickgui::*;
```

## 用法

```rust
let calendar = Calendar::new("month");
calendar.root_part(div().flex_col())
```

## 结构

- `Calendar::root_part`
- `Calendar::week_part`
- `Calendar::day_part`

## 主要属性

| 属性 | 说明 |
| --- | --- |
| `value` | 受控值，具体类型取决于该组件的约定。 |
| `default_value` | 组件自行管理状态时的初始值。 |
| `min` | 可接受的最小值。 |
| `max` | 可接受的最大值。 |
| `first_weekday` | 第一列对应的星期；周一为 0，周日为 6。 |
| `on_value_change` | 报告核心接受的值。 |
