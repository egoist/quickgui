原生 SwiftUI 仪表，支持线性和圆形附属样式。

## 导入

从 `quickgui` 导入 `SwiftUiGauge`。

```rust
use quickgui::*;
```

## 用法

```rust
SwiftUiGauge::new(1, 0.7).label("Battery")
```

## 主要属性

| 属性 | 说明 |
| --- | --- |
| `value` | 受控值，具体类型取决于该组件的约定。 |
| `min` | 可接受的最小值。 |
| `max` | 可接受的最大值。 |
| `label` | 原生 SwiftUI 控件的可见标签。 |
| `current_value_label` | 当前原生进度或仪表值的易读标签。 |
| `style` | 此控件的原生 SwiftUI 展示样式。 |
