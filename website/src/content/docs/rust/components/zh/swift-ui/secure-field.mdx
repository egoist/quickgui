隐藏输入内容的原生编辑器，受控约定与 TextField 相同。

## 导入

从 `quickgui` 导入 `SwiftUiTextField`。

```rust
use quickgui::*;
```

## 用法

```rust
SwiftUiTextField::new(1, secret).placeholder("Password").secure(true)
```

## 主要属性

| 属性 | 说明 |
| --- | --- |
| `value` | 受控值，具体类型取决于该组件的约定。 |
| `placeholder` | 可编辑值为空时显示的文本。 |
| `on_value_change` | 报告核心接受的值。 |
| `on_submit` | 原生字段提交当前值时运行。 |
