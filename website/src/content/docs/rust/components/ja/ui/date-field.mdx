ロケールに応じた日付パーツを持つ、キーボード編集可能な分割日付フィールドです。

## インポート

`quickgui` から `DateField` をインポートします。

```rust
use quickgui::*;
```

## 使い方

```rust
let field = DateField::new("start");
field.root_part(div().flex_row())
```

## 構成

- `DateField::root_part`
- `DateField::segment_part`

## 主なプロパティ

| プロパティ | 説明 |
| --- | --- |
| `value` | 制御値です。具体的な型は、このコンポーネントの規約に従います。 |
| `min` | 受け入れる最小値です。 |
| `max` | 受け入れる最大値です。 |
| `on_value_change` | コアが受け入れた値を通知します。 |
| `disabled` | 操作を無効にし、無効状態を公開します。 |
