呼び出し側がスタイルした内容を、現在のウィンドウ内でアンカーの横に配置します。

## インポート

`quickgui` から `Popover` をインポートします。

```rust
use quickgui::*;
```

## 使い方

```rust
let popover = Popover::new("help", open);
popover.root_part(div()).child(popover.trigger_part(button().child("Help")))
```

## 構成

- `Popover::root_part`
- `Popover::trigger_part`
- `Popover::content_part`
- `Popover::portal_part`
- `Popover::backdrop_part`
- `Popover::positioner_part`
- `Popover::popup_part`
- `Popover::arrow_part`
- `Popover::viewport_part`
- `Popover::title_part`
- `Popover::description_part`
- `Popover::close_part`

## 主なプロパティ

| プロパティ | 説明 |
| --- | --- |
| `open` | 制御された開閉状態です。 |
| `default_open` | コンポーネント自身が開閉状態を管理するときの初期状態です。 |
| `on_open_change` | コアが決定した開閉を通知します。 |
| `side` | 衝突処理前に優先する配置方向です。 |
| `align` | 配置の交差軸上で優先する揃え方です。 |
| `modal` | フォーカスを内部に閉じ込め、背後のサーフェスへの操作を防ぎます。 |
