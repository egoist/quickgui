Radio 項目間の単一選択とキーボード移動を管理します。

## インポート

`quickgui` から `RadioGroup` をインポートします。

```rust
use quickgui::*;
```

## 使い方

```rust
RadioGroup::new()
    .root_part(div().flex_col().gap(8.0))
```

## 構成

- `RadioGroup::root_part`

## 主なプロパティ

| プロパティ | 説明 |
| --- | --- |
| `value` | 制御値です。具体的な型は、このコンポーネントの規約に従います。 |
| `default_value` | コンポーネント自身が状態を管理するときの初期値です。 |
| `on_value_change` | コアが受け入れた値を通知します。 |
| `read_only` | 値の変更を防ぎつつ、コントロールはフォーカス可能なままにします。 |
| `required` | 検証とフォーム送信で必須の値としてマークします。 |
