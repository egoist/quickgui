シンタックスカラー、行番号、インデント、両軸スクロールに対応した保持型ネイティブコードエディターです。

既定では言語文法を含みません。Rust はリンク済み文法を登録でき、Go / TypeScript は `LoadLanguagePack` / `loadLanguagePack` で選択した Tree-sitter Wasm 文法とクエリをまとめた単一の移植可能なパックを読み込めます。

既定では見た目のスタイルを持ちません。文字と行番号の色は継承され、背景、枠線、角丸、余白、構文・差分の配色は追加されません。外観はアプリ側で明示的に指定します。

## インポート

QuickGUI の任意の `editor` crate feature を有効にし、保持型エディターの型をインポートします。

```rust
use quickgui::{Editor, IntoElement, SyntaxLanguage, View, ViewContext};
```

## 使い方

```rust
struct EditorExample {
    editor: Editor,
}

impl View for EditorExample {
    fn render(&mut self, cx: &mut ViewContext<'_, Self>) -> impl IntoElement {
        let changed = cx.input_listener("source", |view, value, cx| {
            if view.editor.set_text(value).changed {
                cx.invalidate();
            }
        });
        self.editor.element("source").on_input(changed)
    }
}
```

## シンタックスハイライト

`SyntaxLanguage` は同梱の Tree-sitter 文法とハイライトクエリを選択します。クエリのキャプチャは 8 種類の安定した `SyntaxTheme` クラスへ平坦化され、前景色だけの `HighlightStyle` 範囲として適用されるため、色はテキスト寸法を変えません。ソースまたは言語が変わると上限付きドキュメントを再解析し、配色変更では保持済みキャプチャだけを再マッピングします。スクロール時に構文処理は行いません。解析は最大 2 MiB、32 KiB を超える単一行は通常色のまま、キャプチャ数にも上限があります。これは構造的な構文強調であり、言語サーバーのセマンティックトークンではありません。

## 主なプロパティ

| プロパティ          | 説明                                                                                   |
| ------------------- | -------------------------------------------------------------------------------------- |
| `Editor::with_text` | 保持型の制御ソースモデルを作成します。                                                 |
| `set_text`          | 入力コールバックの値を反映し、必要な場合だけ構文範囲を更新します。                     |
| `set_language`      | 同梱の Tree-sitter 文法を選択します。                                                  |
| `TextInputIndentation`    | タブ、空白、自動インデント、読み取り専用動作を設定します。                             |
| `EditorStyle`       | タイポグラフィ、折り返し、配色、ガター、アクティブ行、任意のフォーカス枠を設定します。 |
| `element`           | 安定した要素 ID でネイティブエディターリーフを構築します。                             |

<Note>
  `quickgui` 依存関係に `features = ["editor"]`
  を追加してください。入力、選択、Undo、スクロール状態の識別を保つため、開いたドキュメントごとに 1
  つの Editor モデルを保持します。
</Note>

## 言語パック

既定のコンポーネントには文法を組み込みません。選択した Tree-sitter パーサーを `.wasm` にビルドし、テキストクエリと一緒に単一の移植可能なパックへまとめます。設定の `grammars` は Wasm ファイルのパス、`languages` は名前、文法、別名、拡張子、クエリパスを指定します。宣言した言語依存関係も含め、共有文法は一度だけ格納します。

```sh
quickgui pack-languages languages.json --languages lua,rust --out resources/languages.qglang
```

```rust
// Enable features = ["language-packs"] for the Wasm pack loader.
let languages = quickgui::load_syntax_language_pack("languages.qglang")?;
```

`LoadLanguagePack` / `loadLanguagePack` はアプリ準備完了後にリソースディレクトリのパスで一度呼び出します。パックは JSON マニフェスト、クエリ文字列、生の Wasm モジュールを含むバイナリ ustar ファイルです。base64、解凍、ファイル展開は不要です。同じ内容の再ロードは何も変更せず、競合時には登録全体が失敗します。Rust は `editor` のみで `register_syntax_language` にリンク済み文法を渡すこともできます。
