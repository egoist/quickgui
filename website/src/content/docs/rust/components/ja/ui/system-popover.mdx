QuickGUI の内容を独立したネイティブ子ウィンドウに表示し、親ウィンドウの外側にも広げられます。

## インポート

`quickgui` から `SystemPopover` をインポートします。

```rust
use quickgui::*;
```

## 使い方

```rust
SystemPopover::new(320.0, 240.0)
```

## 構成

- `SystemPopover::root_part`
- `SystemPopover::trigger_part`
- `SystemPopover::content_part`

## 主なプロパティ

| プロパティ | 説明 |
| --- | --- |
| `open` | 制御された開閉状態です。 |
| `default_open` | コンポーネント自身が開閉状態を管理するときの初期状態です。 |
| `on_open_change` | コアが決定した開閉を通知します。 |
| `width` | 宣言された論理幅です。 |
| `height` | 宣言された論理高さです。 |
| `placement` | ネイティブ子ウィンドウの配置要求です。 |
