個別にスタイルできる入力セルで構成された、長さ制限付きのワンタイムコードエディターです。

## インポート

`quickgui` から `OtpField` をインポートします。

```rust
use quickgui::*;
```

## 使い方

```rust
let field = OtpField::new("code");
field.root_part(div().flex_row().gap(8.0))
```

## 構成

- `OtpField::root_part`
- `OtpField::input_part`
- `OtpField::separator_part`

## 主なプロパティ

| プロパティ | 説明 |
| --- | --- |
| `value` | 制御値です。具体的な型は、このコンポーネントの規約に従います。 |
| `length` | ワンタイムコード入力スロットの数です。上限は 12 です。 |
| `on_value_change` | コアが受け入れた値を通知します。 |
| `disabled` | 操作を無効にし、無効状態を公開します。 |
