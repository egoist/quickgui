ネイティブのキーボードとテキストサービスに対応した、コアが管理する制御テキストエディターです。

## インポート

`quickgui` から `text_input` をインポートします。

```rust
use quickgui::*;
```

## 使い方

```rust
text_input(name.as_str())
    .placeholder("Name")
    .on_input(edit)
```

## 主なプロパティ

| プロパティ | 説明 |
| --- | --- |
| `value` | 制御値です。具体的な型は、このコンポーネントの規約に従います。 |
| `placeholder` | 編集値が空のときに表示するテキストです。 |
| `multiline` | 複数行テキスト編集を有効にします。 |
| `on_input` | ネイティブ編集の入力を通知します。 |
