ファイルパス、ファイル URL、base64 データ URL を保持型の画像リソースとして表示します。

## インポート

`quickgui` から `Image` をインポートします。

```rust
use quickgui::*;
```

## 使い方

```rust
img(Image::from_rgba(128, 128, pixels).expect("image"))
    .size(160.0, 160.0)
    .rounded(12.0)
```

## 主なプロパティ

| プロパティ | 説明 |
| --- | --- |
| `value` | コンポーネントが受け取るファイルパス、データ URL、SVG ドキュメント、またはシェーダーソースです。 |
| `object_fit` | 宣言したボックスに画像内容を収める方法です。 |
