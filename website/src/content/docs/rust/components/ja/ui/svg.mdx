外部リソースを読み込まずに、完全なインライン SVG ドキュメントを描画します。

## インポート

`quickgui` から `Svg` をインポートします。

```rust
use quickgui::*;
```

## 使い方

```rust
svg(Svg::from_bytes(ICON).expect("svg"))
    .size(72.0, 72.0)
    .text_color(Color::rgb8(37, 99, 235))
```

## 主なプロパティ

| プロパティ | 説明 |
| --- | --- |
| `value` | コンポーネントが受け取るファイルパス、データ URL、SVG ドキュメント、またはシェーダーソースです。 |
