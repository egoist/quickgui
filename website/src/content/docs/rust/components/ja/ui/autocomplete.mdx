選択値を必須にせず、自由入力テキストの候補を絞り込みます。

## インポート

`quickgui` から `Autocomplete` をインポートします。

```rust
use quickgui::*;
```

## 使い方

```rust
let mut state = AutocompleteState::new(items);
state.set_query("qui");
div().child(text(state.query()))
```

## 主なプロパティ

| プロパティ | 説明 |
| --- | --- |
| `items` | 選択肢やキーボードナビゲーションに使う、上限付きの宣言モデルです。 |
| `input_value` | Combobox または Autocomplete が使う、編集可能な検索テキストです。 |
| `filter_mode` | コアが管理する、部分一致、前方一致、あいまい一致、または無効の絞り込みです。 |
| `on_input_value_change` | コアが保持した編集可能な検索テキストを通知します。 |
| `on_commit` | 明示的なコミット境界と最終値の詳細を通知します。 |
