サブメニュー、グループ、リンク、チェック項目、ラジオ項目を組み合わせられるメニューです。

## インポート

`quickgui` から `PopoverMenu` をインポートします。

```rust
use quickgui::*;
```

## 使い方

```rust
let menu = PopoverMenu::new("actions", &state);
menu.root_part(div()).child(menu.trigger_part(button().child("Actions")))
```

## 主なプロパティ

| プロパティ | 説明 |
| --- | --- |
| `open` | 制御された開閉状態です。 |
| `default_open` | コンポーネント自身が開閉状態を管理するときの初期状態です。 |
| `on_open_change` | コアが決定した開閉を通知します。 |
| `orientation` | 水平または垂直のレイアウトと、それに対応するキーボード方向です。 |
| `loop_focus` | 現在のメニューレベルの端でキーボードハイライトを循環させます。 |
