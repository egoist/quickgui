関連するフィールドを 1 つの凡例と共有セマンティック状態の下にまとめます。

## インポート

`quickgui` から `Fieldset` をインポートします。

```rust
use quickgui::*;
```

## 使い方

```rust
Fieldset::new()
    .root_part(div().flex_col().gap(12.0))
    .child(text("Account"))
```

## 構成

- `Fieldset::root_part`
- `Fieldset::legend_part`
- `Fieldset::description_part`
- `Fieldset::control_part`

## 主なプロパティ

| プロパティ | 説明 |
| --- | --- |
| `disabled` | 操作を無効にし、無効状態を公開します。 |
| `child` | コンポーネント内にマウントする内容です。 |
| `style` | QuickGUI のレイアウト、描画、タイポグラフィ、インタラクション状態のスタイルです。 |
