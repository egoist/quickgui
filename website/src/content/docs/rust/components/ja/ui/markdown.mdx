保持型の Markdown を描画し、ストリーミング内容向けの差分更新にも対応します。

## インポート

```sh
cargo add quickgui --features markdown
```

```rust
use quickgui::Markdown;
```

## 使い方

```rust
let mut markdown = Markdown::with_text("Build **native** interfaces.");
markdown.element("note").w(290.0)
```

## 主なプロパティ

| プロパティ                             | 説明                                                                                 |
| -------------------------------------- | ------------------------------------------------------------------------------------ |
| `value`                                | 組版・描画する Markdown ソースです。                                                 |
| `streaming`                            | 追記された内容に Markdown の差分更新を使います。                                     |
| `element_with_code_blocks`             | 解析済みコードブロックを呼び出し側の Rust コンポーネントファクトリーで置き換えます。 |
| `element_with_highlighted_code_blocks` | `editor` feature も有効な場合に保持型 CodeBlock モデルを使います。                   |
