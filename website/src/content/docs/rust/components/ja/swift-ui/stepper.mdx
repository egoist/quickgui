値の範囲を制限できる、制御されたネイティブ数値 Stepper です。

## インポート

`quickgui` から `SwiftUiStepper` をインポートします。

```rust
use quickgui::*;
```

## 使い方

```rust
SwiftUiStepper::new(1, count).range(0.0, 10.0).step(1.0).label("Copies")
```

## 主なプロパティ

| プロパティ | 説明 |
| --- | --- |
| `value` | 制御値です。具体的な型は、このコンポーネントの規約に従います。 |
| `min` | 受け入れる最小値です。 |
| `max` | 受け入れる最大値です。 |
| `step` | キーボード、ポインター、またはネイティブコントロール入力で使う増分です。 |
| `label` | ネイティブ SwiftUI コントロールに表示するラベルです。 |
| `on_value_change` | コアが受け入れた値を通知します。 |
