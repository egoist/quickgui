連続値または段階値に対応した、制御されたネイティブ Slider です。

## インポート

`quickgui` から `SwiftUiSlider` をインポートします。

```rust
use quickgui::*;
```

## 使い方

```rust
SwiftUiSlider::new(1, volume)
    .range(0.0, 100.0)
    .step(1.0)
    .label("Volume")
```

## 主なプロパティ

| プロパティ | 説明 |
| --- | --- |
| `value` | 制御値です。具体的な型は、このコンポーネントの規約に従います。 |
| `min` | 受け入れる最小値です。 |
| `max` | 受け入れる最大値です。 |
| `step` | キーボード、ポインター、またはネイティブコントロール入力で使う増分です。 |
| `label` | ネイティブ SwiftUI コントロールに表示するラベルです。 |
| `on_value_change` | コアが受け入れた値を通知します。 |
