CSS 形式の RGBA 文字列を返す、ネイティブ SwiftUI カラーピッカーです。

## インポート

`quickgui` から `SwiftUiColorPicker` をインポートします。

```rust
use quickgui::*;
```

## 使い方

```rust
SwiftUiColorPicker::new(1, "#2563eb").label("Accent")
```

## 主なプロパティ

| プロパティ | 説明 |
| --- | --- |
| `selection` | テーブル、ネイティブピッカー、カラーコントロールの制御選択値です。 |
| `label` | ネイティブ SwiftUI コントロールに表示するラベルです。 |
| `supports_opacity` | ネイティブのカラーパネルでアルファ値を選択できるようにします。 |
| `on_value_change` | 選択したネイティブピッカー項目または色を通知します。 |
