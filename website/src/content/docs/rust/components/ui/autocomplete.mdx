Filters suggestions for free-form text without requiring a selected value.

## Import

Import `Autocomplete` from `quickgui`.

```rust
use quickgui::*;
```

## Usage

```rust
let mut state = AutocompleteState::new(items);
state.set_query("qui");
div().child(text(state.query()))
```

## Key props

| Prop | Purpose |
| --- | --- |
| `items` | Bounded declaration model used for options or keyboard navigation. |
| `input_value` | Editable query text used by a combobox or autocomplete. |
| `filter_mode` | Core-owned contains, prefix, fuzzy, or disabled filtering. |
| `on_input_value_change` | Reports the editable query text retained by the core. |
| `on_commit` | Reports one explicit commit boundary and its final value details. |
