A semantic horizontal or vertical divider with no built-in visual style.

## Import

Import `separator` from `quickgui`.

```rust
use quickgui::*;
```

## Usage

```rust
separator(SeparatorOrientation::Horizontal).w(240.0)
```

## Anatomy

- `separator::root_part`

## Key props

| Prop | Purpose |
| --- | --- |
| `orientation` | Horizontal or vertical layout and keyboard direction. |
| `style` | QuickGUI layout, paint, typography, and interaction-state styles. |
