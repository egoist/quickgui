Shapes and paints Unicode text with inherited typography, selection, and accessibility.

## Import

Import `text` from `quickgui`.

```rust
use quickgui::*;
```

## Usage

```rust
text("Hello from Rust").text_lg()
```

## Key props

| Prop | Purpose |
| --- | --- |
| `child` | Content mounted inside the component. |
| `ref` | Receives the retained native node. |
