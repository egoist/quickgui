A fully composable menu with submenus, groups, links, checkbox items, and radio items.

## Import

Import `PopoverMenu` from `quickgui`.

```rust
use quickgui::*;
```

## Usage

```rust
let menu = PopoverMenu::new("actions", &state);
menu.root_part(div()).child(menu.trigger_part(button().child("Actions")))
```

## Key props

| Prop | Purpose |
| --- | --- |
| `open` | Controlled open state. |
| `default_open` | Initial state when the component owns whether it is open. |
| `on_open_change` | Reports an open or close decision from the core. |
| `orientation` | Horizontal or vertical layout and keyboard direction. |
| `loop_focus` | Wraps keyboard highlight at the ends of the current menu level. |
