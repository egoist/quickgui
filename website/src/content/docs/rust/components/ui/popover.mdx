Places caller-styled content beside an anchor inside the current window.

## Import

Import `Popover` from `quickgui`.

```rust
use quickgui::*;
```

## Usage

```rust
let popover = Popover::new("help", open);
popover.root_part(div()).child(popover.trigger_part(button().child("Help")))
```

## Anatomy

- `Popover::root_part`
- `Popover::trigger_part`
- `Popover::content_part`
- `Popover::portal_part`
- `Popover::backdrop_part`
- `Popover::positioner_part`
- `Popover::popup_part`
- `Popover::arrow_part`
- `Popover::viewport_part`
- `Popover::title_part`
- `Popover::description_part`
- `Popover::close_part`

## Key props

| Prop | Purpose |
| --- | --- |
| `open` | Controlled open state. |
| `default_open` | Initial state when the component owns whether it is open. |
| `on_open_change` | Reports an open or close decision from the core. |
| `side` | Preferred placement side before collision handling. |
| `align` | Preferred alignment on the placement cross-axis. |
| `modal` | Contains focus and blocks interaction behind the surface. |
