Groups related fields under one legend and shared semantic state.

## Import

Import `Fieldset` from `quickgui`.

```rust
use quickgui::*;
```

## Usage

```rust
Fieldset::new()
    .root_part(div().flex_col().gap(12.0))
    .child(text("Account"))
```

## Anatomy

- `Fieldset::root_part`
- `Fieldset::legend_part`
- `Fieldset::description_part`
- `Fieldset::control_part`

## Key props

| Prop | Purpose |
| --- | --- |
| `disabled` | Prevents interaction and exposes the disabled state. |
| `child` | Content mounted inside the component. |
| `style` | QuickGUI layout, paint, typography, and interaction-state styles. |
