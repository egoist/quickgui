Shows and hides one panel from a trigger while preserving accessible state.

## Import

Import `Collapsible` from `quickgui`.

```rust
use quickgui::*;
```

## Usage

```rust
let disclosure = Collapsible::new("notes", open);
disclosure.root_part(div()).child(disclosure.trigger_part(text("Notes")))
```

## Anatomy

- `Collapsible::root_part`
- `Collapsible::trigger_part`
- `Collapsible::panel_part`

## Key props

| Prop | Purpose |
| --- | --- |
| `open` | Controlled open state. |
| `default_open` | Initial state when the component owns whether it is open. |
| `on_open_change` | Reports an open or close decision from the core. |
| `keep_mounted` | Keeps inactive content mounted with display disabled. |
