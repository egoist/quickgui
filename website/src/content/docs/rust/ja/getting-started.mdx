これらのガイドは Rust 向けです。サイドバーで Go または TypeScript に切り替えられます。

QuickGUI の Rust アプリは `quickgui` クレートをリンクし、`Application::run` からネイティブウィンドウを開きます。

## 動作要件

- Rust 1.90 以降
- Bun 1.4 以降
- macOS では Xcode Command Line Tools（`xcode-select --install`）

初回の開発ビルドは時間がかかります。以降の編集では増分の Cargo 成果物を再利用します。現在サポートしている対象は macOS です。

## プロジェクトを作成

```sh
bunx @quickgui/cli init my-app --language rust
cd my-app
bun run dev
```

このリポジトリから作る場合：

```sh
git clone https://github.com/egoist/quickgui.git
cd quickgui
bun install
bun packages/cli/src/cli.ts init ../my-app --language rust
cd ../my-app
bun run dev
```

## 最初のウィンドウ

生成された `src/main.rs` は [`Application`](https://docs.rs/quickgui) を起動し、ウィンドウを開いて [`View`](https://docs.rs/quickgui) を実装します。状態はビューに保持し、変更したあとに `cx.invalidate()` を呼び出します。

```rust
use quickgui::{
    App, AppInfo, Application, Color, EventContext, IntoElement, View, ViewContext, WindowOptions,
    div, text,
};

fn main() -> Result<(), quickgui::AppError> {
    Application::new()
        .app_info(AppInfo::new("My App", "0.1.0", "com.example.my-app").expect("valid identity"))
        .on_reopen(|has_visible_windows, cx| {
            if !has_visible_windows {
                open_window(cx);
            }
        })
        .run(open_window)
}

fn open_window(cx: &mut App) {
    cx.open_window(WindowOptions::new("My App").size(760.0, 520.0), Counter { count: 0 });
}

struct Counter {
    count: usize,
}

impl View for Counter {
    fn render(&mut self, cx: &mut ViewContext<'_, Self>) -> impl IntoElement {
        let increment = cx.listener("increment", |this, cx: &mut EventContext| {
            this.count += 1;
            cx.invalidate();
        });
        div()
            .size_full()
            .flex_col()
            .items_center()
            .justify_center()
            .gap_3()
            .child(text(format!("Count: {}", self.count)))
            .child(
                div()
                    .on_click(increment)
                    .px_4()
                    .py_2()
                    .rounded_lg()
                    .bg(Color::rgb8(37, 99, 235))
                    .child("Increment"),
            )
    }
}
```

表示中のウィンドウがないときに Dock アイコンをクリックすると、`on_reopen` がウィンドウを開き直します。

## 実行とビルド

```sh
bun run check
bun run test
bun run fmt
bun run dev
bun run build
```

これらのコマンドは Cargo を呼び出します。本番ビルドは `--release` でコンパイルし、パッケージ済みアプリを `dist/` に書き出します。
