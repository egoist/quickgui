QuickGUI の Rust アプリは通常の Cargo パッケージです。`View` を実装し、CLI がネイティブ macOS アプリの実行、再読み込み、パッケージ化を行います。

## 動作要件

- macOS 14 以降
- Rust 1.90 以降
- Bun 1.4 以降
- Xcode Command Line Tools（`xcode-select --install`）

最初の `dev` ビルドはグラフィックス依存をコンパイルするため時間がかかります。以降の編集は増分 Cargo 成果物を再利用します。現在、パッケージ化したアプリは macOS が対象です。

## プロジェクトを作成

```sh
bunx @quickgui/cli init my-app --language rust
cd my-app
bun run dev
```

CLI は crate を作成し、依存関係をインストールしてアプリを開きます。`--language rust` を省略すると、対話的に言語を選べます。

## 最初のウィンドウ

生成された `src/main.rs` はアプリを開始し、ウィンドウを開き、`View` を実装します。状態はビューに保存し、変更後に `cx.invalidate()` を呼びます。

```rust
use quickgui::{
    App, AppInfo, Application, Color, EventContext, IntoElement, View, ViewContext, WindowOptions,
    div, text,
};

fn main() -> Result<(), quickgui::AppError> {
    Application::new()
        .app_info(AppInfo::new("My App", "0.1.0", "com.example.my-app").expect("valid identity"))
        .on_reopen(|has_visible_windows, cx| {
            if !has_visible_windows {
                open_window(cx);
            }
        })
        .run(open_window)
}

fn open_window(cx: &mut App) {
    cx.open_window(WindowOptions::new("My App").size(760.0, 520.0), Counter { count: 0 });
}

struct Counter {
    count: usize,
}

impl View for Counter {
    fn render(&mut self, cx: &mut ViewContext<'_, Self>) -> impl IntoElement {
        let increment = cx.listener("increment", |this, cx: &mut EventContext| {
            this.count += 1;
            cx.invalidate();
        });
        div()
            .size_full()
            .flex_col()
            .items_center()
            .justify_center()
            .gap_3()
            .child(text(format!("Count: {}", self.count)))
            .child(
                div()
                    .on_click(increment)
                    .px_4()
                    .py_2()
                    .rounded_lg()
                    .bg(Color::rgb8(37, 99, 235))
                    .child("Increment"),
            )
    }
}
```

## 実行とビルド

プロジェクトディレクトリで次を実行します。

```sh
bun run check
bun run test
bun run fmt
bun run dev
bun run build
```

`check`、`test`、`fmt` は Cargo を実行します。`build` はパッケージ済みアプリを `dist/` に書き出します。
