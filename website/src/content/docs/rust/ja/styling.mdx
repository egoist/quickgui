fluent メソッドでレイアウト、描画、タイポグラフィ、インタラクションのスタイルを設定します。数値の長さは論理ピクセルです。

## スタイルメソッド

```rust
div()
    .p(16.0)
    .gap(12.0)
    .bg(Color::rgb8(24, 24, 27))
    .text_color(Color::rgb8(250, 250, 250))
```

`flex_col`、`p_3`、`rounded_lg`、`text_lg` などのヘルパーは、QuickGUI 全体で使う間隔と角丸のスケールに一致します。`p_3` は 12 ピクセルです。独自の値には `p(14.0)`、`rounded(10.0)`、`w` / `h` を使います。

## スタイルのマージ

同じプロパティでは後の fluent 呼び出しが勝ちます。`when` は条件が真のときだけ分岐を適用します。

```rust
div().p(12.0).when(self.selected, |style| style.bg(Color::rgb8(37, 99, 235)))
```

## スタイルの再利用

`Element` を受け取り、返す関数を書きます。

```rust
fn panel(child: impl IntoElement) -> Element {
    div().p_3().rounded_xl().bg(Color::rgb8(32, 36, 44)).child(child)
}
```

## Flexbox

`flex`、`flex_col`、`flex_grow`、配置、`gap` を使います。伸縮するスクロール子には `min_w(0.0)` または `min_h(0.0)` を設定し、縮小できるようにします。

## グリッド

`grid` にトラック、配置、スパンのメソッドを組み合わせます。

```rust
div()
    .grid()
    .grid_template_columns([GridTrack::px(220.0), GridTrack::fr(1.0)])
    .gap(16.0)
    .child(text("Sidebar"))
    .child(text("Content"))
```

## テキストと色

フォントファミリー、ウェイト、サイズ、折り返し、選択はネイティブテキストです。色は `Color::rgb8`、`Color::rgba8`、パックされた値を受け付けます。

## インタラクション状態

```rust
button()
    .bg(Color::rgb8(37, 99, 235))
    .hover(|style| style.bg(Color::rgb8(29, 78, 216)))
    .child("Save")
```

## グループと名前付きグループのホバー

祖先に名前付き `group` を、子孫に `group_hover` を設定すると、まとめてスタイルできます。
