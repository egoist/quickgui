状態を持つ画面には `View` を実装します。プリミティブは `Element` を返す関数です。複合コントロールは所有する要素を装飾します。

## コンポーネントの定義

```rust
struct Greeting {
    name: String,
}
impl View for Greeting {
    fn render(&mut self, _cx: &mut ViewContext<'_, Self>) -> impl IntoElement {
        text(format!("Hello, {}", self.name))
    }
}
```

自身の状態を持たない子ビューは、`Element` を返す関数にもできます。

## プリミティブ

`div`、`text`、`button`、`text_input`、`text_area`、`Markdown`、`img`、`svg`、`custom_shader`、`VirtualList` が構成要素です。`submit_button` は最も近い `form` を送信します。任意の `Terminal` は crate 機能の背後で利用できます。

## 複合コンポーネント

フォーカスと選択を共有できるよう、パーツはルートの下に置きます。

```rust
let checkbox = Checkbox::new(self.checked);
checkbox
    .root_part(div().flex_row().gap(8.0).on_click(toggle))
    .child(checkbox.indicator_part(div().size(16.0, 16.0)))
    .child(text("Remember this device"))
```

## 制御された状態

値はビューに保存し、`Checkbox::new` や `text_input` などのコンストラクタへ渡します。リスナーからそれらのフィールドを更新し、`invalidate` します。状態の所有者はビューです。

## コンポーネントの種類

サイドバーには選択、タブ、フィールド、メニュー、ピッカー、ダイアログ、テーブル、ツリーなどが並びます。各コントロールには使い方、構造、props のページがあります。

画面全体の例は[フォームと入力](/docs/rust/forms-and-input)と[オーバーレイとダイアログ](/docs/rust/overlays-and-dialogs)を参照してください。

## 各パーツのスタイル

視覚パーツごとに fluent なスタイルメソッドを適用します。パーツはスタイルなしで提供されるため、レイアウトと色はアプリ側のものです。`SliderState`、`TabsState`、`SelectState` などの型は、カスタム表示用に現在の状態を公開します。

ヘルパーと再利用は[スタイルとレイアウト](/docs/rust/styling)を参照してください。
