テキストコントロールは制御されています。現在値を `text_input` / `text_area` に渡し、編集は `on_input` から書き込みます。

## テキスト入力

```rust
text_input(self.name.as_str())
    .placeholder("Name")
    .on_input(edit)
text_area(self.notes.as_str())
    .on_input(edit_notes)
```

## フィールド

`Field` と `Fieldset` はラベル、説明、コントロール、エラーを関連付けます。検証モードとデバウンスは `FieldState` 上にあります。

## 選択コントロール

`Checkbox`、`CheckboxGroup`、`RadioGroup`、`Radio`、`Switch` をインジケーターとラベルで組み合わせます。チェック値はビューに保存し、リスナーから更新します。

## Select

`SelectState`、`ComboboxState`、`AutocompleteState` はオプション一覧を受け取ります。オプション値は安定させてください。

## イベント

入力リスナーは次のテキストを受け取ります。ポインター、キー、ジェスチャー、ドロップ、送信のハンドラーは `ViewContext` に登録します。必要なリスナーを宣言すると、コントロールがそのイベントを発行できます。
