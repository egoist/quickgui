現在の値を `text_input` / `text_area` に渡し、編集は `on_input` から書き戻します。

## テキスト入力

```rust
text_input(self.name.as_str())
    .placeholder("Name")
    .on_input(edit)
text_area(self.notes.as_str())
    .on_input(edit_notes)
```

## フィールド

`Field` と `Fieldset` は、ラベル、説明、コントロール、エラーをつなぎます。検証は `FieldState` にあります。

## 選択コントロール

`Checkbox`、`CheckboxGroup`、`RadioGroup`、`Radio`、`Switch` を、それぞれのインジケーターとラベルと組み合わせます。チェックされた値はビューに保持し、リスナーから更新します。

## Select

`SelectState`、`ComboboxState`、`AutocompleteState` が、現在の値とオプションを保持します。オプションの値は安定したままにします。

## イベント

入力リスナーは次のテキストを受け取ります。ポインター、キー、送信のハンドラーは `ViewContext` に登録します。
