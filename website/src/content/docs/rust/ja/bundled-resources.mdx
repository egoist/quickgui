実行ファイルにコンパイルしないファイル（画像、テンプレート、JSON、その他のデータ）は `resources` で同梱します。CLI は各パスをベース名のままアプリにコピーします。実行中のアプリは `AppPaths::resource_dir()` から読みます。起動時のカレントディレクトリには依存しません。

コンパイル時にバイトを埋め込む場合は `BundledAssets` と `Application::assets` を使います。カスタムフォントは別オプションです。[フォント](#fonts)を参照してください。

## 設定

```ts
import { defineConfig } from "@quickgui/cli";

export default defineConfig({
  language: "rust",
  name: "My App",
  identifier: "com.example.my-app",
  entry: ".",
  resources: ["assets", "copy/template.txt"],
  fonts: ["assets/MyFont.ttf"],
});
```

各項目はファイルまたはディレクトリです。相対パスはプロジェクトディレクトリから解決されます。行き先の名前は一意で、`fonts`、`AppIcon.icns`、`quickgui.json` などの予約名を置き換えてはいけません。

`quickgui dev` と `quickgui build` の両方がこれらのファイルをステージします。パスが無いとビルドは失敗します。Rust の識別情報とフォントパスは、同じリソースディレクトリの `quickgui.json` に書かれます。

## インストール先

| プラットフォーム | リソースディレクトリ |
| --- | --- |
| macOS `.app` | `Contents/Resources` |
| Linux の AppDir、AppImage、`.deb` | 実行ファイルの隣（`usr/bin`） |
| Windows インストーラー | `$INSTDIR` 内の実行ファイルの隣 |

設定したパス `assets` は、そのディレクトリの `assets/` として入ります。ファイル `copy/template.txt` は `template.txt` として入ります。実行時はこれらの名前を `resource_dir()` に結合してください。プロジェクトツリーやカレントディレクトリから読まないでください。

## ファイルの読み込み

```rust
let hero = cx
    .app_paths()
    .unwrap()
    .resource_dir()
    .join("assets/hero.png");

img(hero).size(160.0, 120.0)
```

`img` はファイルシステムパスを受け取ります。他のファイルも同じ結合を使い、`std::fs::read` で読むか、バイトをバイナリ内に置く場合はコンパイル時の `BundledAssets` マップを読みます。

```rust
let bundle = BundledAssets::new()
    .with("copy/template.txt", include_bytes!("../assets/template.txt"))?;
let assets = Assets::new(bundle);
```

相対的な画像パスはリソースディレクトリ基準では解決されません。

## フォント

`fonts` は OpenType ファイルの一覧です。CLI はそれらをリソースディレクトリ内の `fonts/` にコピーし、最初のウィンドウを開く前に `quickgui.json` から登録します。

```ts
export default defineConfig({
  language: "rust",
  name: "My App",
  identifier: "com.example.my-app",
  entry: ".",
  fonts: ["assets/MyFont.ttf"],
});
```

`Application::font` にバイトまたはアセットパスを渡すこともできます。フォントは `resources` の代わりにはなりません。画像や JSON は引き続き `resources` または `BundledAssets` に置きます。
