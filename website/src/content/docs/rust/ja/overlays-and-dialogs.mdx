ウィンドウ内の UI には QuickGUI のオーバーレイを、ファイル選択や警告にはシステムのダイアログを使います。

## Popover

`Popover` のトリガー、ポジショナー、ポップアップ、矢印のパーツを組み合わせます。配置と閉じる操作は処理済みです。`open` はビューに保存します。

## Dialog

`Dialog::new` と `Dialog::alert` はモーダル動作に加え、タイトル、説明、背景、ビューポート、クローズのパーツを追加します。フォーカスは `restore_focus_to` で戻し、二重のフォーカストラップを追加しないでください。

## システムポップオーバー

`SystemPopover` はマウント済みノードにアンカーした OS のパネルです。親ウィンドウの外まで広がることができます。所有者とともに破棄してください。

## ネイティブダイアログ

```rust
cx.prompt("Save changes?", ["Save", "Cancel"]);
cx.prompt_for_paths(PathPromptOptions::new().files(true).multiple(true));
```
