Rust プロジェクトでは、アプリケーションコードを Cargo パッケージに置き、開発コマンドは小さな Bun パッケージに置きます。

## 生成されるファイル

```text
my-app/
├── src/main.rs
├── Cargo.toml
├── Cargo.lock
├── quickgui.config.ts
├── package.json
└── README.md
```

初回のビルドが成功したら `Cargo.lock` をコミットします。大きなアプリは通常の Rust モジュールに分割します。

## アプリケーションのエントリ

`src/main.rs` は `Application::new().run(...)` で起動し、そのコールバックからウィンドウを開きます。各ウィンドウは `View` を所有します。設定の `entry` はクレートのディレクトリです。

```rust
fn main() -> Result<(), quickgui::AppError> {
    Application::new().run(|cx| {
        cx.open_window(WindowOptions::new("My App").size(760.0, 520.0), App);
    })
}
```

## 設定

```ts
import { defineConfig } from "@quickgui/cli";

export default defineConfig({
  language: "rust",
  name: "My App",
  identifier: "com.example.my-app",
  entry: ".",
  fonts: ["assets/MyFont.ttf"],
  resources: ["assets"],
});
```

TOML でも同じキーを使えます。CLI は `quickgui.config.ts` より先に `quickgui.toml` を読みます。任意のクレート機能は、アプリ設定の `extensions` ではなく `Cargo.toml` で有効にします。

## パッケージ

アプリケーションは `quickgui` クレートに依存します。`@quickgui/cli` は開発用の依存関係です。任意の `terminal` と `updater` 機能は Cargo の features です：

```toml
[dependencies]
quickgui = { version = "0.1.3", features = ["updater"] }
```

## ローカル開発

```sh
bun run dev
bun run check
bun run test
bun run build
```

`dev` はソースの変更に合わせて再ビルドします。
