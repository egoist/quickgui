生成されるプロジェクトは Cargo パッケージに、開発コマンド用の小さな Bun パッケージを加えたものです。

## 生成されるファイル

```text
my-app/
├── src/main.rs
├── Cargo.toml
├── Cargo.lock
├── quickgui.config.ts
├── package.json
└── README.md
```

最初の成功ビルドのあと `Cargo.lock` をコミットします。大きなアプリは通常の Rust モジュールに分割します。

## アプリケーションのエントリ

`src/main.rs` は `Application::new().run(...)` を開始し、そのコールバックからウィンドウを開きます。各ウィンドウは `View` を所有します。設定の `entry` は crate ディレクトリ（または `Cargo.toml` のパス）です。

```rust
fn main() -> Result<(), quickgui::AppError> {
    Application::new().run(|cx| {
        cx.open_window(WindowOptions::new("My App").size(760.0, 520.0), App);
    })
}
```

## 設定

```ts
import { defineConfig } from "@quickgui/cli";

export default defineConfig({
  language: "rust",
  name: "My App",
  identifier: "com.example.my-app",
  entry: ".",
  fonts: ["assets/MyFont.ttf"],
  resources: ["assets"],
});
```

`quickgui.toml` も同じキーを受け付けます。CLI は `quickgui.toml` を `quickgui.config.ts` より先に読みます。`updater` や `terminal` などの任意機能は `extensions` ではなく `Cargo.toml` で有効にします。

## パッケージ

`quickgui` crate に依存します。`@quickgui/cli` は開発依存です。

```toml
[dependencies]
quickgui = { version = "0.1.3", features = ["updater"] }
```

## ローカル開発

```sh
bun run dev
bun run check
bun run test
bun run build
```

複数の Rust アプリを扱う場合は共有の `CARGO_TARGET_DIR` を使い、最初のグラフィックスビルドを再利用します。
