`View::render` は `invalidate` のあと、または OS が再描画を求めたときにツリーを構築します。描画をまたいで同一性を保つ要素には安定した `id` を与えます。

## レンダリングモデル

`render` から `impl IntoElement` を返します。ウィンドウは何かが変わるまでスリープします。UI がアイドルのときにタイマーで再構築しないでください。

```rust
div()
    .p(16.0)
    .child(text("Hello"))
    .child(button().child("Continue"))
```

## 条件付きコンテンツ

```rust
if self.expanded {
    text("Expanded content")
} else {
    text("Collapsed")
}
```

分岐を省略するとそのノードはドロップされます。安定した id を持つ兄弟要素は同一性を保ちます。

## リストとノードの同一性

```rust
div().children(self.items.iter().map(|item| {
    text(item.name.as_str()).id(item.id)
}))
```

状態を持つ行には位置ではなく安定した `id` を与えます。大きな集合では `VirtualList` や `TableState` を使い、見える行だけをマウントします。

## ウィンドウのライフサイクル

各 `open_window` は独自のビューを持ちます。1 つのウィンドウを閉じても兄弟はドロップされません。macOS では、Dock の再オープンが `has_visible_windows` が false だと報告したときに新しいウィンドウを開きます。

## 現在のウィンドウ

```rust
fn render(&mut self, cx: &mut ViewContext<'_, Self>) -> impl IntoElement {
    let close = cx.listener("close", |_this, cx: &mut EventContext| {
        let _ = cx.close_window();
    });
    button().on_click(close).child("Close")
}
```

`ViewContext` と `EventContext` は、描画とイベントのあいだ現在のウィンドウを提供します。
