状態は `View` に保存します。`render` はその状態を読んでツリーを構築します。変更後に `cx.invalidate()` を呼ぶと、ウィンドウが再描画します。

## リアクティブな状態

フィールドはビューの構造体に置きます。イベントがそれらのフィールドを変えられるよう、`cx.listener` でリスナーを登録します。`render` でコピーした値はそのフレームのスナップショットです。

```rust
struct Counter {
    count: usize,
}
impl View for Counter {
    fn render(&mut self, cx: &mut ViewContext<'_, Self>) -> impl IntoElement {
        let increment = cx.listener("increment", |this, cx: &mut EventContext| {
            this.count += 1;
            cx.invalidate();
        });
        div()
            .child(text(format!("Count: {}", self.count)))
            .child(button().on_click(increment).child("Increment"))
    }
}
```

## 派生状態

すでに保存しているフィールドから、`render` 内で派生値を計算します。計算は純関数のままにし、書き込みはリスナーから行います。

```rust
let doubled = self.count * 2;
text(format!("{doubled}"))
```

同じフレームで複数の子がコストの高い結果を必要とするときは、ビューに保存します。

## 副作用とクリーンアップ

外部の処理はリスナーまたは `Application` のコールバックから開始します。ビューがドロップされたらその処理もドロップします。ウィンドウを閉じるとビューとそのリスナーがドロップされます。

```rust
impl Drop for WatcherView {
    fn drop(&mut self) {
        self.stop.take().map(|stop| stop());
    }
}
```

## 更新のバッチ処理

`cx.invalidate()` はウィンドウを dirty にします。1 つのイベント内の複数の無効化は 1 回の描画になります。通常の状態更新でフレームループを回さないでください。変化がなければウィンドウはスリープします。
