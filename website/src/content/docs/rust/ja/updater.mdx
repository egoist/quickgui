`quickgui` crate の `updater` 機能を有効にします。Rust アプリは `UpdateClient` を直接呼びます。

## 設定

署名キーを生成し、公開鍵をプロジェクトへコピーします。

```sh
bunx @quickgui/cli keygen --sparkle --out-dir "$HOME/.config/my-app/update-keys"
cp "$HOME/.config/my-app/update-keys/quickgui-update.pub" ./update-public-key.pub
```

`quickgui-update.key` はバージョン管理に入れないでください。

```ts
import { readFileSync } from "node:fs";
import { defineConfig } from "@quickgui/cli";

export default defineConfig({
  language: "rust",
  name: "My App",
  identifier: "com.example.my-app",
  version: "1.0.0",
  entry: ".",
  updates: {
    baseUrl: "https://downloads.example.com/my-app",
    publicKey: readFileSync(
      new URL("./update-public-key.pub", import.meta.url),
      "utf8",
    ).trim(),
    automaticChecks: true,
  },
});
```

`extensions` に列挙する代わりに crate 機能を有効にします。

```toml
[dependencies]
quickgui = { version = "0.1.3", features = ["updater"] }
```

`darwin-arm64` ビルドは、`updates.feedUrl` で上書きしない限り `https://downloads.example.com/my-app/appcast-darwin-arm64.xml` を確認します。

## アプリでの使用

アプリ開始後、`View::render` の外で 1 つの `UpdateClient` を構築し、すべてのウィンドウで共有します。

```rust
use quickgui::{UpdateClient, default_update_target};

let client = UpdateClient::new("1.0.0", public_key)?
    .target(default_update_target())?;
if let Some(update) = client.check("https://downloads.example.com/my-app/{{target}}/latest.json")? {
    let staged = client.download_and_stage(&update)?;
    client.install_staged(&staged)?;
}
```

更新の確認アクションはリスナーから `check` を呼び、バナーを更新するときに `cx.invalidate()` を呼べます。

## ライフサイクル

クライアントはプロセスの寿命のあいだ保持します。他のウィンドウが更新状態をまだ必要なら、ウィンドウを閉じてもドロップしないでください。ダウンロードとステージングのキャンセルには `UpdateCancellation` を使います。

## 対応プラットフォーム

`updates.publicKey` を設定すると、macOS は Sparkle の appcast を出力できます。Windows と Linux は署名済み JSON マニフェストを使います。開発ビルドは使い捨てのフィードを指してください。

## 更新の公開

```sh
bun run build --update-manifest
```

署名は `updates.minisignSecretKey` または `QUICKGUI_MINISIGN_SECRET_KEY` の Minisign 秘密鍵を使います。秘密鍵はアプリに埋め込まれません。

## ネイティブ成果物

crate 機能が有効なら、本番ビルドにはすでにアップデーターサポートが含まれます。エンドユーザーはパッケージ済みアプリを実行するだけで、追加のアップデーター用ツールは不要です。
