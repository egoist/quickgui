`quickgui` クレートの `updater` 機能を有効にします。Rust アプリは `UpdateClient` を直接呼び出します。

## 設定

署名用のキーペアを生成し、公開鍵をプロジェクトへコピーします：

```sh
bunx @quickgui/cli keygen --sparkle --out-dir "$HOME/.config/my-app/update-keys"
cp "$HOME/.config/my-app/update-keys/quickgui-update.pub" ./update-public-key.pub
```

秘密鍵の `quickgui-update.key` はバージョン管理に入れないでください。

```ts
import { readFileSync } from "node:fs";
import { defineConfig } from "@quickgui/cli";

export default defineConfig({
  language: "rust",
  name: "My App",
  identifier: "com.example.my-app",
  version: "1.0.0",
  entry: ".",
  updates: {
    baseUrl: "https://downloads.example.com/my-app",
    publicKey: readFileSync(
      new URL("./update-public-key.pub", import.meta.url),
      "utf8",
    ).trim(),
    automaticChecks: true,
  },
});
```

クレート機能を有効にします：

```toml
[dependencies]
quickgui = { version = "0.1.3", features = ["updater"] }
```

CLI は公開鍵、バージョン、`identifier`、フィード URL を埋め込みます。`updates.feedUrl` を設定しないかぎり、`darwin-arm64` ビルドは `https://downloads.example.com/my-app/appcast-darwin-arm64.xml` を確認します。

## アプリでの使用

アプリケーション起動後、`View::render` の外で `UpdateClient` を 1 つ構築します：

```rust
use quickgui::{UpdateClient, default_update_target};

let client = UpdateClient::new("1.0.0", public_key)?
    .target(default_update_target())?;
if let Some(update) = client.check("https://downloads.example.com/my-app/{{target}}/latest.json")? {
    let staged = client.download_and_stage(&update)?;
    client.install_staged(&staged)?;
}
```

更新を確認するアクションは、リスナーから `check` を呼び出せます。進捗を UI に出すときは `cx.invalidate()` します。

## ライフサイクル

クライアントはプロセスの寿命のあいだ保持します。ほかのウィンドウがまだ更新状態を必要とするなら、ウィンドウを閉じてもドロップしてはいけません。

## 対応プラットフォーム

`updates.publicKey` が設定されているとき、macOS は Sparkle の appcast を出力できます。Windows と Linux は署名済み JSON マニフェストを使います。開発ビルドは使い捨てのフィードを指してください。

## 更新の公開

```sh
bun run build --update-manifest
```

署名には、`updates.minisignSecretKey` または `QUICKGUI_MINISIGN_SECRET_KEY` の秘密鍵が必要です。秘密鍵がアプリケーションに埋め込まれることはありません。

## ネイティブ成果物

パッケージ済みの Rust アプリには、実行ファイルと `quickgui.json` が含まれます。アップデーターは、そのメタデータから埋め込み済みの公開鍵と現在のバージョンを読みます。
