UI は Rust モジュールとして共有するか、Go と TypeScript アプリ向けのネイティブ拡張を作成します。Rust アプリ自身は crate 機能を有効にし、設定の `extensions` は使いません。

## 拡張の種類を選ぶ

| 追加するもの | 配布するもの |
| --- | --- |
| コンポーネントやヘルパー | Rust モジュールまたは crate |
| 任意の QuickGUI 機能 | `updater` や `terminal` などの Cargo 機能 |
| Go または TypeScript 向けのネイティブサービス | ライブラリー、マニフェスト、型付きラッパー |

## 拡張プロジェクトを作成する

```sh
bunx @quickgui/cli init-extension my-extension --type rust
```

Go または TypeScript アプリがサービスを利用する場合に使います。`--npm-package` は成果物パッケージ名を設定します。

## コンポーネントの共有

`Element` を返す関数をエクスポートします。

```rust
use quickgui::{Color, Element, text};

pub fn notice(message: impl Into<std::sync::Arc<str>>) -> Element {
    text(message)
        .p(12.0)
        .bg(Color::rgb8(239, 246, 255))
        .text_color(Color::rgb8(30, 64, 175))
        .rounded(8.0)
}
```

`notice("Saved")` を子として返します。アプリ全体のサービスは `View::render` の外に置きます。

## ネイティブ拡張の構成

ネイティブ拡張は `quickgui.extension.json`、バージョン付き共有ライブラリー、宣言した追加ファイルを同梱します。配置は [Go の拡張ガイド](/docs/go/extensions) と [`native-extension` の例](https://github.com/egoist/quickgui/tree/main/examples/native-extension) を参照してください。

## 依存関係の宣言

Rust の**アプリケーション**は `Cargo.toml` で機能を有効にします。

```toml
[dependencies]
quickgui = { version = "0.1.3", features = ["terminal"] }
```

Go と TypeScript の利用者は、それぞれの設定で拡張パッケージを宣言します。

## ネイティブインターフェースを実装する

ネイティブライブラリーは JSON リクエストと任意のセッションに応答します。保持する前に受信バイトをコピーし、遅い処理は worker で行い、セッションが閉じたら処理を止めてください。エントリポイントとリクエスト一覧は[ネイティブインターフェースを実装する](/docs/go/extensions#implement-the-native-contract)を参照してください。

## 自動登録

Cargo は依存する crate をリンクします。`extensions` の列挙は、パッケージ済みライブラリーを読み込む Go と TypeScript アプリ向けです。

## 成果物のビルドとパッケージ化

アプリの編集は crate を再ビルドします。ネイティブ拡張のコードを変更したらライブラリーを再ビルドし、続けて利用側の Go または TypeScript アプリを再ビルドします。

## テストと配布

Rust アプリは crate API を直接呼びます。他言語向けにネイティブライブラリーを配布する場合は、公開前に新しい Go または TypeScript アプリでパッケージ済み成果物を試してください。
