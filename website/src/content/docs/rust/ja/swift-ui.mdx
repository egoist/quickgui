`swift-ui` クレート機能を有効にします。通常の QuickGUI コンポーネントは、これがなくても動きます。

## Host

`MacSwiftUiHost` を構築し、ディスクリプターツリーを `sync` し、`native_view` でマウントします。

```rust
let mut host = MacSwiftUiHost::new(|_id| {})?;
host.sync(&[SwiftUiButton::new(1).label("Continue").into()])?;
native_view(host.view())
```

## ネイティブコントロール

ボタン、トグル、スライダー、ステッパー、プログレスビュー、ゲージ、テキストフィールドとセキュアフィールド、ピッカー、セグメントコントロール、日付ピッカーとカラーピッカー、ポップオーバーです。

## 制御値

```rust
let mut host = MacSwiftUiHost::new_with_control_events(
    |_id| {},
    |_id, _presented| {},
    |id, value| { /* store value for id */ },
    |_id| {},
)?;
host.sync(&[SwiftUiToggle::new(1, enabled).label("Notifications").into()])?;
native_view(host.view())
```

## サイズ

`MacSwiftUiHost::fitting_size` は、コントロールの固有サイズを報告します。固定幅にしたいときは親を制約します。

## 対応プラットフォーム

SwiftUI のホスティングには macOS が必要です。Liquid Glass などの任意の外観は、オペレーティングシステムのバージョンに依存します。
