`swift-ui` crate 機能を有効にします。QuickGUI ウィンドウ内の本物の macOS コントロールです。通常の QuickGUI コンポーネントはこれらなしで動作します。

## Host

`MacSwiftUiHost` を構築し、ディスクリプターツリーを同期し、`native_view` でマウントします。

```rust
let mut host = MacSwiftUiHost::new(|_id| {})?;
host.sync(&[SwiftUiButton::new(1).label("Continue").into()])?;
native_view(host.view())
```

## ネイティブコントロール

ボタン、トグル、スライダー、ステッパー、プログレスビュー、ゲージ、テキスト／セキュアフィールド、ピッカー、セグメントコントロール、日付・カラーピッカー、ポップオーバーが利用できます。各コンポーネントページにビルダーメソッドが載っています。

## 制御値

```rust
let mut host = MacSwiftUiHost::new_with_control_events(
    |_id| {},
    |_id, _presented| {},
    |id, value| { /* store value for id */ },
    |_id| {},
)?;
host.sync(&[SwiftUiToggle::new(1, enabled).label("Notifications").into()])?;
native_view(host.view())
```

## サイズ

`MacSwiftUiHost::fitting_size` はコントロールの固有サイズを報告します。一方の軸だけを内容に合わせたいときは親を制約します。

## 対応プラットフォーム

SwiftUI ホスティングは macOS 専用です。Liquid Glass などの任意の外観は OS に従います。[モディファイアとホスティング](/docs/rust/swift-ui-hosting)を参照してください。
