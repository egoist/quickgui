パッケージ後のアプリアイコンは、Finder、Dock、Windows のタスクバーとスタートメニュー、Linux のデスクトップランチャーが表示する画像です。PNG を `resources/icon.png` に置きます。実行中にウィンドウアイコンや macOS の Dock アイコンを変えることもできます。

## 元になるアイコン

`resources/icon.png` に、少なくとも 256×256 ピクセルの正方形 PNG を置きます。1024×1024 がよい元画像です。QuickGUI は原稿をラスタライズしません。既にある PNG データをパッケージします。

```text
my-app/
├── resources/
│   └── icon.png
├── src/main.rs
└── quickgui.config.ts
```

macOS では `quickgui build` が `sips` でその PNG をリサイズできます。他のプラットフォームでは、元ファイルの隣の `resources/icon.iconset/` に事前サイズのファイルを置きます。

```text
resources/icon.png
resources/icon.iconset/
  icon_16x16.png
  icon_32x32.png
  icon_48x48.png
  icon_64x64.png
  icon_128x128.png
  icon_256x256.png
  icon_512x512.png
  icon_1024x1024.png
```

CLI は macOS 用に `.icns`、Windows インストーラー用に `.ico`、Linux 用に Freedesktop の `hicolor` サイズを書き出します。開発リロードは生成コンテナをスキップします。本番ビルドと設定済みの `macos.icon` はアイコンをインストールします。`icon.iconset` はビルド入力であり、パッケージにはコピーされません。

ソース PNG が `resources/icon.png` 以外にあるときだけ、CLI 設定の `icon` を使います。

## プラットフォーム固有のアイコン

既にプラットフォーム用コンテナがあるときに使います。

```text
resources/icon.png
resources/icon.icns
resources/icon.ico
```

`macos.icon` を省略すると macOS は `resources/icon.icns` を使います。`windows.icon` を省略すると NSIS インストーラーは `resources/icon.ico` を使います。`resources/icon.png` と `icon` の両方を省略したとき、`linux.icon` が正方形 PNG として使われます。

```ts
export default defineConfig({
  language: "rust",
  name: "My App",
  identifier: "com.example.my-app",
  entry: ".",
  macos: { icon: "packaging/AppIcon.icns" },
  windows: { icon: "packaging/AppIcon.ico" },
});
```

`macos.icon` は `.icns` でなければなりません。`windows.icon` は `.ico` です。これらの設定パスは `resources/` 内のファイルより優先されます。

ドキュメントタイプのアイコンは、パッケージされたリソース内のベース名です。[バンドルするリソース](/docs/rust/bundled-resources)を参照してください。

## ウィンドウと Dock のアイコン

パッケージされたアイコンはアプリケーションの識別です。ウィンドウは Windows と X11 で別の画像を表示できます。

```rust
let icon = Image::open(
    cx.app_paths()
        .unwrap()
        .resource_dir()
        .join("icon.png"),
)
.expect("icon");
cx.open_window(WindowOptions::new("My App").icon(icon), App);
```

ウィンドウの作成後は `cx.set_window_icon(icon)` と `cx.clear_window_icon()` がその画像を更新します。macOS ではウィンドウ固有のアイコンはありません。`cx.set_dock_icon(icon)` でこのプロセスの Dock 画像を置き換えます。

## 生成されるサイズ

| Target | Sizes |
| --- | --- |
| macOS `.icns` | 32, 64, 128, 256, 512, 1024 |
| Windows `.ico` | 16, 24, 32, 48, 64, 128, 256 |
| Linux `hicolor` | 16, 32, 48, 64, 128, 256, 512 |

そのピクセルサイズの PNG があるときだけ含まれます。ソース PNG は正方形で、少なくとも 256×256、最大 16 MiB です。
