パッケージ後のアプリアイコンは、Finder、Dock、Windows のタスクバーとスタートメニュー、Linux のデスクトップランチャーが表示する画像です。CLI の設定で指定します。実行中にウィンドウアイコンや macOS の Dock アイコンを変えることもできます。

## 元になるアイコン

一辺が 256 ピクセル以上の正方形 PNG を追加します。1024×1024 が扱いやすい元画像です。QuickGUI は原稿をラスタライズしません。すでに存在する PNG データをパッケージします。

```ts
import { defineConfig } from "@quickgui/cli";

export default defineConfig({
  language: "rust",
  name: "My App",
  identifier: "com.example.my-app",
  entry: ".",
  icon: "assets/icon.png",
});
```

macOS では `quickgui build` が `sips` でその PNG をリサイズできます。それ以外の環境では、元ファイルの横の `assets/icon.iconset/` に事前サイズのファイルを置きます：

```text
assets/icon.png
assets/icon.iconset/
  icon_16x16.png
  icon_32x32.png
  icon_48x48.png
  icon_64x64.png
  icon_128x128.png
  icon_256x256.png
  icon_512x512.png
  icon_1024x1024.png
```

CLI は macOS 向けに `.icns`、Windows インストーラー向けに `.ico`、Linux 向けに Freedesktop の `hicolor` サイズを書き出します。開発時のリロードは生成コンテナをスキップします。本番ビルドと設定済みの `macos.icon` はアイコンをインストールします。

## プラットフォーム固有のアイコン

すでにプラットフォーム用コンテナがある場合や、Linux 専用の PNG がある場合に使います：

```ts
export default defineConfig({
  language: "rust",
  name: "My App",
  identifier: "com.example.my-app",
  entry: ".",
  icon: "assets/icon.png",
  macos: { icon: "assets/AppIcon.icns" },
  windows: { icon: "assets/AppIcon.ico" },
  linux: { icon: "assets/icon.png" },
});
```

`macos.icon` は `.icns` でなければなりません。`windows.icon` は NSIS インストーラーが使う `.ico` です。トップレベルの `icon` を省略したとき、`linux.icon` は正方形 PNG として使われます。トップレベルの `icon` は、専用ファイルがないプラットフォームに使われます。

ドキュメントタイプのアイコンは、パッケージされたリソース内のベース名です。[バンドルするリソース](/docs/rust/bundled-resources)を参照してください。

## ウィンドウと Dock のアイコン

パッケージのアイコンはアプリの識別です。ウィンドウは Windows と X11 で別の画像を表示できます：

```rust
let icon = Image::open(
    cx.app_paths()
        .unwrap()
        .resource_dir()
        .join("assets/icon.png"),
)
.expect("icon");
cx.open_window(WindowOptions::new("My App").icon(icon), App);
```

ウィンドウの作成後は `cx.set_window_icon(icon)` と `cx.clear_window_icon()` がその画像を更新します。macOS ではウィンドウ固有のアイコンはありません。`cx.set_dock_icon(icon)` でこのプロセスの Dock 画像を差し替えます。

## 生成されるサイズ

| 対象 | サイズ |
| --- | --- |
| macOS `.icns` | 32, 64, 128, 256, 512, 1024 |
| Windows `.ico` | 16, 24, 32, 48, 64, 128, 256 |
| Linux `hicolor` | 16, 32, 48, 64, 128, 256, 512 |

そのピクセルサイズの PNG があるときだけ、そのサイズが入ります。元の PNG は正方形で、256×256 以上、最大 16 MiB です。
