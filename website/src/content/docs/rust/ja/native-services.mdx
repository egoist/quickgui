`main` から `Application::new().run(...)` を一度呼びます。起動コールバックでウィンドウを開き、アプリ全体の振る舞いを登録します。リスナーは UI スレッドで実行されます。

## ウィンドウのライフタイム

`cx.open_window(WindowOptions::new("Title").size(width, height), view)` は独自の `View` を持つウィンドウを開きます。ウィンドウを閉じるとそのビューはドロップされます。

```rust
Application::new()
    .on_reopen(|has_visible_windows, cx| {
        if !has_visible_windows {
            cx.open_window(WindowOptions::new("My App").size(760.0, 520.0), App);
        }
    })
    .run(|cx| {
        cx.open_window(WindowOptions::new("My App").size(760.0, 520.0), App);
    })
```

## コマンドとサービス

```rust
cx.prompt("Save changes?", ["Save", "Cancel"]);
cx.prompt_for_paths(PathPromptOptions::new().files(true));
cx.message_box(MessageBoxOptions::new("Replace this file?"));
```

型付き API はダイアログ、クリップボード、シェル、外観、メニュー、ディスプレイをカバーします。あとの処理でそのウィンドウが必要なら、リスナー内で `cx.window_handle()` を保持します。

## イベントとファイル監視

ウィンドウイベントにはフォーカス、リサイズ、外観、最小化、フルスクリーン、クローズがあります。アプリのコールバックには再オープン、アクティベーション、終了、URL を開くことがあります。ファイルシステムのイベントには `file-watcher` crate 機能を有効にし、所有するビューとともに watcher をドロップします。
