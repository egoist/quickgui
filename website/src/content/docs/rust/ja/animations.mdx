`transition` でスタイルの変化をアニメーションします。ビューは毎フレーム描画されません。

## ホバーのトランジション

```rust
button()
    .bg(Color::rgb8(37, 99, 235))
    .transition(Transition::colors(Duration::from_millis(160)))
    .hover(|style| style.bg(Color::rgb8(29, 78, 216)))
    .child("Hover")
```

## 状態によるアニメーション

ビューの状態からスタイルフィールドを変更し、`invalidate` を呼びます。対応するプロパティは、要素がマウントされたままアニメーションします。

## 時間とフレームレート

`Transition::new` は `Duration` を取ります。イージングは `with_easing`、実行中の周期上限は `max_fps` で設定します。

## 対応するプロパティ

`TransitionProperties` は背景、境界線の色と幅、角丸、文字色、ボックスシャドウ、不透明度、変換を対象にします。幅、高さ、パディングは補間しません。

## マウントと視差効果の抑制

コンポーネントが対応している場合は、閉じるアニメーションが終わるまでオーバーレイをマウントしたままにします。システムの「視差効果を減らす」設定に従ってください。フレームループでアニメーションを駆動しないでください。

## アニメーション画像

`img` はアニメーション GIF と WebP を再生します。タイマーは不要です。[Image](/docs/rust/components/image) を参照してください。
