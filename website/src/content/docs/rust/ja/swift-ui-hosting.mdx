`SwiftUiModifier` 値は宣言順に適用します。`style`、`control_size`、`disabled` などのビルダーはそれらのモディファイアを追加します。

## モディファイア

ボタンスタイル、境界形状、コントロールサイズ、ラベルスタイル、ティント、無効状態に対応しています。`sync` の前にディスクリプターへ適用します。

## Liquid Glass

```rust
SwiftUiButton::new(1)
    .label("Continue")
    .style(SwiftUiButtonStyle::Glass)
    .control_size(SwiftUiControlSize::Large)
```

macOS は利用できる場所でガラスを描画します。

## リバースホスティング

```rust
SwiftUiQuickGuiHost::pending(1)
```

`SwiftUiQuickGuiHost` と `MacSwiftUiHost::set_embedded_view` で、QuickGUI の内容を SwiftUI へ戻して埋め込みます。

## SwiftUI ポップオーバー

`SwiftUiPopover` には明示的な `trigger` と `content` のリストがあります。その内容の `SwiftUiQuickGuiHost` が通常の QuickGUI コンポーネントをホストします。

## ライフサイクル

`MacSwiftUiHost` をドロップするとネイティブビューが解放されます。埋め込みサーフェスはホストとともに、提示されたパネルは所有者とともに破棄されます。
