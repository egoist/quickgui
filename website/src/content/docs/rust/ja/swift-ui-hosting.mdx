`SwiftUiModifier` の値は、宣言した順に適用します。`style`、`control_size`、`disabled` などの便利なビルダーは、それらのモディファイアを追加します。

## モディファイア

ボタンスタイル、ボーダーの形、コントロールサイズ、ラベルスタイル、ティント、無効状態に対応しています。`sync` の前にディスクリプターへ適用します。

## Liquid Glass

```rust
SwiftUiButton::new(1)
    .label("Continue")
    .style(SwiftUiButtonStyle::Glass)
    .control_size(SwiftUiControlSize::Large)
```

macOS は、利用できる場所にガラスを描画します。

## リバースホスティング

```rust
SwiftUiQuickGuiHost::pending(1)
```

`SwiftUiQuickGuiHost` と `MacSwiftUiHost::set_embedded_view` で、QuickGUI のサブツリーを埋め込みます。

## SwiftUI ポップオーバー

`SwiftUiPopover` には `trigger` と `content` の要素リストがあります。その `content` 内の `SwiftUiQuickGuiHost` が、通常の QuickGUI の子をホストします。

## ライフサイクル

`MacSwiftUiHost` をドロップすると、ネイティブビューが解放されます。表示中のパネルは、オーナーと一緒に閉じます。
