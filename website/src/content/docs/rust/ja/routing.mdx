ルーターは現在のパスからマッチを選び、戻る／進む履歴を保持します。ビューはマッチしたツリーをマウントします。

## ルートの宣言

```rust
let router = Router::new(
    [
        RouteDefinition::new("home", "/"),
        RouteDefinition::new("project", "/projects/:id"),
    ],
    "/",
)?;
```

`RouteDefinition::layout` はパスなしの祖先を宣言します。相対の子パスは親に結合され、絶対の子パスはルートから始まります。

## 入れ子のレイアウト

ルートチェーンをマッチし、内側の内容をレイアウト要素で包みます。パスなしレイアウトは URL セグメントを増やさずに `matched` の祖先に現れます。

```rust
RouteDefinition::layout("shell").parent("root")
```

## ナビゲーション

```rust
self.router.push("/projects/42")?;
cx.invalidate();
```

ルーターは `push`、`replace`、`back`、`forward` に対応します。ナビゲーションはアプリ内に留まります。

## ルートパラメーター

```rust
if let Some(matched) = self.router.matched() {
    let id = matched
        .params()
        .iter()
        .find(|param| param.name() == "id")
        .map(|param| param.value())
        .unwrap_or("");
    text(format!("Project {id}"))
} else {
    text("Page not found")
}
```

クエリの組は `RouteLocation` にあります。
