Implement `View` for application components. Primitives are functions that return `Element`. Compound components are copyable descriptors whose `*_part` methods decorate caller-owned elements.

## Defining components

```rust
struct Greeting {
    name: String,
}
impl View for Greeting {
    fn render(&mut self, _cx: &mut ViewContext<'_, Self>) -> impl IntoElement {
        text(format!("Hello, {}", self.name))
    }
}
```

Child views can also be functions that return `Element` when they have no retained state.

## Primitives

`div`, `text`, `button`, `text_input`, `text_area`, `Markdown`, `img`, `svg`, `custom_shader`, `VirtualList`, and optional `Terminal` are native building blocks. `submit_button` submits the nearest `form`.

## Compound components

```rust
let checkbox = Checkbox::new(self.checked);
checkbox
    .root_part(div().flex_row().gap(8.0).on_click(toggle))
    .child(checkbox.indicator_part(div().size(16.0, 16.0)))
    .child(text("Remember this device"))
```

Compound roots coordinate named parts through ids and state you store on the view. Keep parts under the intended root so focus and value relationships stay explicit.

## Controlled state

Store values on the view and pass them into constructors such as `Checkbox::new`, `SliderState`, or `text_input`. Update those fields from listeners, then `invalidate`. There is no separate `defaultValue` layer: the view owns the state.

## Component families

The reference covers selection controls, tabs, disclosure, fields, menus, context menus, pickers, dialogs, popovers, preview cards, drawers, navigation menus, ranges, splitters, progress, meters, toggles, toolbars, toasts, calendars, date/time fields, scroll areas, tables, trees, and SwiftUI controls. Run `examples/base_ui_components.rs` for a gallery.

## Styling parts

Apply fluent style methods to each visual part. Parts remain unstyled so layout and colors belong to the application. State types such as `SliderState`, `TabsState`, `SelectState`, and `ScrollAreaState` expose the current native state for custom presentation.
