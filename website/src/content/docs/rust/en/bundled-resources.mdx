Use `resources` to ship files that are not compiled into the executable: images, templates, JSON, and other data. The CLI copies each path into the packaged app under its basename. The running app reads them from `AppPaths::resource_dir()`, which does not depend on the launch working directory.

To embed bytes at compile time instead, use `BundledAssets` and `Application::assets`. Custom fonts are a separate option. See [Fonts](#fonts).

## Configuration

```ts
import { defineConfig } from "@quickgui/cli";

export default defineConfig({
  language: "rust",
  name: "My App",
  identifier: "com.example.my-app",
  entry: ".",
  resources: ["assets", "copy/template.txt"],
  fonts: ["assets/MyFont.ttf"],
});
```

Each entry is a file or a directory. Relative paths resolve from the project directory. Destination names must be unique and must not replace reserved names such as `fonts`, `AppIcon.icns`, or `quickgui.json`.

`quickgui dev` and `quickgui build` both stage these files. Missing paths fail the build. Rust identity and font paths are written to `quickgui.json` in the same resource directory.

## Install locations

| Platform | Resource directory |
| --- | --- |
| macOS `.app` | `Contents/Resources` |
| Linux AppDir, AppImage, and `.deb` | Next to the executable (`usr/bin`) |
| Windows installer | Next to the executable in `$INSTDIR` |

A configured path `assets` is installed as `assets/` in that directory. A file `copy/template.txt` is installed as `template.txt`. Join those names onto `resource_dir()` at runtime; do not read from the project tree or the current working directory.

## Loading files

```rust
let hero = cx
    .app_paths()
    .unwrap()
    .resource_dir()
    .join("assets/hero.png");

img(hero).size(160.0, 120.0)
```

`img` accepts a filesystem path. Other files use the same join: `std::fs::read` the path, or load a compile-time `BundledAssets` map when the bytes should live inside the binary.

```rust
let bundle = BundledAssets::new()
    .with("copy/template.txt", include_bytes!("../assets/template.txt"))?;
let assets = Assets::new(bundle);
```

Relative image paths are not resolved against the resource directory.

## Fonts

`fonts` lists OpenType files. The CLI copies them into `fonts/` inside the resource directory and registers them from `quickgui.json` before the first window opens.

```ts
export default defineConfig({
  language: "rust",
  name: "My App",
  identifier: "com.example.my-app",
  entry: ".",
  fonts: ["assets/MyFont.ttf"],
});
```

You can also call `Application::font` with bytes or an asset path. Fonts are not a replacement for `resources`: an image or JSON file still belongs in `resources` or `BundledAssets`.
