A retained native code editor with syntax coloring, line numbers, indentation, and both-axis scrolling.

No language grammars are included by default. Register a linked grammar in Rust, or load one portable pack of selected Tree-sitter Wasm grammars and queries using `loadLanguagePack` (TypeScript) / `LoadLanguagePack` (Go).

Unstyled by default: text and line-number colors inherit, and the component adds no background, border, rounding, padding, or syntax/diff palette. Supply application styles and explicit colors to opt into an appearance.

## Import

```sh
bun add @quickgui/extension-editor
```

```tsx
import { createSignal } from "solid-js";
import { Editor, loadLanguagePack } from "@quickgui/extension-editor";
```

```ts
// quickgui.config.ts
extensions: ["@quickgui/extension-editor"]
```

## Usage

```tsx
const [source, setSource] = createSignal("export function answer() { return 42; }\n");

<Editor
  value={source()}
  language="typescript"
  lineNumbers
  tabSize={2}
  onInput={(event) => setSource(event.value ?? "")}
  style={{ width: "100%", height: 360 }}
/>;
```

## Syntax highlighting

`language` selects a registered Tree-sitter grammar and highlight query. Query captures map through `syntaxTheme` to eight foreground-only paint classes, so color never changes text metrics. Source or language changes reparse the bounded document; palette changes only remap retained captures, and scrolling does no syntax work. Parsing is limited to 2 MiB, individual lines over 32 KiB stay plain, and the capture count is capped. This does not require a language server.

## Key props

| Prop           | Purpose                                                            |
| -------------- | ------------------------------------------------------------------ |
| `value`        | Controlled UTF-8 source. Commit `onInput` back to the same signal. |
| `language`     | Syntax language such as `"typescript"`, `"rust"`, or `"go"`.       |
| `lineNumbers`  | Shows or hides the paint-only logical-line gutter.                 |
| `tabSize`      | Indentation width, clamped by the Rust core.                       |
| `insertSpaces` | Inserts spaces instead of a tab character.                         |
| `autoIndent`   | Carries the current indentation onto a new line.                   |
| `readOnly`     | Keeps selection and scrolling while rejecting edits.               |
| `syntaxTheme`  | Overrides Tree-sitter capture colors.                              |
| `onInput`      | Reports the complete bounded source after an accepted edit.        |
| `style`        | QuickGUI layout and paint styles for the retained editor.          |

The native caret remains functional without styling. Active-line fills and focus borders are opt-in.

## Language packs

No grammars are compiled into the default component. Build selected Tree-sitter parsers as `.wasm` files, then bundle them with text queries into one portable pack. The configuration maps `grammars` to Wasm file paths and lists `languages` with `name`, `grammar`, aliases, extensions, and query file paths. Declared language dependencies are included automatically; shared grammars are stored once.

```sh
quickgui pack-languages languages.json --languages lua,rust --out resources/languages.qglang
```

```ts
await loadLanguagePack("/absolute/path/languages.qglang");
// Editor and CodeBlock can now select language="lua".
```

Load once after application readiness using the packaged resource directory. The pack is a binary ustar file with a JSON manifest, text queries, and raw Wasm modules—no base64, decompression, or file extraction. Identical loads are no-ops; conflicts fail atomically. Rust can instead register an application-linked grammar with `register_syntax_language` using only `features = ["editor"]`.
