シンタックスカラー、行番号、インデント、両軸スクロールに対応した保持型ネイティブコードエディターです。

既定では見た目のスタイルを持ちません。文字と行番号の色は継承され、背景、枠線、角丸、余白、構文・差分の配色は追加されません。外観はアプリ側で明示的に指定します。

## インポート

```sh
bun add @quickgui/extension-editor
```

```tsx
import { createSignal } from "solid-js";
import { Editor } from "@quickgui/extension-editor";
```

```ts
// quickgui.config.ts
extensions: ["@quickgui/extension-editor"]
```

## 使い方

```tsx
const [source, setSource] = createSignal("export function answer() { return 42; }\n");

<Editor
  value={source()}
  language="typescript"
  lineNumbers
  tabSize={2}
  onInput={(event) => setSource(event.value ?? "")}
  style={{ width: "100%", height: 360 }}
/>;
```

## シンタックスハイライト

`language` は同梱の Tree-sitter 文法とハイライトクエリを選択します。クエリのキャプチャは `syntaxTheme` を通して 8 種類の前景色だけの描画クラスへ変換されるため、色はテキスト寸法を変えません。ソースまたは言語が変わると上限付きドキュメントを再解析し、配色変更では保持済みキャプチャだけを再マッピングします。スクロール時に構文処理は行いません。解析は最大 2 MiB、32 KiB を超える単一行は通常色のまま、キャプチャ数にも上限があり、言語サーバーは不要です。

## 主なプロパティ

| プロパティ     | 説明                                                                |
| -------------- | ------------------------------------------------------------------- |
| `value`        | 制御された UTF-8 ソースです。`onInput` を同じシグナルへ反映します。 |
| `language`     | `"typescript"`、`"rust"`、`"go"` などの構文言語です。               |
| `lineNumbers`  | 描画のみで構成される論理行番号ガターを表示または非表示にします。    |
| `tabSize`      | Rust コアが範囲を制限するインデント幅です。                         |
| `insertSpaces` | タブ文字の代わりに空白を挿入します。                                |
| `autoIndent`   | 改行時に現在のインデントを引き継ぎます。                            |
| `readOnly`     | 選択とスクロールを保ちながら編集を拒否します。                      |
| `syntaxTheme`  | Tree-sitter キャプチャの色を上書きします。                          |
| `onInput`      | 受理された編集後の、上限付き完全ソースを通知します。                |
| `style`        | 保持型エディターの QuickGUI レイアウトおよび描画スタイルです。      |

キャレットはスタイルなしでも機能します。アクティブ行の背景とフォーカス枠は明示的に指定します。
