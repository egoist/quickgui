可选择、无插入光标的代码视图，支持 Tree-sitter 着色和逻辑行虚拟化。

默认不包含任何语言语法。Rust 可注册静态链接的语法；Go 和 TypeScript 可通过 `LoadLanguagePack` / `loadLanguagePack` 加载单个跨平台包，其中包含所选 Tree-sitter Wasm 语法与查询。

组件默认不带视觉样式：文本和行号继承颜色，不添加背景、边框、圆角、内边距或语法／差异配色。外观由应用显式提供样式与颜色。

## 导入

```sh
bun add @quickgui/extension-editor
```

```tsx
import { CodeBlock } from "@quickgui/extension-editor";
```

```ts
// quickgui.config.ts
extensions: ["@quickgui/extension-editor"]
```

## 用法

```tsx
<CodeBlock
  value={"export function answer(): number { return 42; }\n"}
  language="typescript"
  lineNumbers
  wrap={false}
  style={{ width: "100%", height: 280 }}
/>
```

## 语法高亮

`language` 选择已注册的 Tree-sitter 语法和高亮查询。捕获结果通过 `syntaxTheme` 映射为只影响前景色的区间，因此高亮不会改变布局。源码或语言变化时由 Rust 核心解析；滚动只挂载逻辑行并创建预先计算的区间。解析最多处理 2 MiB，超过 32 KiB 的单行保持普通颜色，捕获数量也有上限。

## 主要属性

| 属性               | 说明                                                |
| ------------------ | --------------------------------------------------- |
| `value`            | UTF-8 源码字符串或响应式表达式。                    |
| `language`         | 内置语法，例如 `"typescript"`、`"rust"` 或 `"go"`。 |
| `lineNumbers`      | 显示固定在左侧且不可选择的逻辑行号栏。              |
| `wrap`             | 对长行换行，而不是启用横向滚动。                    |
| `gutterBackground` | 覆盖行号栏背景色。                                  |
| `gutterColor`      | 覆盖行号前景色。                                    |
| `syntaxTheme`      | 覆盖八种共享 Tree-sitter 捕获颜色。                 |
| `style`            | 设置保留式代码块的 QuickGUI 布局与绘制样式。        |

CodeBlock 可选择，但没有输入监听器、插入光标、IME 状态、撤销栈或焦点环。需要用户修改源码时请使用 Editor。
