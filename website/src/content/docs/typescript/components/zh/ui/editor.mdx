保留式原生代码编辑器，支持语法着色、行号、缩进和双轴滚动。

组件默认不带视觉样式：文本和行号继承颜色，不添加背景、边框、圆角、内边距或语法／差异配色。外观由应用显式提供样式与颜色。

## 导入

```sh
bun add @quickgui/extension-editor
```

```tsx
import { createSignal } from "solid-js";
import { Editor } from "@quickgui/extension-editor";
```

```ts
// quickgui.config.ts
extensions: ["@quickgui/extension-editor"]
```

## 用法

```tsx
const [source, setSource] = createSignal("export function answer() { return 42; }\n");

<Editor
  value={source()}
  language="typescript"
  lineNumbers
  tabSize={2}
  onInput={(event) => setSource(event.value ?? "")}
  style={{ width: "100%", height: 360 }}
/>;
```

## 语法高亮

`language` 选择内置的 Tree-sitter 语法和高亮查询。查询捕获结果通过 `syntaxTheme` 映射为八种只影响前景色的绘制类别，因此颜色不会改变文本尺寸。源码或语言变化时重新解析受限文档；调色板变化只重新映射已有捕获，滚动不会执行语法分析。解析最多处理 2 MiB，超过 32 KiB 的单行保持普通颜色，捕获数量也有上限，且不需要语言服务器。

## 主要属性

| 属性           | 说明                                                |
| -------------- | --------------------------------------------------- |
| `value`        | 受控 UTF-8 源码；将 `onInput` 写回同一信号。        |
| `language`     | 语法语言，例如 `"typescript"`、`"rust"` 或 `"go"`。 |
| `lineNumbers`  | 显示或隐藏仅绘制的逻辑行号栏。                      |
| `tabSize`      | 缩进宽度，由 Rust 核心限制范围。                    |
| `insertSpaces` | 插入空格而不是制表符。                              |
| `autoIndent`   | 新建行时沿用当前缩进。                              |
| `readOnly`     | 保留选择与滚动，同时拒绝编辑。                      |
| `syntaxTheme`  | 覆盖 Tree-sitter 捕获颜色。                         |
| `onInput`      | 接受编辑后报告完整且受限的源码。                    |
| `style`        | 保留式编辑器的 QuickGUI 布局与绘制样式。            |

原生光标不依赖视觉样式；活动行背景和焦点边框均需显式设置。
