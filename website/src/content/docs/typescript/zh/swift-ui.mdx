从 `@quickgui/solid/swift-ui` 导入 SwiftUI 控件，并用 `Host` 包裹。它们是 QuickGUI 窗口中真正的 macOS 控件。普通 QuickGUI 组件无需依赖它们。

## Host

```tsx
import { Host, Button } from "@quickgui/solid/swift-ui";

<Host matchContents>
  <Button label="Continue" />
</Host>
```

## 原生控件

可用控件包括按钮、标签、开关、滑块、步进器、进度视图、仪表、文本和安全输入、选择器、分段控件、日期和颜色选择器以及浮窗。每个组件页面列出其 props 和事件。

## 受控值

```tsx
import { Host, Toggle } from "@quickgui/solid/swift-ui";

<Host matchContents>
  <Toggle label="Notifications" isOn={enabled()} onIsOnChange={setEnabled} />
</Host>
```

SwiftUI 控件和 QuickGUI 节点可以共享同一个信号。

## 尺寸

`matchContents` 根据控件确定 Host 尺寸，并在支持的情况下提供按轴选项。只希望高度随内容变化时，请约束父级宽度。

## 平台支持

SwiftUI 托管仅支持 macOS。Liquid Glass 等可选外观跟随操作系统。参见[修饰器与托管](/docs/typescript/swift-ui-hosting)。
