Solid 组件在挂载时运行一次。在 JSX 中读取信号，让文本和属性保持同步。

## 响应式状态

用 `createSignal` 创建信号。需要保持实时时，在 JSX 中读取它。在初始化阶段读取则是快照。

```tsx
const [count, setCount] = createSignal(0);
<Text>Count: {count()}</Text>
<Button onClick={() => setCount(count() + 1)}>Increment</Button>
```

## 派生状态

用 `createMemo` 计算依赖其他信号的值。保持计算纯净；从事件或副作用中写入。

```tsx
const doubled = createMemo(() => count() * 2);
<Text>{doubled()}</Text>
```

## 副作用与清理

用 `createEffect` 处理视图之外的工作，例如订阅。注册清理逻辑，以便关闭窗口或移除分支时停止该工作。

```tsx
import { createEffect, onCleanup } from "solid-js";

createEffect(
  () => count(),
  (value) => console.log(value),
);
const stop = watchProject();
onCleanup(stop);
```

## 批量更新

事件处理函数中的信号写入会一起刷新。测试中若断言需要 UI 立即稳定，请使用 `flush()`。
