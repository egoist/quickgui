用元素上的 `transition` 为样式变化添加动画。组件不会为每一帧重新运行。

## 悬停过渡

```tsx
<Button
  style={{
    bg: "#2563eb",
    transition: { property: "bg", duration: 160 },
    hover: { bg: "#1d4ed8" },
  }}
>
  Hover
</Button>
```

## 状态驱动的动画

根据应用状态改变样式。节点保持挂载，同时颜色、透明度和其他受支持属性进行动画。

## 时长与帧率

时长接受数字或 `"180ms"` 这样的字符串。需要时设置缓动和 `maxFps`。`maxFps` 仅在动画运行期间生效。

## 支持的属性

过渡覆盖背景、边框、圆角、文本颜色、透明度、阴影和变换。宽度、高度和内边距不会插值。完整列表见 `@quickgui/solid` 中带类型的过渡属性联合。

## 挂载与减少动态效果

若组件支持，请让浮层保持挂载直到关闭动画结束。遵循窗口上的 `reduceMotion` 以及系统偏好。不要用 JavaScript 定时器驱动动画。

## 动态图像

`Image` 会播放动态 GIF 和 WebP 文件。不需要定时器。参见 [Image](/docs/typescript/components/image)。
