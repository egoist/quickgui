路由器根据当前路径选择组件，并保留前进/后退历史。路由在当前窗口中渲染。

## 路由声明

```tsx
import { Router, Route, Link } from "@quickgui/solid/router";

<Router initialPath="/">
  <Route path="/" component={() => <Text>Home</Text>} />
  <Route path="/projects/:id" component={Project} />
</Router>
```

## 嵌套布局

嵌套路由相对于其父路由。在下一层匹配应出现的位置渲染 `<Outlet />` 或布局的 `children`。无路径路由可以共享布局，而不增加 URL 段。

```tsx
<Route
  path="/"
  component={(props) => (
    <View>
      <Link href="/">Home</Link>
      <Link href="/settings">Settings</Link>
      {props.children}
    </View>
  )}
>
  <Route path="/" component={() => <Text>Home</Text>} />
  <Route path="/settings" component={() => <Text>Settings</Text>} />
</Route>
```

## 导航

```tsx
const navigate = useNavigate();
<Button onClick={() => navigate("/projects/42")}>Open project</Button>
<Link href="/">Home</Link>
```

`navigate` 支持 push、replace、back 和 forward。导航始终在应用内部进行。

## 路由参数

```tsx
function Project() {
  const params = useParams();
  return <Text>Project {params().id}</Text>;
}
```

`useLocation()` 和 `useSearchParams()` 返回会随 URL 更新的访问器。重复的查询键是数组。
