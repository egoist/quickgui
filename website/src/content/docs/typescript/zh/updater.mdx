安装 `@quickgui/extension-updater` 即可提供自动更新。

## 配置

```sh
bun add @quickgui/extension-updater
```

生成签名密钥，然后将公钥复制到项目中：

```sh
bunx @quickgui/cli keygen --sparkle --out-dir "$HOME/.config/my-app/update-keys"
cp "$HOME/.config/my-app/update-keys/quickgui-update.pub" ./update-public-key.pub
```

不要将 `quickgui-update.key` 纳入版本控制。

```ts
import { readFileSync } from "node:fs";
import { defineConfig } from "@quickgui/cli";

export default defineConfig({
  language: "typescript",
  name: "My App",
  identifier: "com.example.my-app",
  version: "1.0.0",
  entry: "app.tsx",
  extensions: ["@quickgui/extension-updater"],
  updates: {
    baseUrl: "https://downloads.example.com/my-app",
    publicKey: readFileSync(
      new URL("./update-public-key.pub", import.meta.url),
      "utf8",
    ).trim(),
    automaticChecks: true,
  },
});
```

`darwin-arm64` 构建会检查 `https://downloads.example.com/my-app/appcast-darwin-arm64.xml`，除非用 `updates.feedUrl` 覆盖。该 URL 中的 `{target}` 会被展开。私钥仅在使用 `--update-manifest` 签名时使用。

## 应用用法

在 `app.whenReady()` 之后、在组件之外启动更新器，让所有窗口共享同一个会话：

```ts
import { app } from "@quickgui/native";
import Updater from "@quickgui/extension-updater";

await app.whenReady();

export const updater = new Updater({}, (event) => {
  if (event.error) console.error(event.error);
  if (event.quitRequired) {
    void app.quit().catch(console.error);
  }
});

await updater.ready;
```

```tsx
import { Button } from "@quickgui/solid";
import { updater } from "./updates";

export function CheckForUpdatesButton() {
  return (
    <Button p-3 rounded-lg onClick={() => {
      void updater.check().catch(console.error);
    }}>
      Check for Updates
    </Button>
  );
}
```

## 生命周期

如果启动失败，`updater.ready` 会拒绝。各命令返回 Promise。

| API | 用途 |
| --- | --- |
| `updater.check()` | 检查是否有更新。 |
| `updater.install()` | 安装已有的更新。 |
| `updater.setAutomaticChecks(enabled)` | 更改自动检查偏好。 |
| `updater.state` | 读取最近一次事件。 |
| `updater.close()` | 停止会话。 |

状态为 `idle`、`checking`、`available`、`downloading`、`installing` 或 `disabled`。关闭窗口时不得关闭共享的更新器。

开发构建会保持禁用，除非传入 `{ allowDevelopment: true }`，并提供测试更新源和可丢弃的应用包。

## 平台支持

macOS 使用 Sparkle。Windows 使用已签名的 NSIS 安装包；Linux 使用 AppImage。预构建的更新器软件包目前覆盖 macOS。通过 Linux 软件包管理器安装的版本会报告 `disabled`。

## 发布更新

每次发布时递增 `quickgui.config.ts` 中的 `version`。加载私钥：

```sh
export QUICKGUI_UPDATER_PRIVATE_KEY="$(cat "$HOME/.config/my-app/update-keys/quickgui-update.key")"
```

```sh
bunx @quickgui/cli build --target darwin-arm64 --update-manifest \
  --sign "Developer ID Application: Example (TEAMID)" \
  --notarize my-app-notary
```

先上传已签名的归档，再上传生成的 `appcast-darwin-arm64.xml`。Intel Mac 请再用 `--target darwin-x64` 重复一次。每种架构都有各自的更新源。

在 CI 中将 `QUICKGUI_UPDATER_PRIVATE_KEY` 存为密钥。也接受 `SPARKLE_PRIVATE_KEY`。本地签名时，`updates.ed25519SecretKey` 可以指向密钥文件。设置 `updates.manifest: true` 可在每次生产构建时生成更新源。

## 原生产物

只要在 `extensions` 中列出该软件包，生产构建就会包含更新器。最终用户运行打包后的应用即可，无需安装额外的更新器工具。
