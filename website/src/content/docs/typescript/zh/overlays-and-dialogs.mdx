窗口内界面使用 QuickGUI 浮层；文件选择和警告使用系统对话框。

## Popover

组合 `Popover.Root`、触发器、portal、定位器、弹出层、箭头、标题、说明和关闭。放置与关闭由系统处理。使用受控的 `open` 或默认打开选项。

## Dialog

`Dialog` 和 `AlertDialog` 增加模态行为，以及标题、说明、背景、视口和关闭部件。焦点通过对话框自身的生命周期返回；不要再加第二层焦点陷阱。

## 系统浮窗

`SystemPopover` 是锚定到已挂载节点的操作系统面板。它可以延伸到父窗口之外。随其所有者一起释放。

## 原生对话框

```tsx
import { Dialog } from "@quickgui/native";

const choice = await Dialog.showAlertDialog({
  message: "Save changes?",
  buttons: [{ label: "Save" }, { label: "Cancel", role: "cancel" }],
});
const result = await Dialog.showOpenDialog({
  properties: ["openFile", "multiSelections"],
});
```
