QuickGUI 的 TypeScript 应用使用 Solid 2 JSX。用 TypeScript 编写窗口和组件，CLI 负责运行、热重载并打包原生 macOS 应用。

## 系统要求

- macOS 14 或更新版本
- Bun 1.4 或更新版本
- Xcode Command Line Tools（`xcode-select --install`）

脚手架会固定 Solid 2 和 TypeScript 7。当前打包的应用面向 macOS。

## 创建项目

```sh
bunx @quickgui/cli init my-app --language typescript
cd my-app
bun run dev
```

CLI 会创建项目、安装依赖并打开应用。省略 `--language typescript` 可在提示时选择语言。

## 第一个窗口

生成的 `app.tsx` 会等待应用就绪、打开窗口，并渲染一个 Solid 组件。

```tsx
import { createSignal } from "solid-js";
import { app, Window } from "@quickgui/native";
import { Button, Text, View, createRenderer } from "@quickgui/solid";

function Counter() {
  const [count, setCount] = createSignal(0);
  return (
    <View
      width="100%"
      height="100%"
      display="flex"
      flexDirection="column"
      alignItems="center"
      justifyContent="center"
      gap={16}
    >
      <Text fontSize={24}>Count: {count()}</Text>
      <Button padding={12} onClick={() => setCount(count() + 1)}>
        Increment
      </Button>
    </View>
  );
}

function openWindow() {
  new Window({
    title: "My App",
    width: 640,
    height: 460,
    renderer: createRenderer(Counter),
  });
}

app.on("reopen", ({ hasVisibleWindows }) => {
  if (!hasVisibleWindows) openWindow();
});
await app.whenReady();
openWindow();
```

在 JSX 中读取 `count()` 可让该文本保持同步。点击按钮会更新信号，窗口其余部分保持不变。

## 运行与构建

在项目目录中执行：

```sh
bun run check
bun run test
bun run dev
bun run build
```

`dev` 会在编辑时重新构建。`check` 进行类型检查。`build` 将打包后的应用写入 `dist/`，在 macOS 上包含 `.app` 和 DMG。
