## 生成的文件

The scaffold contains `app.tsx`, `quickgui.config.ts`, `tsconfig.json`, and `package.json`. Keep reusable components and application data access in ordinary TypeScript modules. Generated build files live in `.quickgui` and release artifacts in `dist`.

## 应用入口

Import `app` and `Window` from `@quickgui/native`; import components and `createRenderer` from `@quickgui/solid`. Await `app.whenReady()` before opening windows. Each window owns and disposes one renderer root. The CLI starts the event consumer; application code does not call `app.run()`.

## 配置

```tsx
import { defineConfig } from "@quickgui/cli";
export default defineConfig({
  language: "typescript", name: "My App", identifier: "com.example.my-app",
  entry: "app.tsx", fonts: ["assets/MyFont.ttf"], resources: ["assets"],
});
```

TOML supports the same configuration keys. Set `jsx` to `preserve` and `jsxImportSource` to `@quickgui/solid` in `tsconfig.json`; the CLI applies the Solid universal transform.

## 软件包

Applications depend directly on `@quickgui/native`, `@quickgui/solid`, and `solid-js`. `@quickgui/cli`, TypeScript, and Bun type definitions are development dependencies. Optional terminal and updater extensions are separate packages.

## 本地开发

```sh
bun install
bun run build:native
bun run --cwd examples/components-typescript dev
bun run --cwd examples/quick-git-typescript dev
```

Use `quickgui check` for typechecking and `quickgui test` for application tests with the same Solid compiler and reactive client runtime as packaged builds.
