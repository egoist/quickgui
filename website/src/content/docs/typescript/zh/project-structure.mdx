生成的项目是一个 TypeScript 应用，外加一个小型 Bun 包来提供开发命令。

## 生成的文件

```text
my-app/
├── app.tsx
├── quickgui.config.ts
├── tsconfig.json
├── package.json
└── README.md
```

把可复用组件和数据访问放在普通 TypeScript 模块中。生成文件位于 `.quickgui`；发布构建输出到 `dist/`。

## 应用入口

`app.tsx` 从 `@quickgui/native` 导入 `app` 和 `Window`，从 `@quickgui/solid` 导入组件和 `createRenderer`。打开窗口前请先等待 `app.whenReady()`。每个窗口拥有自己的渲染器；关闭窗口会释放该渲染器。

不要在应用代码中调用 `app.run()`。应用由 CLI 启动。

## 配置

```ts
import { defineConfig } from "@quickgui/cli";

export default defineConfig({
  language: "typescript",
  name: "My App",
  identifier: "com.example.my-app",
  entry: "app.tsx",
  fonts: ["assets/MyFont.ttf"],
  resources: ["assets"],
});
```

`quickgui.toml` 接受相同的配置项。在 `tsconfig.json` 中，将 `jsx` 设为 `preserve`，将 `jsxImportSource` 设为 `@quickgui/solid`。

## 软件包

| 软件包 | 用途 |
| --- | --- |
| `@quickgui/native` | 窗口、菜单、对话框等平台 API |
| `@quickgui/solid` | 组件和 JSX |
| `solid-js` | 信号、memo 和副作用 |
| `@quickgui/cli` | `dev`、`check`、`test` 和 `build` |

终端和更新器支持是可选软件包。参见[编写扩展](/docs/typescript/extensions)。

## 本地开发

```sh
bun run dev
bun run check
bun run test
bun run build
```

`dev` 会在编辑时重新加载 TypeScript。
