SwiftUI 修饰器为原生控件设置样式。反向托管把 QuickGUI 内容放进 SwiftUI。

## 修饰器

按顺序应用 `@quickgui/solid/swift-ui/modifiers` 中的修饰器工厂。包括控件尺寸、色调、禁用、标签样式、按钮边框形状和按钮样式。

## Liquid Glass

```tsx
<Button label="Continue" modifiers={[buttonStyle("glass"), controlSize("large")]} />
```

macOS 在可用时绘制玻璃效果。

## 反向托管

```tsx
<Host matchContents>
  <QuickGUIHostView width={320} height={180}>
    <View padding={16}>
      <Text>QuickGUI inside SwiftUI</Text>
    </View>
  </QuickGUIHostView>
</Host>
```

## SwiftUI Popover

用 `Popover.Trigger` 搭配 SwiftUI 控件，用 `Popover.Content` 提供呈现的树。该内容中的 `QuickGUIHostView` 可托管普通 QuickGUI 组件。

## 生命周期

嵌入表面随其 Host 一起释放。已呈现的面板随其所有者一起释放。不要通过全局订阅让已分离的 Host 继续存活。
