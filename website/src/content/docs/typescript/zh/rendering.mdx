组件在挂载时运行，并返回应显示的树。之后的信号更新会改变绑定的文本和属性。当子节点结构本身会变化时，使用 `<Show>` 和 `<For>`。

## 渲染模型

从组件返回原生 JSX。布局、绘制、焦点和无障碍都是原生的。你不会渲染到 HTML。

```tsx
<View padding={20} gap={12}>
  <Text>Hello</Text>
  <Button onClick={() => {}}>Continue</Button>
</View>
```

## 条件内容

初始化阶段的普通 `if` 只在组件创建时运行。子节点稍后需要出现或消失时，使用 `<Show>`。

```tsx
<Show when={expanded()} fallback={<Text>Collapsed</Text>}>
  <Text>Expanded content</Text>
</Show>
```

移除该分支会释放其副作用和节点。兄弟节点保持各自的身份。

## 列表与节点身份

```tsx
<For each={items()}>{(item) => <Text>{item.name}</Text>}</For>
```

为有状态的行提供稳定身份（例如 id），而不是位置。重排序会移动已有行。大型集合请使用 `Table` 或 `Tree`，以便只挂载可见行。

## 窗口生命周期

每个 `Window` 都有自己的 Solid 根。关闭一个窗口不会释放其兄弟窗口。在 macOS 上，当 Dock 重新打开并报告 `hasVisibleWindows` 为 false 时，打开一个新窗口。

## 当前窗口

```tsx
function Content() {
  const window = Window.getCurrentWindow();
  return <Button onClick={() => window.close()}>Close</Button>;
}
```

在初始化阶段捕获窗口，或把它传入后续的异步工作。

## 检查、测试与调试

```sh
bun run check
bun run test
```

`check` 使用与应用相同的 JSX 转换进行类型检查。`test` 运行应用测试。
