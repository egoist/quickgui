把字段值保存在信号中，并从回调把已接受的更改写回。

## 文本输入

```tsx
const [value, setValue] = createSignal("");
<Input
  value={value()}
  onInput={(event) => setValue(event.value ?? "")}
  placeholder="Name"
/>
<TextArea
  value={notes()}
  onInput={(event) => setNotes(event.value ?? "")}
/>
```

## 字段

`Field` 和 `Fieldset` 将标签、说明、控件和错误关联起来。由应用驱动有效性、touched 和 dirty 状态。验证模式和防抖在字段上设置。

## 选项

用指示器和标签组合 `Checkbox`、`CheckboxGroup`、`RadioGroup`、`Radio` 和 `Switch`。从每个根的变更回调更新受控状态。禁用与只读是分开的。

## 选择器

`Select`、`Combobox` 和 `Autocomplete` 接收选项列表。保持选项值稳定。状态 hook 会公开选择、查询、高亮和标签项，便于自定义部件。

## 事件

文本事件把字符串放在 `event.value` 中。指针、按键、手势、拖放和提交处理函数具有带类型的载荷。声明你需要的处理函数，控件才能发出对应事件。
