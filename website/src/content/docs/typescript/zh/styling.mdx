用 kebab-case 属性或带 camelCase 字段的 `style` 对象为原生组件设置样式。数值长度使用逻辑像素。

## 样式方法

`color` 和 `textColor` 设置继承的文本颜色。

```tsx
<View padding={16} gap={12} bg="#18181b" color="#fafafa" />
```

`flex-col`、`p-3`、`rounded-lg`、`items-center`、`text-lg`、`font-bold` 等辅助项是布尔属性。`p-3` 为 12 像素；`rounded-lg` 为 8 像素。它们不接受尺寸参数。自定义值请使用 `padding={14}`、`border-radius={10}` 或 `width="50%"`。

```tsx
<View flex-col p-3 gap-2 rounded-lg>
  <Text text-lg font-semibold>Panel title</Text>
</View>
```

将辅助项设为 `false`、`null` 或 `undefined` 会关闭它。

## 合并样式

样式数组从左到右合并。后面的字段覆盖前面的。假值项会被忽略。

```tsx
<View style={[base, selected() && selectedStyle, { padding: 20 }]} />
```

## 复用样式

用 `JSX.Style` 表示共享对象。需要保持实时时，在 JSX 中使用 getter。

```tsx
import type { JSX } from "@quickgui/solid";

const panel = { "p-3": true, "rounded-xl": true, bg: "#20242c" } satisfies JSX.Style;
<View style={panel}><Text>Reusable panel</Text></View>
```

## Flexbox

使用 `display`、`flexDirection`、`flexGrow`、`flexShrink`、对齐和 `gap`。在可伸缩的滚动子项上设置 `minWidth={0}` 或 `minHeight={0}`，以便它们可以缩小。

## 网格布局

使用 `display="grid"`，配合轨道列表、放置和跨度。

```tsx
<View display="grid" gridTemplateColumns="220px 1fr" gap={16}>
  <Text>Sidebar</Text>
  <Text>Content</Text>
</View>
```

## 文本与颜色

字族、字重、字号、换行、省略和选择都是原生文本。颜色接受十六进制、CSS 颜色字符串或打包的 RGBA 值。

## 交互状态

```tsx
<Button
  style={{
    bg: "#2563eb",
    hover: { bg: "#1d4ed8" },
    active: { opacity: 0.8 },
    focusVisible: { outlineColor: "#93c5fd", outlineWidth: 2 },
  }}
>
  Save
</Button>
```

## 分组与具名分组悬停

在祖先上设置 `group`，在后代上设置 `groupHover` 或 `groupActive`，即可一起设置样式。

```tsx
<View group="card" padding={20}>
  <Text color="#64748b" groupHover={{ color: "#2563eb" }}>
    Changes when the card is hovered
  </Text>
</View>
```
