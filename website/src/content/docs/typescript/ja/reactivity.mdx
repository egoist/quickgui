Solid コンポーネントはマウント時に一度実行されます。テキストとプロパティを同期するには、JSX でシグナルを読みます。

## リアクティブな状態

`createSignal` でシグナルを作成します。値をライブに保つときは JSX で読みます。セットアップ中の読み取りはスナップショットです。

```tsx
const [count, setCount] = createSignal(0);
<Text>Count: {count()}</Text>
<Button onClick={() => setCount(count() + 1)}>Increment</Button>
```

## 派生状態

他のシグナルから計算する値には `createMemo` を使います。計算は純関数のままにし、書き込みはイベントまたはエフェクトから行います。

```tsx
const doubled = createMemo(() => count() * 2);
<Text>{doubled()}</Text>
```

## 副作用とクリーンアップ

購読など、ビューの外の処理には `createEffect` を使います。ウィンドウを閉じたり分岐を外したりしたときに止まるよう、クリーンアップを登録します。

```tsx
import { createEffect, onCleanup } from "solid-js";

createEffect(
  () => count(),
  (value) => console.log(value),
);
const stop = watchProject();
onCleanup(stop);
```

## 更新のバッチ処理

イベントハンドラー内のシグナル書き込みはまとめて反映されます。テストで UI の確定をすぐ待つ必要があるときは `flush()` を使います。
