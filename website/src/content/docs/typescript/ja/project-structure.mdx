TypeScript プロジェクトでは、アプリケーションコードを `app.tsx` に、開発用コマンドを `package.json` に置きます。

## 生成されるファイル

```text
my-app/
├── app.tsx
├── quickgui.config.ts
├── tsconfig.json
├── package.json
└── README.md
```

再利用するコンポーネントは、通常の TypeScript モジュールに置きます。ビルド成果物は `.quickgui` に、パッケージ済みアプリは `dist` に出力されます。

## アプリケーションのエントリ

`app` と `Window` は `@quickgui/native` から、コンポーネントと `createRenderer` は `@quickgui/solid` からインポートします。ウィンドウを開く前に `app.whenReady()` を待ちます。各ウィンドウは独自のレンダラーを持ち、ウィンドウが閉じると破棄されます。

## 設定

```ts
import { defineConfig } from "@quickgui/cli";

export default defineConfig({
  language: "typescript",
  name: "My App",
  identifier: "com.example.my-app",
  entry: "app.tsx",
  icon: "assets/icon.png",
  fonts: ["assets/MyFont.ttf"],
  resources: ["assets"],
});
```

[アプリアイコン](/docs/typescript/app-icon)と[バンドルするリソース](/docs/typescript/bundled-resources)を参照してください。TOML でも同じキーを使えます。`tsconfig.json` では `jsx` を `"preserve"` に、`jsxImportSource` を `"@quickgui/solid"` に設定します。

## パッケージ

アプリケーションは `@quickgui/native`、`@quickgui/solid`、`solid-js` に依存します。`@quickgui/cli` は開発用の依存関係です。Terminal と updater はオプションのパッケージです。[自動更新](/docs/typescript/updater)と[拡張の作成](/docs/typescript/extensions)を参照してください。

## ローカル開発

```sh
quickgui check
quickgui test
quickgui fmt
quickgui dev
quickgui build
```

`check` はプロジェクトの型チェックを行います。`test` はビルドと同じコンパイラでテストを実行します。
