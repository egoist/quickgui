生成されるプロジェクトは TypeScript アプリに、開発コマンド用の小さな Bun パッケージを加えたものです。

## 生成されるファイル

```text
my-app/
├── app.tsx
├── quickgui.config.ts
├── tsconfig.json
├── package.json
└── README.md
```

再利用するコンポーネントとデータアクセスは通常の TypeScript モジュールに置きます。生成ファイルは `.quickgui` にあり、リリースビルドは `dist/` に出力されます。

## アプリケーションのエントリ

`app.tsx` は `@quickgui/native` から `app` と `Window` を、`@quickgui/solid` からコンポーネントと `createRenderer` をインポートします。ウィンドウを開く前に `app.whenReady()` を待ってください。各ウィンドウは独自のレンダラーを持ち、閉じると破棄されます。

アプリケーションコードから `app.run()` を呼ばないでください。アプリは CLI が起動します。

## 設定

```ts
import { defineConfig } from "@quickgui/cli";

export default defineConfig({
  language: "typescript",
  name: "My App",
  identifier: "com.example.my-app",
  entry: "app.tsx",
  fonts: ["assets/MyFont.ttf"],
  resources: ["assets"],
});
```

`quickgui.toml` も同じキーを受け付けます。`tsconfig.json` では `jsx` を `preserve`、`jsxImportSource` を `@quickgui/solid` に設定します。

## パッケージ

| パッケージ | 用途 |
| --- | --- |
| `@quickgui/native` | ウィンドウ、メニュー、ダイアログなどのプラットフォーム API |
| `@quickgui/solid` | コンポーネントと JSX |
| `solid-js` | シグナル、memo、エフェクト |
| `@quickgui/cli` | `dev`、`check`、`test`、`build` |

ターミナルとアップデーターのサポートは任意パッケージです。[拡張の作成](/docs/typescript/extensions)を参照してください。

## ローカル開発

```sh
bun run dev
bun run check
bun run test
bun run build
```

`dev` は編集に合わせて TypeScript を再読み込みします。
