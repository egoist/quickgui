要素の `transition` でスタイルの変化をアニメーションします。コンポーネントは毎フレーム再実行されません。

## ホバーのトランジション

```tsx
<Button
  style={{
    bg: "#2563eb",
    transition: { property: "bg", duration: 160 },
    hover: { bg: "#1d4ed8" },
  }}
>
  Hover
</Button>
```

## 状態によるアニメーション

アプリの状態からスタイルを変更します。ノードはマウントされたままで、色、不透明度、その他の対応プロパティがアニメーションします。

## 時間とフレームレート

時間には数値、または `"180ms"` のような文字列を渡せます。必要なときにイージングと `maxFps` を設定します。`maxFps` はアニメーション実行中だけ適用されます。

## 対応するプロパティ

トランジションは背景、境界線、角丸、文字色、不透明度、影、変換を対象にします。幅、高さ、パディングは補間しません。完全な一覧は `@quickgui/solid` の型付きトランジションプロパティのユニオンを参照してください。

## マウントと視差効果の抑制

コンポーネントが対応している場合は、閉じるアニメーションが終わるまでオーバーレイをマウントしたままにします。ウィンドウの `reduceMotion` とシステムの設定に従ってください。JavaScript のタイマーでアニメーションを駆動しないでください。

## アニメーション画像

`Image` はアニメーション GIF と WebP を再生します。タイマーは不要です。[Image](/docs/typescript/components/image) を参照してください。
