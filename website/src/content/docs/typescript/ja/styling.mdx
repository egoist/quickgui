ネイティブコンポーネントは kebab-case の属性、または camelCase フィールドの `style` オブジェクトでスタイルします。数値の長さは論理ピクセルです。

## スタイルメソッド

`color` と `textColor` は継承される文字色を設定します。

```tsx
<View padding={16} gap={12} bg="#18181b" color="#fafafa" />
```

`flex-col`、`p-3`、`rounded-lg`、`items-center`、`text-lg`、`font-bold` などのヘルパーはブール属性です。`p-3` は 12 ピクセル、`rounded-lg` は 8 ピクセルです。サイズ引数は取りません。独自の値には `padding={14}`、`border-radius={10}`、`width="50%"` を使います。

```tsx
<View flex-col p-3 gap-2 rounded-lg>
  <Text text-lg font-semibold>Panel title</Text>
</View>
```

ヘルパーを `false`、`null`、`undefined` にするとオフになります。

## スタイルのマージ

スタイル配列は左から右へマージされます。後のフィールドが勝ちます。偽値の項目は無視されます。

```tsx
<View style={[base, selected() && selectedStyle, { padding: 20 }]} />
```

## スタイルの再利用

共有オブジェクトには `JSX.Style` を使います。値をライブに保つときは JSX 内で getter を使います。

```tsx
import type { JSX } from "@quickgui/solid";

const panel = { "p-3": true, "rounded-xl": true, bg: "#20242c" } satisfies JSX.Style;
<View style={panel}><Text>Reusable panel</Text></View>
```

## Flexbox

`display`、`flexDirection`、`flexGrow`、`flexShrink`、配置、`gap` を使います。伸縮するスクロール子には `minWidth={0}` または `minHeight={0}` を設定し、縮小できるようにします。

## グリッド

`display="grid"` にトラックリスト、配置、スパンを組み合わせます。

```tsx
<View display="grid" gridTemplateColumns="220px 1fr" gap={16}>
  <Text>Sidebar</Text>
  <Text>Content</Text>
</View>
```

## テキストと色

フォントファミリー、ウェイト、サイズ、折り返し、省略、選択はネイティブテキストです。色は十六進、CSS カラー文字列、またはパックされた RGBA 値を受け付けます。

## インタラクション状態

```tsx
<Button
  style={{
    bg: "#2563eb",
    hover: { bg: "#1d4ed8" },
    active: { opacity: 0.8 },
    focusVisible: { outlineColor: "#93c5fd", outlineWidth: 2 },
  }}
>
  Save
</Button>
```

## グループと名前付きグループのホバー

祖先に `group` を、子孫に `groupHover` または `groupActive` を設定すると、まとめてスタイルできます。

```tsx
<View group="card" padding={20}>
  <Text color="#64748b" groupHover={{ color: "#2563eb" }}>
    Changes when the card is hovered
  </Text>
</View>
```
