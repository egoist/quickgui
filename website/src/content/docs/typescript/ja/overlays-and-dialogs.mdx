ウィンドウ内の UI には QuickGUI のオーバーレイを、ファイル選択や警告にはシステムのダイアログを使います。

## Popover

`Popover.Root`、トリガー、portal、ポジショナー、ポップアップ、矢印、タイトル、説明、クローズを組み合わせます。配置と閉じる操作は処理済みです。制御された `open`、または default-open オプションを使います。

## Dialog

`Dialog` と `AlertDialog` はモーダル動作に加え、タイトル、説明、背景、ビューポート、クローズのパーツを追加します。フォーカスはダイアログ自身のライフサイクルで戻ります。二重のフォーカストラップを追加しないでください。

## システムポップオーバー

`SystemPopover` はマウント済みノードにアンカーした OS のパネルです。親ウィンドウの外まで広がることができます。所有者とともに破棄してください。

## ネイティブダイアログ

```tsx
import { Dialog } from "@quickgui/native";

const choice = await Dialog.showAlertDialog({
  message: "Save changes?",
  buttons: [{ label: "Save" }, { label: "Cancel", role: "cancel" }],
});
const result = await Dialog.showOpenDialog({
  properties: ["openFile", "multiSelections"],
});
```
