自動更新を入れるには `@quickgui/extension-updater` をインストールします。省略したアプリには updater は同梱されません。

## 設定

```sh
bun add @quickgui/extension-updater
```

署名用のキーペアを生成し、公開鍵をプロジェクトにコピーします。

```sh
bunx @quickgui/cli keygen --sparkle --out-dir "$HOME/.config/my-app/update-keys"
cp "$HOME/.config/my-app/update-keys/quickgui-update.pub" ./update-public-key.pub
```

秘密鍵の `quickgui-update.key` はバージョン管理に入れないでください。

```ts
import { readFileSync } from "node:fs";
import { defineConfig } from "@quickgui/cli";

export default defineConfig({
  language: "typescript",
  name: "My App",
  identifier: "com.example.my-app",
  version: "1.0.0",
  entry: "app.tsx",
  extensions: ["@quickgui/extension-updater"],
  updates: {
    baseUrl: "https://downloads.example.com/my-app",
    publicKey: readFileSync(
      new URL("./update-public-key.pub", import.meta.url),
      "utf8",
    ).trim(),
    automaticChecks: true,
  },
});
```

`darwin-arm64` ビルドは、`updates.feedUrl` を設定しない限り `https://downloads.example.com/my-app/appcast-darwin-arm64.xml` を確認します。その URL の `{target}` は現在のターゲットに置き換わります。

## アプリでの使用

すべてのウィンドウが 1 つのセッションを共有するよう、コンポーネントの外で `app.whenReady()` のあとに開始します。

```ts
import { app } from "@quickgui/native";
import Updater from "@quickgui/extension-updater";

await app.whenReady();

export const updater = new Updater({}, event => {
  if (event.error) console.error(event.error);
  if (event.quitRequired) {
    void app.quit().catch(console.error);
  }
});

await updater.ready;
```

```tsx
import { Button } from "@quickgui/solid";
import { updater } from "./updates";

export function CheckForUpdatesButton() {
  return (
    <Button style={{ p3: true, roundedLg: true }} onClick={() => void updater.check()}>
      Check for Updates
    </Button>
  );
}
```

## ライフサイクル

| API | 用途 |
| --- | --- |
| `updater.check()` | 手動で更新を確認します。 |
| `updater.install()` | 利用可能な更新をインストールします。 |
| `updater.setAutomaticChecks(enabled)` | 自動チェックの設定を変更します。 |
| `updater.state` | 最後のイベントを読み取ります。 |
| `updater.close()` | アプリがもう必要としないセッションを停止します。 |

状態は `idle`、`checking`、`available`、`downloading`、`installing`、`disabled` です。ウィンドウを閉じても、共有の updater を閉じてはいけません。

開発ビルドは既定で `disabled` を報告します。`{ allowDevelopment: true }` は、テスト用フィードと使い捨て可能なアプリバンドルでのみ使ってください。

## 対応プラットフォーム

macOS は Sparkle を使います。Windows は署名済み NSIS インストーラーを使います。Linux は AppImage を使います。Linux のパッケージマネージャによるインストールは `disabled` を報告します。現在の事前ビルド済みパッケージは macOS 向けです。他のターゲットでは、そのホスト上でネイティブビルドが必要です。

## 更新の公開

`quickgui.config.ts` の `version` を上げます。秘密鍵を環境変数に読み込みます。

```sh
export QUICKGUI_UPDATER_PRIVATE_KEY="$(cat "$HOME/.config/my-app/update-keys/quickgui-update.key")"
```

```sh
bunx @quickgui/cli build --target darwin-arm64 --update-manifest \
  --sign "Developer ID Application: Example (TEAMID)" \
  --notarize my-app-notary
```

先にバージョン付きアーカイブをアップロードし、そのあと appcast をアップロードします。アーキテクチャごとに独自のフィードがあります。`updates.manifest: true` は、本番ビルドのたびにフィードを生成します。

## ネイティブ成果物

このリポジトリからは、`bun packages/native/build.ts --extension updater` で updater を一度ビルドします。設定に拡張が列挙されていると、パッケージ済みアプリに含まれます。
