自動更新を配布するには `@quickgui/extension-updater` をインストールします。

## 設定

```sh
bun add @quickgui/extension-updater
```

署名キーを生成し、公開鍵をプロジェクトへコピーします。

```sh
bunx @quickgui/cli keygen --sparkle --out-dir "$HOME/.config/my-app/update-keys"
cp "$HOME/.config/my-app/update-keys/quickgui-update.pub" ./update-public-key.pub
```

`quickgui-update.key` はバージョン管理に入れないでください。

```ts
import { readFileSync } from "node:fs";
import { defineConfig } from "@quickgui/cli";

export default defineConfig({
  language: "typescript",
  name: "My App",
  identifier: "com.example.my-app",
  version: "1.0.0",
  entry: "app.tsx",
  extensions: ["@quickgui/extension-updater"],
  updates: {
    baseUrl: "https://downloads.example.com/my-app",
    publicKey: readFileSync(
      new URL("./update-public-key.pub", import.meta.url),
      "utf8",
    ).trim(),
    automaticChecks: true,
  },
});
```

`darwin-arm64` ビルドは、`updates.feedUrl` で上書きしない限り `https://downloads.example.com/my-app/appcast-darwin-arm64.xml` を確認します。その URL では `{target}` が展開されます。秘密鍵は `--update-manifest` で署名するときだけ使います。

## アプリでの使用

`app.whenReady()` のあと、コンポーネントの外でアップデーターを開始し、すべてのウィンドウが同じセッションを共有するようにします。

```ts
import { app } from "@quickgui/native";
import Updater from "@quickgui/extension-updater";

await app.whenReady();

export const updater = new Updater({}, (event) => {
  if (event.error) console.error(event.error);
  if (event.quitRequired) {
    void app.quit().catch(console.error);
  }
});

await updater.ready;
```

```tsx
import { Button } from "@quickgui/solid";
import { updater } from "./updates";

export function CheckForUpdatesButton() {
  return (
    <Button p-3 rounded-lg onClick={() => {
      void updater.check().catch(console.error);
    }}>
      Check for Updates
    </Button>
  );
}
```

## ライフサイクル

起動に失敗すると `updater.ready` は拒否されます。各コマンドは Promise を返します。

| API | 用途 |
| --- | --- |
| `updater.check()` | 更新を確認します。 |
| `updater.install()` | 利用可能な更新をインストールします。 |
| `updater.setAutomaticChecks(enabled)` | 自動チェックの設定を変更します。 |
| `updater.state` | 直近のイベントを読み取ります。 |
| `updater.close()` | セッションを停止します。 |

状態は `idle`、`checking`、`available`、`downloading`、`installing`、`disabled` のいずれかです。ウィンドウを閉じても共有アップデーターを閉じないでください。

開発ビルドは、テスト用フィードと使い捨てアプリバンドルとともに `{ allowDevelopment: true }` を渡さない限り無効のままです。

## 対応プラットフォーム

macOS は Sparkle を使います。Windows は署名済み NSIS インストーラー、Linux は AppImage を使います。ビルド済みアップデーターパッケージは現在 macOS を対象としています。Linux のパッケージマネージャー経由のインストールは `disabled` を報告します。

## 更新の公開

リリースごとに `quickgui.config.ts` の `version` を上げます。秘密鍵を読み込みます。

```sh
export QUICKGUI_UPDATER_PRIVATE_KEY="$(cat "$HOME/.config/my-app/update-keys/quickgui-update.key")"
```

```sh
bunx @quickgui/cli build --target darwin-arm64 --update-manifest \
  --sign "Developer ID Application: Example (TEAMID)" \
  --notarize my-app-notary
```

先に署名済みアーカイブをアップロードし、続いて生成された `appcast-darwin-arm64.xml` をアップロードします。Intel Mac 向けには `--target darwin-x64` でも繰り返します。アーキテクチャごとにフィードがあります。

CI では `QUICKGUI_UPDATER_PRIVATE_KEY` をシークレットとして保存します。`SPARKLE_PRIVATE_KEY` も受け付けます。ローカル署名では `updates.ed25519SecretKey` を鍵ファイルに向けられます。毎回の本番ビルドでフィードを生成するには `updates.manifest: true` を設定します。

## ネイティブ成果物

`extensions` にパッケージが列挙されていれば、本番ビルドにはすでにアップデーターが含まれます。エンドユーザーはパッケージ済みアプリを実行するだけで、追加のアップデーター用ツールは不要です。
