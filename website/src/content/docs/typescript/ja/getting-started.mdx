QuickGUI の TypeScript アプリは Solid 2 の JSX を使います。ウィンドウとコンポーネントは TypeScript で記述し、CLI がネイティブ macOS アプリの実行、再読み込み、パッケージ化を行います。

## 動作要件

- macOS 14 以降
- Bun 1.4 以降
- Xcode Command Line Tools（`xcode-select --install`）

雛形は Solid 2 と TypeScript 7 を固定します。現在、パッケージ化したアプリは macOS が対象です。

## プロジェクトを作成

```sh
bunx @quickgui/cli init my-app --language typescript
cd my-app
bun run dev
```

CLI はプロジェクトを作成し、依存関係をインストールしてアプリを開きます。`--language typescript` を省略すると、対話的に言語を選べます。

## 最初のウィンドウ

生成された `app.tsx` はアプリの準備完了を待ち、ウィンドウを開き、Solid コンポーネントを描画します。

```tsx
import { createSignal } from "solid-js";
import { app, Window } from "@quickgui/native";
import { Button, Text, View, createRenderer } from "@quickgui/solid";

function Counter() {
  const [count, setCount] = createSignal(0);
  return (
    <View
      width="100%"
      height="100%"
      display="flex"
      flexDirection="column"
      alignItems="center"
      justifyContent="center"
      gap={16}
    >
      <Text fontSize={24}>Count: {count()}</Text>
      <Button padding={12} onClick={() => setCount(count() + 1)}>
        Increment
      </Button>
    </View>
  );
}

function openWindow() {
  new Window({
    title: "My App",
    width: 640,
    height: 460,
    renderer: createRenderer(Counter),
  });
}

app.on("reopen", ({ hasVisibleWindows }) => {
  if (!hasVisibleWindows) openWindow();
});
await app.whenReady();
openWindow();
```

JSX で `count()` を読むとそのテキストが同期します。ボタンをクリックするとシグナルが更新され、ウィンドウの残りはそのままです。

## 実行とビルド

プロジェクトディレクトリで次を実行します。

```sh
bun run check
bun run test
bun run dev
bun run build
```

`dev` は編集に合わせて再ビルドします。`check` は型検査を行います。`build` はパッケージ済みアプリを `dist/` に書き出し、macOS では `.app` と DMG を含めます。
