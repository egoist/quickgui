UI は TypeScript パッケージとして共有するか、QuickGUI が同梱しない追加ライブラリーが必要なときにネイティブサービスを追加します。

## 拡張の種類を選ぶ

再利用する Solid コンポーネントには通常の TypeScript パッケージを使います。機能に Rust、Go、Zig のサービスが必要なときはネイティブ拡張を使います。TypeScript アプリは Go と同じネイティブパッケージを利用できます。

## 拡張プロジェクトを作成する

```sh
bunx @quickgui/cli init-extension my-extension --type rust
```

雛形にはデモアプリとネイティブライブラリーのテンプレートが含まれます。成果物パッケージ名は `--npm-package @acme/extension-my-service` で指定します。

## コンポーネントの共有

```tsx
import { Button, type JSX } from "@quickgui/solid";

export function PrimaryButton(props: JSX.NativeProps) {
  return <Button bg="#2563eb" color="#ffffff" rounded-lg p-3 {...props} />;
}
```

パッケージを公開し、他の TypeScript モジュールと同じようにアプリからインポートします。

## ネイティブ拡張の構成

ネイティブ拡張は `quickgui.extension.json`、バージョン付き共有ライブラリー、宣言した追加ファイルを同梱します。マニフェストにはサービス、バージョン、npm パッケージ、ライブラリーファイルを書きます。

ネイティブの配置は [Go の拡張ガイド](/docs/go/extensions) と [`native-extension` の例](https://github.com/egoist/quickgui/tree/main/examples/native-extension) を参照してください。

## 依存関係の宣言

```ts
import { defineConfig } from "@quickgui/cli";

export default defineConfig({
  language: "typescript",
  name: "Terminal App",
  identifier: "com.example.terminal",
  extensions: ["@quickgui/extension-terminal"],
});
```

対応する npm パッケージを依存関係に追加します。独自拡張は `@acme/extension-echo` のようなスコープ付きパッケージ、スコープなしパッケージ、またはマニフェストを含むディレクトリにできます。

## ネイティブインターフェースを実装する

ネイティブライブラリーは JSON リクエストと任意のセッションに応答します。保持する前に受信バイトをコピーし、遅い処理は worker で行い、セッションが閉じたら処理を止めてください。エントリポイントとリクエスト一覧は[ネイティブインターフェースを実装する](/docs/go/extensions#implement-the-native-contract)を参照してください。

## 自動登録

`extensions` にパッケージを列挙すれば十分です。CLI が同梱し、アプリは起動時に読み込みます。

## 成果物のビルドとパッケージ化

サポートする各 OS とアーキテクチャでネイティブライブラリーをビルドします。アプリの編集ではそれらのビルド済みファイルを再利用します。ネイティブコードを変更したら拡張を再ビルドし、続けてアプリを再ビルドします。

## テストと配布

```tsx
import { ExtensionSession, invokeExtension } from "@quickgui/native";

const result = await invokeExtension("acme-service", "lookup", { key: "example" });
const session = new ExtensionSession("acme-service", {}, (event) => console.log(event));
await session.ready;
await session.request("refresh", null);
await session.close();
```

公開する前に、新しいアプリでパッケージ済み成果物を試してください。エンドユーザーが受け取るのはパッケージ済みアプリケーションであり、実行にネイティブツールチェーンは不要です。
