拡張は、再利用できるコンポーネントの TypeScript パッケージか、アプリから呼び出せるネイティブライブラリです。まずは TypeScript パッケージから始めます。オプションのバックエンドが必要なときにネイティブライブラリを追加します。

## 拡張の種類を選ぶ

再利用する Solid コンポーネントには、通常の TypeScript パッケージを使います。機能に Rust、Go、Zig のサービスが必要なときはネイティブ拡張を使います。ネイティブ拡張はアプリと同じプロセスに読み込まれます。

## 拡張プロジェクトを作成する

```sh
quickgui init-extension my-components --type go
quickgui init-extension my-service --type rust
```

TypeScript アプリは、Go と同じネイティブパッケージを利用します。`--npm-package` は成果物のパッケージ名を設定します。

## コンポーネントの共有

```tsx
import { Button, type JSX } from "@quickgui/solid";

export function PrimaryButton(props: JSX.NativeProps) {
  return (
    <Button
      {...props}
      style={[props.style, { bg: "#2563eb", color: "#ffffff", roundedLg: true, p3: true }]}
    />
  );
}
```

パッケージを公開し、アプリケーションの依存関係として追加します。

## ネイティブ拡張の構成

ネイティブ拡張は `quickgui.extension.json`、バージョン付き共有ライブラリ、宣言したリソースを同梱します。マニフェストはサービス、ABI、npm パッケージ、バージョン、ライブラリの名前を指定します。ネイティブ契約については Go の[拡張の作成](/docs/go/extensions)ガイドと、[`native-extension` の例](https://github.com/egoist/quickgui/tree/main/examples/native-extension)を参照してください。

## 依存関係の宣言

```ts
import { defineConfig } from "@quickgui/cli";

export default defineConfig({
  language: "typescript",
  name: "Terminal App",
  identifier: "com.example.terminal",
  extensions: ["@quickgui/extension-terminal"],
});
```

対応する npm パッケージをアプリケーションの依存関係に追加します。独自の拡張では `@acme/extension-echo` のようなスコープ付きの名前を使えます。

## ネイティブインターフェースを実装する

ネイティブライブラリで `invoke` と `shutdown` を実装します。返す前に借用した入力をコピーし、イベントはそれぞれのセッションに限定し、セッションが止まったらワーカーを解放します。

## 自動登録

CLI は宣言された拡張をバンドルします。アプリは起動時に読み込むので、コンポーネントは `app.whenReady()` のあとに呼び出せます。

## 成果物のビルドとパッケージ化

実装が変わったらネイティブライブラリを再ビルドし、そのあとアプリを再ビルドします。マニフェストに列挙したリソースは、ライブラリの隣にコピーされます。

## テストと配布

```tsx
import { ExtensionSession, invokeExtension } from "@quickgui/native";

const result = await invokeExtension("acme-service", "lookup", { key: "example" });
const session = new ExtensionSession("acme-service", {}, event => console.log(event));
await session.ready;
await session.request("refresh", null);
await session.close();
```

新しいプロジェクトで、パック済みの拡張に対してテストします。パッケージがないアプリにはライブラリがバンドルされないことを確認します。
