SwiftUI モディファイアはネイティブコントロールをスタイルします。リバースホスティングは QuickGUI の内容を SwiftUI の中に置きます。

## モディファイア

`@quickgui/solid/swift-ui/modifiers` のモディファイアファクトリーを順に適用します。コントロールサイズ、ティント、無効化、ラベルスタイル、ボタンの境界形状、ボタンスタイルが含まれます。

## Liquid Glass

```tsx
<Button label="Continue" modifiers={[buttonStyle("glass"), controlSize("large")]} />
```

macOS は利用できる場所でガラスを描画します。

## リバースホスティング

```tsx
<Host matchContents>
  <QuickGUIHostView width={320} height={180}>
    <View padding={16}>
      <Text>QuickGUI inside SwiftUI</Text>
    </View>
  </QuickGUIHostView>
</Host>
```

## SwiftUI ポップオーバー

SwiftUI コントロールには `Popover.Trigger` を、提示するツリーには `Popover.Content` を使います。その内容の `QuickGUIHostView` が通常の QuickGUI コンポーネントをホストします。

## ライフサイクル

埋め込みサーフェスはホストとともに破棄されます。提示されたパネルは所有者とともに破棄されます。グローバルな購読で切り離されたホストを生かし続けないでください。
