モディファイアはネイティブの SwiftUI コントロールにスタイルを付けます。リバースホスティングは SwiftUI の中に QuickGUI のコンテンツを置きます。

## モディファイア

ファクトリは `@quickgui/solid/swift-ui/modifiers` からインポートし、順番どおりに渡します。

```tsx
<Button
  label="Create project"
  modifiers={[buttonStyle("borderedProminent"), controlSize("large"), tint("#f97316")]}
/>
```

モディファイアにはコントロールサイズ、tint、無効状態、ラベルスタイル、ボタンのボーダー形状、ボタンスタイルが含まれます。

## Liquid Glass

```tsx
<Button label="Continue" modifiers={[buttonStyle("glass"), controlSize("large")]} />
```

macOS は、利用できる場所にガラスを描画します。

## リバースホスティング

```tsx
<Host matchContents>
  <QuickGUIHostView width={320} height={180}>
    <View style={{ padding: 16 }}><Text>QuickGUI inside SwiftUI</Text></View>
  </QuickGUIHostView>
</Host>
```

## SwiftUI ポップオーバー

SwiftUI コントロールには `Popover.Trigger` を、表示する UI には `Popover.Content` を使います。そのコンテンツ内の `QuickGUIHostView` が、通常の QuickGUI の子をホストします。

## ライフサイクル

埋め込まれたホストはオーナーとともに閉じます。アンマウントするとネイティブビューは取り除かれます。グローバルな購読を通して、切り離されたホストを保持しないでください。
