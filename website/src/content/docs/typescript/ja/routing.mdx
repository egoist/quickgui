ルーターは現在のパスからコンポーネントを選び、戻る／進む履歴を保持します。ルートは現在のウィンドウで描画されます。

## ルートの宣言

```tsx
import { Router, Route, Link } from "@quickgui/solid/router";

<Router initialPath="/">
  <Route path="/" component={() => <Text>Home</Text>} />
  <Route path="/projects/:id" component={Project} />
</Router>
```

## 入れ子のレイアウト

入れ子のルートは親からの相対パスです。次のマッチを置く位置で `<Outlet />` またはレイアウトの `children` を描画します。パスなしルートは URL セグメントを増やさずにレイアウトを共有できます。

```tsx
<Route
  path="/"
  component={(props) => (
    <View>
      <Link href="/">Home</Link>
      <Link href="/settings">Settings</Link>
      {props.children}
    </View>
  )}
>
  <Route path="/" component={() => <Text>Home</Text>} />
  <Route path="/settings" component={() => <Text>Settings</Text>} />
</Route>
```

## ナビゲーション

```tsx
const navigate = useNavigate();
<Button onClick={() => navigate("/projects/42")}>Open project</Button>
<Link href="/">Home</Link>
```

`navigate` は push、replace、back、forward に対応します。ナビゲーションはアプリ内に留まります。

## ルートパラメーター

```tsx
function Project() {
  const params = useParams();
  return <Text>Project {params().id}</Text>;
}
```

`useLocation()` と `useSearchParams()` は URL に合わせて更新されるアクセサーを返します。繰り返しのクエリキーは配列です。
