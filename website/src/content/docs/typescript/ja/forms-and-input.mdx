フィールド値はシグナルに保存し、受け入れた変更をコールバックから書き戻します。

## テキスト入力

```tsx
const [value, setValue] = createSignal("");
<Input
  value={value()}
  onInput={(event) => setValue(event.value ?? "")}
  placeholder="Name"
/>
<TextArea
  value={notes()}
  onInput={(event) => setNotes(event.value ?? "")}
/>
```

## フィールド

`Field` と `Fieldset` はラベル、説明、コントロール、エラーを関連付けます。validity、touched、dirty の状態はアプリ側で駆動します。検証モードとデバウンスはフィールド上にあります。

## 選択コントロール

`Checkbox`、`CheckboxGroup`、`RadioGroup`、`Radio`、`Switch` をインジケーターとラベルで組み合わせます。各ルートの変更コールバックから制御状態を更新します。無効と読み取り専用は別です。

## Select

`Select`、`Combobox`、`Autocomplete` はオプション一覧を受け取ります。オプション値は安定させてください。状態フックは選択、クエリ、ハイライト、チップを公開し、カスタムパーツに使えます。

## イベント

テキストイベントは文字列を `event.value` に入れます。ポインター、キー、ジェスチャー、ドロップ、送信のハンドラーは型付きのペイロードを持ちます。必要なハンドラーを宣言すると、コントロールがそのイベントを発行できます。
