ウィンドウを開く前に `app.whenReady()` を待ってください。ウィンドウとダイアログのコールバックはアプリケーションコードで実行されます。

## ウィンドウのライフタイム

`renderer: createRenderer(...)` でウィンドウを作成します。`onClose` と `on("closed", ...)` で閉じたタイミングを観察できます。`onCloseRequested` はユーザーによるクローズを遅らせられ、`close()` で完了します。`whenReady()` は非表示ウィンドウも含め、ウィンドウが存在したあとに解決します。

```tsx
const window = new Window({
  title: "My App",
  width: 720,
  height: 480,
  renderer: createRenderer(App),
});
window.on("closed", () => {
  // Release window-owned resources here.
});
```

macOS では、Dock の再オープンが `hasVisibleWindows` が false だと報告したときに新しいウィンドウを開きます。

## コマンドとサービス

```tsx
import { app, Clipboard, Dialog, Menu, Screen, Shell } from "@quickgui/native";

await app.whenReady();
const displays = await Screen.getAllDisplays();
const selected = await Dialog.showOpenDialog({ properties: ["openDirectory"] });
```

ダイアログ、クリップボード、メニュー、ディスプレイ、外観は Promise を返します。システムメニューとファイルダイアログはプラットフォームのコントロールです。

## イベントとファイル監視

ウィンドウイベントにはフォーカス、リサイズ、外観、ready-to-show、最小化、フルスクリーン、クローズがあります。アプリイベントには ready、再オープン、アクティベーション、終了、URL を開くことがあります。

ファイルは Bun で監視し、所属ウィンドウが閉じたら watcher を停止します。
