SwiftUI コントロールは `@quickgui/solid/swift-ui` からインポートし、`Host` で包みます。QuickGUI ウィンドウ内の本物の macOS コントロールです。通常の QuickGUI コンポーネントはこれらなしで動作します。

## Host

```tsx
import { Host, Button } from "@quickgui/solid/swift-ui";

<Host matchContents>
  <Button label="Continue" />
</Host>
```

## ネイティブコントロール

ボタン、ラベル、トグル、スライダー、ステッパー、プログレスビュー、ゲージ、テキスト／セキュアフィールド、ピッカー、セグメントコントロール、日付・カラーピッカー、ポップオーバーが利用できます。各コンポーネントページに props とイベントが載っています。

## 制御値

```tsx
import { Host, Toggle } from "@quickgui/solid/swift-ui";

<Host matchContents>
  <Toggle label="Notifications" isOn={enabled()} onIsOnChange={setEnabled} />
</Host>
```

SwiftUI コントロールと QuickGUI ノードは同じシグナルを共有できます。

## サイズ

`matchContents` はコントロールからホストのサイズを決め、対応する軸ごとのオプションも含みます。高さを内容に合わせたいだけなら、親の幅を制約します。

## 対応プラットフォーム

SwiftUI ホスティングは macOS 専用です。Liquid Glass などの任意の外観は OS に従います。[モディファイアとホスティング](/docs/typescript/swift-ui-hosting)を参照してください。
