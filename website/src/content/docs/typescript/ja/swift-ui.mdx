SwiftUI コントロールは `@quickgui/solid/swift-ui` からインポートし、`Host` で包みます。通常の QuickGUI コンポーネントにはこれは不要です。

## Host

```tsx
import { Host, Button } from "@quickgui/solid/swift-ui";

<Host matchContents>
  <Button label="Continue" />
</Host>
```

ホストはネイティブビューの境界であり、コンテンツから自身のサイズを決められます。

## ネイティブコントロール

ボタン、ラベル、トグル、スライダー、ステッパー、プログレスビュー、ゲージ、テキストフィールドとセキュアフィールド、ピッカー、セグメントコントロール、日付ピッカーとカラーピッカー、ポップオーバーがあります。見た目と動きはシステムコントロールと同じです。

## 制御値

```tsx
import { Host, Toggle } from "@quickgui/solid/swift-ui";

<Host matchContents>
  <Toggle label="Notifications" isOn={enabled()} onIsOnChange={setEnabled} />
</Host>
```

## サイズ

`matchContents` はコントロールからホストのサイズを決めます。幅を固定して高さを固有サイズにしたいときは、軸ごとのオプションがあります。

## 対応プラットフォーム

SwiftUI ホスティングには macOS が必要です。Liquid Glass のような任意の外観は、OS のバージョンに依存します。
