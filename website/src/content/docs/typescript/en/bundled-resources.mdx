Use `resources` to ship files that are not compiled into the executable: images, templates, JSON, and other data. The CLI copies each path into the packaged app under its basename. The running app reads them from the resource directory, which does not depend on the launch working directory.

Custom fonts are a separate option. See [Fonts](#fonts).

## Configuration

```ts
import { defineConfig } from "@quickgui/cli";

export default defineConfig({
  language: "typescript",
  name: "My App",
  identifier: "com.example.my-app",
  entry: "app.tsx",
  resources: ["assets", "copy/template.txt"],
  fonts: ["assets/MyFont.ttf"],
});
```

Each entry is a file or a directory. Relative paths resolve from the project directory. Destination names must be unique and must not replace reserved names such as `fonts`, `AppIcon.icns`, `quickgui.json`, or the host shared library.

`quickgui dev` and `quickgui build` both stage these files. Missing paths fail the build.

## Install locations

| Platform | Resource directory |
| --- | --- |
| macOS `.app` | `Contents/Resources` |
| Linux AppDir, AppImage, and `.deb` | Next to the executable (`usr/bin`) |
| Windows installer | Next to the executable in `$INSTDIR` |

A configured path `assets` is installed as `assets/` in that directory. A file `copy/template.txt` is installed as `template.txt`. Join those names onto `resourceDir` at runtime; do not read from the project tree or the current working directory.

## Loading files

Await `app.whenReady()`, then join the packaged name onto `resourceDir`:

```tsx
import { join } from "node:path";
import { app, Window } from "@quickgui/native";
import { Image, createRenderer } from "@quickgui/solid";

await app.whenReady();
const paths = await app.getPaths();
const hero = join(paths!.resourceDir, "assets", "hero.png");

new Window({
  title: "My App",
  renderer: createRenderer(() => (
    <Image source={hero} style={{ width: 160, height: 120 }} />
  )),
});
```

`Image` accepts that filesystem path. Other files use the same join: read them with `Bun.file` or `readFileSync`. Relative image paths are not resolved against the resource directory.

## Fonts

`fonts` lists OpenType files. The CLI copies them into `fonts/` inside the resource directory and registers them before the first window opens.

```ts
export default defineConfig({
  language: "typescript",
  name: "My App",
  identifier: "com.example.my-app",
  entry: "app.tsx",
  fonts: ["assets/MyFont.ttf"],
});
```

Use the font family name in `style`. Fonts are not a replacement for `resources`: an image or JSON file still belongs in `resources`.
